# The pages a person has to read

These 93 pages went to the reader three times and never came back clean. The reader keeps a page like that rather than dropping it, with the faults named in the front matter under `flags`, so nothing is lost, but nothing has looked at them since either. This is the handover: the list, what is wrong with each one, and where to find it in the pdf.

It is generated and it goes stale the moment one of them is repaired. To rebuild it, look for the pages whose flags carry the phrase the reader writes, `never came back clean`, and read the rule out of the same line.

## What is wrong with them

| rule | pages |
| --- | ---: |
| rule statement names still on it | 65 |
| rule math names still on it | 23 |
| rule head names still on it | 3 |
| rule math, statement names still on it | 2 |

The rule names are the reader's own checks. `statement names` is a statement whose name did not come back in the form the assembler looks for, `math names` is an operator or a function name set as prose rather than as mathematics, and `head names` is a running head that did not match what the contents has for that page.
