25. Let C be a cogebra over a ring A. A sub-A-module S of C is called a coideal if c(S) ⊂ Im(S ⊗ C) + Im(C ⊗ S). If C is counital, with counit γ, a coideal S is called conull if γ(x) = 0 for x ∈ S.

(a) A right or left coideal is a coideal. Every sum of coideals is a coideal.
(b) If S is a coideal of C, the orthogonal S^0 is a subalgebra of the dual algebra C*. If C is counital and S is conull, S^0 is unital.
(c) Suppose that A is a field and C a counital cogebra. Show that if E' is a unital subalgebra of C* with the same unit element as C*, the orthogonal E'^0 in C is a conull coideal.
(d) If S is a coideal of C, show that there exists on C/S one and only one cogebra structure such that the canonical mapping p: C → C/S is a cogebra morphism. If C is counital and S is conull, C/S is counital.

(26) Let C be a coassociative counital cogebra over a commutative field K.

(a) For every vector subspace E of C which is a left C*-module under the law (u, x) ↦ u ↼ x, the left annihilator of this C*-module is a two-sided ideal J' of the algebra C*. Show that if E is finite-dimensional over K, C*/J' is finite-dimensional.
(b) Deduce from (a) that for every element x ∈ C, the subcogebra of C generated by x is finite-dimensional. (Note that the C*-module E generated by x is finite-dimensional and that, if J' is its left annihilator, x ∈ J'^0, the orthogonal of J' in C.)

(27) Let B be an associative unital algebra over a commutative field K and let m: B ⊗_K B → B be the K-linear mapping defining the multiplication on B. The tensor product B* ⊗_K B* (where B* is the dual vector space of the vector space B) is canonically identified with a vector subspace of (B ⊗_K B)* (II, § 7, no. 7, Proposition 16).

(a) Show that for an element w ∈ B* the following conditions are equivalent: (1) ^t m(w) ∈ B* ⊗ B*; (2) the set of x ↼ w, where x runs through B, is a finite-dimensional subspace of B*; (3) the set of w ↼ x, where x runs through B, is a finite-dimensional subspace of B*; (4) the set of x ↼ w ↼ y, where x and y run through B, is contained in a finite-dimensional subspace of B*.
