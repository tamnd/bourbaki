### 4. INITIAL RAMIFICATION INDEX

Definition 4. Let G be a totally ordered commutative group and H a subgroup of G of finite index. The number of major subsets of G consisting of strictly positive elements and containing all the elements > O of H is called the initial index of H in G and denoted by $\varepsilon(G, H)$.

This initial index is a natural number by virtue of the following proposition:

Proposition 3. Under the hypotheses of Definition 4, if the set of strictly positive elements of G has no least element, then $\varepsilon(G, H) = 1$ for all H. If there exists a least element > O of G and $G'$ denotes the subgroup it generates, then

$$
\varepsilon(G, H) = (G : (G \cap H)).
$$

In the first case, let x be an element > 0 in G. The set of $y \in G$ such that $0 < y < x$ is infinite and hence there exist two elements of this set which are distinct and congruent modulo H; their difference is an element z of H such that $0 < z < x$. Hence every major subset which contains all the strictly positive elements of H contains x and hence all the elements > 0 of G.
