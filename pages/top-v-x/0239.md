b) Let $ X $ be a metrizable space and let $ R $ be a closed equivalence relation on $ X $. Show that if every point of $ X/R $ has a countable fundamental system of neighbourhoods, then each equivalence class (mod $ R $) has a compact frontier in $ X $. (Show that if the result were false there would exist a sequence in $ X $, all of whose points were distinct, which had no cluster point, and whose image in $ X/R $ was a sequence which converged to a point distinct from all the points of the sequence.)
