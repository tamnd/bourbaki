c) If the set $\mathscr{P}_0$ of functions in $\mathscr{P}$ that are continuous and finite on X is total in $\mathscr{C}(X; \mathbf{R})$, then the relation $\mu \prec \nu$ is an order relation on $\mathscr{M}_+(X)$. If a measure $\nu \in \mathscr{M}_+(X)$ is maximal for this order relation, then so is every measure $\nu'$ such that $0 \leqslant \nu' \leqslant \nu$ (for the usual order) (argue by contradiction using a)). If $\mathscr{P}_0 = \mathscr{P}$ and $\mathscr{P}$ is total, then every increasing directed set for the order relation $\mu \prec \nu$ admits a supremum in $\mathscr{M}_+(X)$ for this relation; in particular, $\mathscr{M}_+(X)$ is *inductive* for this relation.

d) Suppose that the functions in $\mathscr{P}$ are continuous and finite, that $\mathscr{P}$ is total in $\mathscr{C}(X; \mathbf{R})$, and that $\mathscr{P} + \mathscr{P} \subset \mathscr{P}$ and $c \cdot \mathscr{P} \subset \mathscr{P}$ for all $c > 0$. For every function $f \in \mathscr{C}(X; \mathbf{R})$, denote by $S(f)$ the lower envelope of the functions $h \in -\mathscr{P}$ such that $f \leqslant h$; for every $\varepsilon > 0$, denote by $K_{f,\varepsilon}$ the set of $x \in X$ such that $S(f)(x) \geqslant f(x) + \varepsilon$. Show that the following conditions are equivalent:
α) The measure $\mu \in \mathscr{M}_+(X)$ is maximal for the order relation $\lambda \prec \lambda'$.
β) For every function $f \in \mathscr{C}(X; \mathbf{R})$, $\mu(S(f)) = \mu(f)$.
β') For every function $f \in \mathscr{P}$, $\mu(S(f)) = \mu(f)$.
γ) For every function $f \in \mathscr{C}(X; \mathbf{R})$ and every $\varepsilon > 0$, $\mu(K_{f,\varepsilon}) = 0$.
γ') For every function $f \in \mathscr{P}$ and every $\varepsilon > 0$, $\mu(K_{f,\varepsilon}) = 0$.
(Apply b) to $-\mathscr{P}$.)

e) Under the hypotheses of d), show that if $\mu$ and $\mu'$ are two positive measures on X that are maximal for the relation $\prec$, then so is $\mu + \mu'$. From this, deduce that the set of positive measures that are maximal for this order relation is a lattice for the usual order relation $\leqslant$.

¶ 3) Let X be a nonempty compact space, $\mathscr{P}$ a set of lower semi-continuous numerical functions on X, taking values in $]-\infty, +\infty]$; assume that $\mathscr{P}$ contains the finite constants. A point $x \in X$ is said to be $\mathscr{P}$-*extremal* if the measure $\varepsilon_x$ is *minimal* for the pre-order relation $\mu \prec \nu$ [^1]; the set of $\mathscr{P}$-extremal points is denoted $\mathrm{Ch}_{\mathscr{P}}(X)$.

a) Show that if $\mathscr{P}'$ is the set of linear combinations $\sum_i c_i h_i$ of functions in $\mathscr{P}$ with coefficients $\geqslant 0$, the $\mathscr{P}$-extremal points are identical to the $\mathscr{P}'$-extremal points.

b) For a point $x \in X$, show that the following conditions are equivalent:
α) $x$ is $\mathscr{P}$-extremal.
β) For every function $f \in \mathscr{C}(X; \mathbf{R})$ and every $\varepsilon > 0$, there exists an $h \in \mathscr{P}'$ such that $f \leqslant h$ and $h(x) \leqslant f(x) + \varepsilon$.
γ) For every open neighborhood U of $x$ and every $\varepsilon > 0$, there exists a function $h \geqslant 0$ in $\mathscr{P}'$ such that $h(x) \leqslant \varepsilon$ and $h(y) \geqslant 1$ for all $y \in X - U$. (Use Exer. 2 b).)

Show, moreover, that the set of points of $\mathrm{Ch}_{\mathscr{P}}(X)$ where at least one function in $\mathscr{P}$ attains its infimum in X is dense in $\mathrm{Ch}_{\mathscr{P}}(X)$.

c) A subset F of X is said to be $\mathscr{P}$-*stable* if it is closed and if the relations $\lambda \prec \mu$ and $\mathrm{Supp}(\mu) \subset F$ imply $\mathrm{Supp}(\lambda) \subset F$. Show that if $u \in \mathscr{P}$ and if $F'$ is the set of points of F where $u$ attains its infimum in F, then the set $F'$ is $\mathscr{P}$-stable.

d) Assume in addition that $\mathscr{P}$ separates the points of X. Show that for every function $h \in \mathscr{P}$, the set $S_h$ of points of X where $h$ attains its infimum in X intersects $\mathrm{Ch}_{\mathscr{P}}(X)$. (Consider a minimal $\mathscr{P}$-stable subset contained in $S_h$ and use c) to show that such a subset reduces to a single point.)

e) With the same hypotheses as in d), show that for a closed subset F of X to contain $\mathrm{Ch}_{\mathscr{P}}(X)$, it is necessary and sufficient that for every function $h \in \mathscr{P}'$, F intersect the set $S_h$ of points where $h$ attains its infimum in X (make use of b)). From this, deduce that for $a \in X$ to be in the closure of $\mathrm{Ch}_{\mathscr{P}}(X)$, it is necessary and sufficient that for every open neighborhood U of $a$, there exist $h \in \mathscr{P}'$ and $b \in U$ such that $h(b) < h(x)$ for all $x \in X - U$ (in other words, $S_h \subset U$).

[^1]: The definition of maximal (or minimal) element in an ordered set (S, III, §1, No. 6) extends at once to pre-ordered sets.
