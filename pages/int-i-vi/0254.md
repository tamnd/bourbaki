¶ 8) The general notations and hypotheses being those of Exer. 6, set $S = \check{S}_{\mathscr{H}}(X)$. A function $f \in \mathscr{C}(S; \mathbf{R})$ is said to be $\mathscr{H}\text{-resolvent}$ if there exists a function $g \in \mathscr{H}^c$ such that $f = g|S$ (this function is then unique).

a) Show that the following conditions on a function $f \in \mathscr{C}(S; \mathbf{R})$ are equivalent:
(i) $f$ is $\mathscr{H}\text{-resolvent}$.
(ii) For every $x \in X$, $\underline{H}_x^S(f) = \overline{H}_x^S(f)$.
(iii) For every $x \in X$ and every pair of measures $\mu_1, \mu_2$ in $\mathscr{M}_x^S$, one has $\int f d\mu_1 = \int f d\mu_2$.

b) Show that the following properties are equivalent:
(i) Every function $f \in \mathscr{C}(S; \mathbf{R})$ is $\mathscr{H}\text{-resolvent}$.

(iv) The set $\mathscr{H}^c$ is lattice-ordered.
