§ 3

1. Let $A$, $B$, $C$ be relations in a logical theory $\mathscr{T}$. Show that the following relations are theorems in $\mathscr{T}$ :

$$A \Rightarrow (B \Rightarrow A),$$
$$(A \Rightarrow B) \Rightarrow ((B \Rightarrow C) \Rightarrow (A \Rightarrow C)),$$
$$A \Rightarrow ((\text{not } A) \Rightarrow B),$$
$$(A \text{ or } B) \Leftrightarrow ((A \Rightarrow B) \Rightarrow B),$$
$$(A \Leftrightarrow B) \Leftrightarrow ((A \text{ and } B) \text{ or } ((\text{not } A) \text{ and } (\text{not } B))),$$
$$(A \Leftrightarrow B) \Leftrightarrow \text{not } ((\text{not } A) \Leftrightarrow B),$$
$$(A \Rightarrow (B \text{ or } (\text{not } C))) \Leftrightarrow ((C \text{ and } A) \Rightarrow B),$$
$$(A \Rightarrow (B \text{ or } C)) \Leftrightarrow (B \text{ or } (A \Rightarrow C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \Rightarrow C) \Rightarrow (A \Rightarrow (B \text{ and } C))),$$
$$(A \Rightarrow C) \Rightarrow ((B \Rightarrow C) \Rightarrow ((A \text{ or } B) \Rightarrow C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \text{ and } C) \Rightarrow (B \text{ and } C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \text{ or } C) \Rightarrow (B \text{ or } C)).$$

2. Let $A$ be a relation in a logical theory $\mathscr{T}$. If $A \Leftrightarrow (\text{not } A)$ is a theorem of $\mathscr{T}$, then $\mathscr{T}$ is contradictory.

3. Let $A_1$, $A_2$, ..., $A_n$ be relations in a logical theory $\mathscr{T}$.

(a) To prove the relation "$A_1$ or $A_2$ or ... or $A_n$" in $\mathscr{T}$, it is enough to prove $A_n$ in the theory obtained by adjoining to $\mathscr{T}$ the axioms not $A_1$, not $A_2$, ..., not $A_{n-1}$.

(b) If "$A_1$ or $A_2$ or ... or $A_n$" is a theorem in $\mathscr{T}$, then to prove a theorem $A$ in $\mathscr{T}$ it is sufficient to prove the theorems

$$A_1 \Rightarrow A, \qquad A_2 \Rightarrow A, \qquad \ldots, \qquad A_n \Rightarrow A.$$
