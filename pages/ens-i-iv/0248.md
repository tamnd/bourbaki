Show that, if $ 0 \leq \eta < \xi \leq \alpha $, then $ \mathrm{Card}(f_\alpha(\eta)) < \mathrm{Card}(f_\alpha(\xi)) $ and that, if $ \xi \leq \alpha \leq \beta $, then $ f_\alpha(\xi) = f_\beta(\xi) $. Put $ \omega_\alpha = f_\alpha(\alpha) $; $ \omega_\alpha $ is said to be the initial ordinal with index $ \alpha $. We have $ \omega_\alpha \geq \alpha $.
