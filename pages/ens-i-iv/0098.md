If $(X_i)_{i \in I}$ is a family of subsets of a set E, then its union is a subset of E; notice that it does not depend on E, nor on the target $ \mathscr{G} $ of the mapping $ i \rightarrow X_i $.

It is clear that if $ I = \varnothing $, we have $ \bigcup_{i \in I} X_i = \varnothing $, because the relation $ (\exists i)(i \in I \text{ and } x \in X_i) $ is then false.

Suppose now that $ I \neq \varnothing $. If $ \alpha $ is an element of I, the relation

$$
(\forall i)((i \in I) \implies (x \in X_i))
$$

implies $ x \in X_\alpha $ and therefore, by virtue of C52 (\$1, no. 6), this relation is collectivizing in $ x $.

**Definition 2.** Let $(X_i)_{i \in I}$ be a family of sets whose index set I is not empty. The set $ \mathscr{E}_x((\forall i)((i \in I) \implies (x \in X_i))) $, that is to say, the set of all $ x $ which belong to every set of the family $(X_i)_{i \in I}$, is called the intersection of the family and is denoted by $ \bigcap_{i \in I} X_i $.

If $ I = \varnothing $, the relation $ (\forall i)((i \in I) \implies (x \in X_i)) $ is not collectivizing in $ x $; for it is a true relation and there exists no set Y such that $ x \in Y $ is a true relation, because Y would then be the set of all objects (cf. \$1, no. 7, Remark).

If $(X_i)_{i \in I}$ is a family of subsets of a set E and if $ I \neq \varnothing $, the relation "x \in E and $ (\forall i)((i \in I) \implies (x \in X_i)) $" is equivalent to

$$
(\forall i)((i \in I) \implies (x \in X_i));
$$

consequently it is collectivizing in $ x $, and the set of all $ x $ which satisfy this relation is equal to $ \bigcap_{i \in I} X_i $. If $ I = \varnothing $, the relation "x \in E and $ (\forall i)((i \in I) \implies (x \in X_i)) $" is equivalent to $ x \in E $; it is therefore collectivizing in $ x $, and the set of all $ x $ which satisfy this relation is E.
