SYSTEMS OF TYPE B_l ($l \geq 2$)

(I) $V = E = \mathbf{R}^l$.
Roots: $\pm \varepsilon_i,\ (1 \leq i \leq l),\ \pm \varepsilon_i \pm \varepsilon_j\ (1 \leq i < j \leq l)$.
Number of roots: $n = 2l^2$.

(II) Basis: $\alpha_1 = \varepsilon_1 - \varepsilon_2, \alpha_2 = \varepsilon_2 - \varepsilon_3, \ldots, \alpha_{l-1} = \varepsilon_{l-1} - \varepsilon_l, \alpha_l = \varepsilon_l$.
Positive roots:
$$
\varepsilon_i = \sum_{i \leq k \leq l} \alpha_k\quad (1 \leq i \leq l),
$$
$$
\varepsilon_i - \varepsilon_j = \sum_{i \leq k < j} \alpha_k\quad (1 \leq i < j \leq l),
$$
$$
\varepsilon_i + \varepsilon_j = \sum_{i \leq k < j} \alpha_k + 2 \sum_{j \leq k \leq l} \alpha_k\quad (1 \leq i < j \leq l),
$$

(III) Coxeter number: $h = 2l$.

(IV) Highest root:
$$
\tilde{\alpha} = \varepsilon_1 + \varepsilon_2 = \alpha_1 + 2\alpha_2 + 2\alpha_3 + \cdots + 2\alpha_l.
$$
We have $\tilde{\alpha} = 2\omega_2$ if $l = 2, \tilde{\alpha} = \omega_2$ if $l \geq 3$.
Completed Dynkin graph:

for $l = 2$:
$$
\begin{array}{c}
\circ \longrightarrow \circ \\
\alpha_2 \quad \alpha_1
\end{array}
$$

for $l \geq 3$:
$$
\begin{array}{c}
\circ \longrightarrow \circ \cdots \longrightarrow \circ \\
\alpha_1 \quad \alpha_2 \quad \alpha_3 \quad \cdots \quad \alpha_{l-1} \quad \alpha_l
\end{array}
$$

(V) $R^-$ is the set of vectors
$$
\pm 2\varepsilon_i\quad (1 \leq i \leq l),\ \pm \varepsilon_i \pm \varepsilon_j\ (1 \leq i < j \leq l).
$$
$$
\Phi_R(x, y) = \frac{(x|y)}{4l-2},\quad \gamma(R) = (l+1)(4l-2).
$$
