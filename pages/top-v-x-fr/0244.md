**¶ 20) Soient $X, X'$ deux espaces métrisables. Pour tout ordinal dénombrable pair (resp impair) $\alpha$, on dit qu’une application $f$ de $X$ dans $X'$ est *borélienne de classe $\alpha$* si, pour toute partie fermée $F'$ de $X'$, $f^{-1}(F')$ appartient à $\mathcal{F}_\alpha(X)$ (resp. $\mathcal{G}_\alpha(X)$) (IX, p. 119, exerc. 6); alors, pour toute partie ouverte $G'$ de $X'$, $f^{-1}(G')$ appartient à $\mathcal{G}_\alpha(X)$ (resp. $\mathcal{F}_\alpha(X)$). Les fonctions boréliennes de classe 0 sont les fonctions continues.
$\alpha)$ Pour que la fonction caractéristique $\varphi_A$ d’une partie $A$ de $X$ soit de classe $\alpha$, il faut et il suffit que $A$ appartienne à $\mathcal{F}_\alpha \cap \mathcal{G}_\alpha$.
b) Soit $f$ une application de classe $\alpha$ de $X$ dans $X'$; montrer que pour toute partie $B' \in \mathcal{F}_\beta(X')$ (resp. $B' \in \mathcal{G}_\beta(X')$), $f^{-1}(B')$ appartient à $\mathcal{F}_{\alpha+\beta}(X)$ (resp. $\mathcal{G}_{\alpha+\beta}(X)$). (Raisonner par récurrence transfinie sur $\beta$.)
c) Soient $f$ une application de classe $\alpha$ de $X$ dans $X'$, $g$ une application de classe $\beta$ de $X'$ dans un espace métrisable $X''$; montrer que $g \circ f$ est une application de classe $\alpha + \beta$.
d) Pour tout ordinal dénombrable pair (resp. impair) $\alpha$, soit $(A_n)$ une suite de parties de $X$ appartenant à $\mathcal{G}_\alpha$ (resp. $\mathcal{F}_\alpha$) et formant un recouvrement de $X$; si une application $f$ de $X$ dans $X'$ est telle que sa restriction à chacun des $A_n$ soit de classe $\alpha$, alors $f$ est de classe $\alpha$. Résultat analogue pour une suite *finie* de parties de $X$ appartenant à $\mathcal{F}_\alpha$ (resp. $\mathcal{G}_\alpha$) et formant un recouvrement de $X$.

21) a) Soient $X, X'$ deux espaces métrisables, $X'$ étant de type dénombrable, et soit $(U'_n)$ une base dénombrable pour la topologie de $X'$. Soit $\alpha$ un ordinal dénombrable pair (resp. impair); si une application $f$ de $X$ dans $X'$ est telle que $f^{-1}(U'_n)$ appartienne à $\mathcal{G}_\alpha(X)$ (resp. $\mathcal{F}_\alpha(X)$), $f$ est de classe $\alpha$.
b) Soit $(X_n)$ une suite d’espaces métrisables de type dénombrable. Pour qu’une application $f = (f_n)$ de $X$ dans $\prod_n X'_n$ soit de classe $\alpha$, il faut et il suffit que chacune des $f_n$ soit de classe $\alpha$ (utiliser a)). En déduire que si $X$ est de type dénombrable, les fonctions numériques finies de classe $\alpha$ sur $X$ forment un anneau.
c) Soient $X, X'$ deux espaces métrisables de type dénombrable, $\alpha$ un ordinal dénombrable pair (resp. impair). Si une application $f$ de $X$ dans $X'$ et de classe $\alpha$, montrer que son graphe appartient à $\mathcal{F}_\alpha(X \times X')$ (resp. $\mathcal{G}_\alpha(X \times X')$) (utiliser b) et l’exerc. 20 b)).

22) Soient $X, Y$ deux espaces métrisables, $f$ une application approchable (IX, p. 115, exerc. 22) de $X$ dans $Y$. Montrer que pour tout ensemble borélien $B \subset Y, f^{-1}(B)$ est approchable dans $X$ (cf. IX, p. 112, exerc. 6). En déduire que si $g$ est une application borélienne de $Y$ dans un espace métrisable $Z$, $g \circ f$ est approchable. Donner un exemple d’une application continue $f$ et d’une application approchable $g$ telles que $g \circ f$ ne soit pas approchable (cf. IX, p. 122, exerc. 14 b)).
