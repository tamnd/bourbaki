9) Si un espace topologique X est tel que chaque point de X admette un voisinage fermé dans X qui soit un sous-espace uniformisable, montrer que X est uniformisable.

10) Soit X un espace uniformisable; montrer que la famille de tous les écarts sur X qui sont continus dans X × X, définit sur X une structure uniforme compatible avec la topologie de X (IX, p. 84, exerc. 3). Cette structure uniforme $ \mathcal{U}_\omega $ (dite structure uniforme universelle sur X) et la plus fine de toutes les structures uniformes compatibles avec la topologie de X. Si Y est un espace uniforme, f une application continue de X dans Y, f est uniformément continue lorsqu’on munit X de sa structure universelle, et cette propriété caractérise uniquement $ \mathcal{U}_\omega $ parmi toutes les structures uniformes compatibles avec la topologie de X. S’il existe une structure uniforme $ \mathcal{U} $ compatible avec la topologie de X et telle que, muni de $ \mathcal{U} $, X soit un espace uniforme complet, montrer que pour toute structure uniforme $ \mathcal{U}' $ plus fine que $ \mathcal{U} $ et moins fine que $ \mathcal{U}_\omega $, l’espace X, muni de $ \mathcal{U}' $, est aussi un espace complet (remarquer que les filtres de Cauchy sont les mêmes pour $ \mathcal{U} $ et pour $ \mathcal{U}' $).

11) a) Soient X un espace complètement régulier, $ \mathcal{U} $ une structure uniforme compatible avec la topologie de X. Soit $ \mathcal{U}^* $ la structure uniforme la moins fine sur X rendant uniformément continues toutes les applications de X dans $[0,1]$ qui sont uniformément continues quand on munit X de la structure $ \mathcal{U} $. Montrer que la structure uniforme $ \mathcal{U}^* $ est séparée et compatible avec la topologie de X, et que X, muni de cette structure uniforme, est précompact.
b) Soit Y un espace compact quelconque; montrer que toute application f de X dans Y, qui est uniformément continue lorsqu’on munit X de la structure uniforme $ \mathcal{U} $, est encore uniformément continue lorsqu’on munit X de la structure $ \mathcal{U}^* $ (utiliser IX, p. 9, prop. 5). En déduire que, sur X, la structure uniforme $ \mathcal{U}^* $ est la plus fine des structures uniformes moins fines que $ \mathcal{U} $ et pour lesquelles X est précompact.

12) a) Soient X un espace localement compact, $ \Phi $ l’ensemble des applications continues de X dans $[0,1]$, à support compact (IX, p. 46, déf. 2). Soit $ \mathcal{U}_\alpha $ la structure uniforme la moins fine sur X rendant uniformément continues toutes les fonctions de $ \Phi $; montrer que la structure $ \mathcal{U}_\alpha $ est compatible avec la topologie de X, que le complété $ \tilde{X} $ de X pour cette structure est compact, et que le complémentaire de X dans $ \tilde{X} $ est vide ou réduit à un point (montrer que si X n’est pas compact le filtre des complémentaires des ensembles relativement compacts dans X est un filtre de Cauchy pour $ \mathcal{U}_\alpha $).
b) Montrer que la structure uniforme $ \mathcal{U}_\alpha $ est la moins fine des structures uniformes compatibles avec la topologie de X.
c) Inversement, soit X un espace complètement régulier tel que, dans l’ensemble des structures uniformes compatibles avec la topologie de X, il existe une structure $ \mathcal{U}_\alpha $ moins fine que toutes les autres. Montrer que X est localement compact (en utilisant l’exerc. 11, montrer que X, muni de $ \mathcal{U}_\alpha $, est précompact; puis faire voir que le complémentaire de X dans son complété pour la structure $ \mathcal{U}_\alpha $ ne peut avoir plus d’un point).
d) On suppose que X est localement compact et dénombrable à l’infini, donc (I, p. 68, prop. 15) réunion d’une suite croissante $(U_n)$ d’ensembles ouverts relativement compacts telle que $ \overline{U}_n \subset U_{n+1} $. Montrer qu’il existe une fonction numérique f continue dans X, telle que $ f(x) \leq n $ pour $ x \in \overline{U}_n $ et $ f(x) \geq n $ pour $ x \notin \overline{U}_n $ (cf. IX, p. 102, exerc. 6). Soit $ \mathcal{U} $ la structure uniforme la moins fine sur X rendant uniformément continues toutes les fonctions de $ \Phi $ et la fonction f; montrer que cette structure est compatible avec la topologie de X et qu’il existe un entourage V de $ \mathcal{U} $ tel que, pour tout $ x \in X $, $ V(x) $ soit relativement compact dans X (II, p. 37, exerc. 9).

13) a) Soit X un espace complètement régulier, $ \mathcal{U}_\omega $ sa structure uniforme universelle (IX, p. 86, exerc. 10); montrer que la structure $ \mathcal{U}_\omega^* $ (IX, p. 86, exerc. 11) est la structure uniforme induite sur X par celle de son compactifié de Stone-Čech $ \beta X $ (IX, p. 10).
b) Montrer que l’espace compact $ \tilde{X} $ défini dans I, p. 110, exerc. 26, est canoniquement isomorphe à $ \beta X $.
