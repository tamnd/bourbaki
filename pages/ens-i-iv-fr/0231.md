Exercises

§ 1

1) Soit S l’ensemble des signes P, X, x₁, ..., xₙ, les lettres xᵢ étant de poids 0, P de poids 1 et X de poids 2. Soit T un mot équilibré de L₀(S) (I, p. 42); on dira qu’un tel mot est un type d’échelon sur x₁, ..., xₙ.

Soient maintenant E₁, ..., Eₙ n termes d’une théorie plus forte que la théorie des ensembles. Pour tout type d’échelon T sur x₁, ..., xₙ, on définit un terme T(E₁, ..., Eₙ) de la façon suivante:
1° si T est une lettre xᵢ, T(E₁, ..., Eₙ) est l’ensemble Eᵢ;
2° si T est de la forme PU, T(E₁, ..., Eₙ) est l’ensemble $ \mathfrak{P}(U(E₁, ..., Eₙ)) $;
3° Si T est de la forme XUV, T(E₁, ..., Eₙ) est l’ensemble
$$
U(E₁, ..., Eₙ) \times V(E₁, ..., Eₙ).
$$
Montrer que, pour tout type d’échelon T sur x₁, ..., xₙ, T(E₁, ..., Eₙ) est un échelon sur les termes E₁, ..., Eₙ, et réciproquement (raisonner par récurrence sur la longueur du type d’échelon ou du schéma de construction d’échelon); on dit que T(E₁, ..., Eₙ) est la réalisation du type d’échelon T sur les termes E₁, ..., Eₙ. De façon plus précise, tout échelon sur n lettres distinctes peut s’écrire d’une manière et d’une seule sous la forme T(x₁, ..., xₙ), où T est un type d’échelon.

Montrer de même comment on peut associer à un type d’échelon T sur n lettres, et à n applications f₁, ..., fₙ une extension canonique de ces applications. En déduire que si deux schémas de construction d’échelon S, S’ sur n lettres sont tels que S(x₁, ..., xₙ) = S’(x₁, ..., xₙ) (x₁, ..., xₙ lettres distinctes), on a $ \langle f₁, ..., fₙ \rangle^S = \langle f₁, ..., fₙ \rangle^{S'} $.

§ 2

1) Soit S l’ensemble des signes P, P⁻, X, X⁻, x₁, ..., xₙ les lettres xᵢ étant de poids 0, P et P⁻ de poids 1, X et X⁻ de poids 2. Pour tout mot Λ de L₀(S) (I, p. 42) on définit la variance de Λ de la façon suivante: chacune des lettres xᵢ ainsi que les signes P, X ont pour variance 0, les signes P⁻, X⁻ ont pour variance 1; la variance de Λ est la somme *(dans le corps F₂)* des variances des signes qui y figurent (autrement dit, elle est 0 s’il y a un nombre pair de ces signes ayant la variance 1, et 1 dans le cas contraire).

On appelle type d’échelon signé un mot équilibré A de L₀(S) (I, p. 42) qui vérifie l’une des conditions suivantes:
1° A est une des lettres xᵢ;
2° Si A est de la forme fA₁A₂...Aₚ (I, p. 45, cor. 2), où f est l’un des signes P, P⁻, X, X⁻, p est égal à 1 ou 2 et les Aᵢ (1 ≤ i ≤ p) sont des mots équilibrés, alors chacun des Aᵢ est un type d’échelon signé; en outre, si f = X, A₁ et A₂ ont pour variance 0, et si f = X⁻, A₁ et A₂ ont pour variance 1.

Un type d’échelon signé est dit covariant s’il est de variance 0, contravariant s’il est de variance 1. Si, dans un type d’échelon signé A, on remplace P⁻ et X⁻ par P et X respectivement, on obtient un type d’échelon A* (IV, § 1, exerc. 1); toute réalisation du type d’échelon A* sur n termes E₁, ..., Eₙ est dite réalisation du type d’échelon signé A sur E₁, ..., Eₙ, et notée A(E₁, ..., Eₙ).

Soient E₁, ..., Eₙ, E₁', ..., Eₙ' des ensembles, fᵢ une application de Eᵢ dans Eᵢ' (1 ≤ i ≤ n). Montrer qu’à chaque type d’échelon signé S sur x₁..., xₙ, on peut associer une application {f₁, ..., fₙ}^S ayant les propriétés suivantes:
1° Si S est covariant (resp. contravariant), {f₁, ..., fₙ}^S est une application de S(E₁, ..., Eₙ) dans S(E₁', ..., Eₙ') (resp. de S(E₁', ..., Eₙ') dans S(E₁, ..., Eₙ)).
