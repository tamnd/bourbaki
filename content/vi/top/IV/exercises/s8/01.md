Nếu $x$ và $y$ là thực, ta có
$$
[x + y] = [x] + [y] + \varepsilon \quad \text{với } \varepsilon = 0 \text{ hoặc } \varepsilon = 1,
$$
$$
[x - y] = [x] - [y] - \varepsilon \quad \text{với } \varepsilon = 0 \text{ hoặc } \varepsilon = 1,
$$
$$
[x] + [x + y] + [y] \leqslant [2x] + [2y],
$$
$$
[x] + \left[ x + \frac{1}{n} \right] + \left[ x + \frac{2}{n} \right] + \cdots + \left[ x + \frac{n-1}{n} \right] = [nx],
$$
$$
\left[ \frac{[nx]}{n} \right] = [x]
$$
với mọi số nguyên $n > 0$.
