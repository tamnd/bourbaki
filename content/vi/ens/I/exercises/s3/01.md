Cho $A$, $B$, $C$ là các quan hệ trong một lý thuyết lôgic $\mathscr{T}$. Hãy chứng minh rằng các quan hệ sau là các định lý trong $\mathscr{T}$ :

$$A \Rightarrow (B \Rightarrow A),$$
$$(A \Rightarrow B) \Rightarrow ((B \Rightarrow C) \Rightarrow (A \Rightarrow C)),$$
$$A \Rightarrow ((\text{không } A) \Rightarrow B),$$
$$(A \text{ hoặc } B) \Leftrightarrow ((A \Rightarrow B) \Rightarrow B),$$
$$(A \Leftrightarrow B) \Leftrightarrow ((A \text{ và } B) \text{ hoặc } ((\text{không } A) \text{ và } (\text{không } B))),$$
$$(A \Leftrightarrow B) \Leftrightarrow \text{không } ((\text{không } A) \Leftrightarrow B),$$
$$(A \Rightarrow (B \text{ hoặc } (\text{không } C))) \Leftrightarrow ((C \text{ và } A) \Rightarrow B),$$
$$(A \Rightarrow (B \text{ hoặc } C)) \Leftrightarrow (B \text{ hoặc } (A \Rightarrow C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \Rightarrow C) \Rightarrow (A \Rightarrow (B \text{ và } C))),$$
$$(A \Rightarrow C) \Rightarrow ((B \Rightarrow C) \Rightarrow ((A \text{ hoặc } B) \Rightarrow C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \text{ và } C) \Rightarrow (B \text{ và } C)),$$
$$(A \Rightarrow B) \Rightarrow ((A \text{ hoặc } C) \Rightarrow (B \text{ hoặc } C)).$$
