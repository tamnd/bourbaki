Cho $R$, $S$, $T$ là quan hệ trong $\mathscr{T}$ và cho $x$ là một chữ cái. Nếu $R$ là pharem hàm trong $x$ trong $\mathscr{T}$, chứng minh rằng các quan hệ sau là định lý trong $\mathscr{T}$ :

$$(\text{không } (\exists x)(R \text{ và } S)) \Leftrightarrow (\exists x)(R \text{ vanda } (\text{không } S)),$$

$$(\exists x)(R \text{ vanda } (S \text{ vanda } T)) \Leftrightarrow (\exists x)(R \text{ vanda } S) \text{ vanda } (\exists x)(R \text{ vanda } T)),$$
$$(\exists x)(R \text{ vanda } (S \text{ hoặc } T)) \Leftrightarrow ((\exists x)(R \text{ vanda } S) \text{ hoặc } (\exists x)(R \text{ vanda } T)).$$
