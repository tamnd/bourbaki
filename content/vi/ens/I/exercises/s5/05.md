Cho $R$, $S$, $T$ là các quan hệ trong $\mathscr{T}$ và $x$ là một chữ cái. Nếu $R$ là phiếm hàm theo $x$ trong $\mathscr{T}$, hãy chỉ ra rằng các quan hệ sau là các định lý trong $\mathscr{T}$ :

$$(\text{không } (\exists x)(R \text{ và } S)) \Leftrightarrow (\exists x)(R \text{ và } (\text{không } S)),$$

$$(\exists x)(R \text{ và } (S \text{ và } T)) \Leftrightarrow (\exists x)(R \text{ và } S) \text{ và } (\exists x)(R \text{ và } T)),$$
$$(\exists x)(R \text{ và } (S \text{ hoặc } T)) \Leftrightarrow ((\exists x)(R \text{ và } S) \text{ hoặc } (\exists x)(R \text{ và } T)).$$
