a) On a set X, the set of regular topologies, and the set of regular topologies without isolated point, are inductive for the relation « 𝒯 is less fine than 𝒯’ ».

b) A topology 𝒯 on a set X is said to be ultraregular if it is maximal in the set of topologies on X which are regular and without isolated point; for every regular topology without isolated point on X, there therefore exists a finer ultraregular topology. A space whose topology is ultraregular is said to be ultraregular. For a regular topology without isolated point to be ultraregular, it is necessary and sufficient that if A and B are two complementary subsets of X without isolated point, A and B are open for 𝒯. In particular, an ultraregular space is not solvable (I, p. 92, exerc. 11). (To now prove that the condition is sufficient, remark that if 𝒯’ is a regular topology without isolated point, finer than 𝒯, U a nonempty open subset for 𝒯’, $\overline{U}$ its closure for 𝒯’, $\overline{U}$ and X — $\overline{U}$ have no isolated point for 𝒯).

c) In an ultraregular space, the closure of every set without isolated point is an open set, and the interior of a everywhere dense set is everywhere dense; the intersection of two everywhere dense sets is therefore everywhere dense. Conclude that if $\mathcal{T}_0$ is an ultraregular topology, among all the topologies 𝒯 such that $\mathcal{T}^* = \mathcal{T}_0$ (I, p. 103, exerc. 20), there is one which is finer than all the others (necessarily submaximal).
