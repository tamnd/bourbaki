Let $X$ be a set with one element. If $n$ is an integer $\geq 1$, denote by $u_n$ the number of elements of $M(X)$ of length $n$.
a) For every set $Y$, now prove that one has
$$
\operatorname{Card}(M_n(Y)) = u_n \cdot \operatorname{Card}(Y)^n.
$$
(Use exerc. 3.)
b) Establish the relation
$$
u_n = \sum_{p=1}^{n-1} u_p u_{n-p} \quad \text{for } \quad n \geq 2.
$$

c) \* Let $f(T)$ be the formal series $\sum_{n=1}^{\infty} u_n T^n$. Now prove that one has $f(T) = T + f(T)^2$. Deduce the formulas
$$
f(T) = \frac{1}{2}(1 - (1 - 4T)^{1/2}), \qquad u_n = \frac{2^{n-1}}{n!} 1.3.5...(2n-3) \quad \text{for } n \geq 2.*
$$
Find this last result again using exerc. 11 of E, III, p. 85.
