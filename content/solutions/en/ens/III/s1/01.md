Let E be an ordered set; denote its order relation by ≤. For x, y ∈ E we write x < y to mean x ≤ y and x ≠ y. The relation R is defined by: R{x, y} holds if and only if x ∈ E, y ∈ E and x < y.

We verify the three conditions of no. 1 for R.

**First condition (transitivity).** Assume R{x, y} and R{y, z}. Then x < y and y < z, so x ≤ y, y ≤ z, x ≠ y and y ≠ z. By transitivity of ≤ we have x ≤ z. If x = z, then x ≤ y and y ≤ x, whence x = y by antisymmetry of ≤, contradicting x ≠ y. Thus x ≠ z, so x < z, and therefore R{x, z} holds.

**Second condition.** Assume R{x, y} and R{y, x}. Then x < y and y < x, so x ≤ y and y ≤ x. Antisymmetry of ≤ gives x = y. But x < y implies x ≠ y, a contradiction. Hence the antecedent R{x, y} ∧ R{y, x} is false for all x, y, and the implication (R{x, y} ∧ R{y, x}) ⇒ (x = y) is true (vacuously).

**Third condition.** We show that this condition fails. By hypothesis there exists at least one pair of distinct comparable elements in E; thus there are a, b ∈ E with a ≠ b and either a < b or b < a. Without loss of generality suppose a < b. Then R{a, b} holds. However R{a, a} would mean a < a, which is false because a ≤ a is true but a ≠ a is false. Similarly R{b, b} is false. Consequently R{a, b} is true while R{a, a} ∧ R{b, b} is false, so the implication R{a, b} ⇒ (R{a, a} ∧ R{b, b}) is false. Therefore the third condition is not satisfied.
