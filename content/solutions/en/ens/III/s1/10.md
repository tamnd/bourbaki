Let E and F be two lattices and let f be a mapping of E into F.

First suppose that f is increasing. Let x, y ∈ E. Since E is a lattice (Definition 8, tag 03QM), the infimum inf(x, y) exists and satisfies inf(x, y) ≤ x and inf(x, y) ≤ y. Because f is increasing (Definition 1, tag 03JC), we obtain f(inf(x, y)) ≤ f(x) and f(inf(x, y)) ≤ f(y). Thus f(inf(x, y)) is a lower bound of the set {f(x), f(y)}. As inf(f(x), f(y)) is the greatest lower bound of this set in the lattice F, we have f(inf(x, y)) ≤ inf(f(x), f(y)).

Conversely, assume that f(inf(x, y)) ≤ inf(f(x), f(y)) for all x, y ∈ E. Let x, y ∈ E with x ≤ y. Then inf(x, y) = x, since x is a lower bound of {x, y} and every lower bound is ≤ x. Hence f(x) = f(inf(x, y)) ≤ inf(f(x), f(y)). By definition of the infimum, inf(f(x), f(y)) ≤ f(y). Therefore f(x) ≤ f(y), which proves that f is increasing.

For the example, consider the ordered set ℕ of natural numbers with its usual order. The product ordered set ℕ × ℕ is ordered by (a, b) ≤ (c, d) iff a ≤ c and b ≤ d. Define f : ℕ × ℕ → ℕ by f(a, b) = a + b. If (a, b) ≤ (c, d), then a ≤ c and b ≤ d, so a + b ≤ c + d; thus f(a, b) ≤ f(c, d) and f is increasing. Now take x = (1, 0) and y = (0, 1). Their infimum in ℕ × ℕ is (min(1, 0), min(0, 1)) = (0, 0). Then f(inf(x, y)) = 0 + 0 = 0. On the other hand, f(x) = 1 and f(y) = 1, so inf(f(x), f(y)) = min(1, 1) = 1. Hence f(inf(x, y)) = 0 ≠ 1 = inf(f(x), f(y)), and the equality fails for this pair.
