(a) 设a、b为环 A的两个互素理想。证明a: b = a, b: a = b。如果 c 是 A 的理想，且满足 ac ⊂ b，则 c ⊂ b。

(b) 设 p、q 为两个素理想，其中一个不包含在另一个中；则 p: q = p 和 q: p = q 给出多项式环 A = K[X, Y ]（其中 K 为域）中的两个主素数理想 p、q 的例，其中两个都不包含在另一个中，并且互不互质。

(c) 令 a 为元素，它不是 A 中 0 的除子。证明，如果主理想 p = Aa 是素数，则对于两个理想 b、A 的 c，关系 p = bc 意味着 b = A 或 c = A。
