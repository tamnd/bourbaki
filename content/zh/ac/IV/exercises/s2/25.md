令 $A$ 为 Laskerian 环。令$a$为$A$的理想，且$a = \bigcap_{1 \leq i \leq n} q_i$为$A$中$a$的约化初等分解；设$p_i$表示$q_i$的根号；假设$\mathrm{Ass}_f(A/a)$的最小元素是$p_i$，这样$1 \leq i \leq s$和$s < n$。我们写$b = \bigcap_{1 \leq i \leq s} q_i, c = \bigcap_{s+1 \leq i \leq n} q_i$。

(a) 证明存在 $x \in c$，使得 $x \notin p_i$ 对应 $1 \leq i \leq s$ 以及 $a = b \cap (a + Ax)$。

(b) 假设对于例，$p_{s+1}$ 在$\mathrm{Ass}_f(A/c)$ 中是最小的。证明$xp_{s+1} + a \neq Ax + a$和$a = b \cap (xp_{s+1} + a)$；此外，$p_{s+1}$在$\mathrm{Ass}_f(A/b)$中最小，其中$b = xp_{s+1} + a$。证明$b$相对于$p_{s+1}$的饱和度与$q''_1$不同。 （注这个饱和度不能包含$x$。）
