设 M 为 A-模，N 为 M 的子模，并承认简化的初等分解 N = \bigcap_{i=1}^{n} Q_i；令 p_i 为与 Q_i 相关的素理想。

(a) 证明，如果 b 是 A 的理想，并且不包含在任何 p_i 中，则 N : b = N (cf. 习题 17)。

(b) 如果每个 Q_i 在 M 中都是强主要的，则反过来证明，如果 N : b = N，则 b 不包含在任何 p_i 中。 （请注意，如果 b \子集 p_i 且 P = \bigcap_{j \neq i} Q_j，则 b^rP \子集 N 对于某些合适的整数 r 并推断出，如果 N : b = N，则 P = N。）推断出 b 中存在 \beta \，使得 N : (\beta) = N。
