(a) 令$A$为普吕弗域，$M$为有限秩$n$的向量空间$V$在分数$K$$A$的域上的有限生成格。证明存在$V$和$n$分数理想$a, (1 \leq i \leq n)$的基$(e_i)_{1 \leq i \leq n}$，使得M等于$a_i e_i$的直和。 （通过归纳对$n$论证：如果$(u_i)_{1 \leq i \leq n}$是V的基，则考虑由M的元素的$u_1$坐标生成的有限生成的分数理想$b_1$；通过考虑A-模$b_1^{-1}M$， 约化 $b_1 = A$ 的情况。）

推出，如果 W 是 V 的子空间，则 $M \cap W$ 是 M 的直因子。

(b) 假设 M 是 A" 的子模等于 $a_i e_i$ 的直和，其中 $a_i$ 是 A 的有限生成（整的）理想和 $A^n$ 的 $(e_i)_{1 \leq i \leq n}$ 典范基。证明存在基 $(u_i)_{1 \leq i \leq n}$ A 的理想 $b_i$ 使得 M 是 $b_i u_i$ 的直和和 $b_i$ 除 $b_{i+1}$ 对于 $1 \leq i \leq n - 1$。 （约化对应于$n = 2$和$a_1 + a_2 = A$的情况。）
