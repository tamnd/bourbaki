设$\mathbf{A}$为整环。
   (a) 令 $(p_i)_{1 \leq i \leq m}, (p'_j)_{1 \leq j \leq n}$ 为两个有限族可逆素理想，使得$p_1p_2\ldots p_m = p'_1p'_2\ldots p'_n$。 证明$m = n$并且存在$[1, n]$的置换$\pi$使得$p'_i = p_{\pi(i)}$对于所有$i$使得$1 \leq i \leq n$。
   (b) 设$p$为$\mathbf{A}$的素理想，$a$元素为$\mathbf{A} - q$的素理想；如果$p \subset \mathbf{A}a + p^2$，则表明$p = p(\mathbf{A}a + p)$；推出，如果$p$是可逆的，则$\mathbf{A}a + p = \mathbf{A}$。
   (c) 证明，如果 $\mathbf{A}$ 的每个理想都是 $\mathbf{A}$ 素理想的乘积（不一定先验唯一），则 $\mathbf{A}$ 是 Dedekind 域。 （首先证明每个可逆素理想$q$是最大的，考虑$\mathbf{A}a + p$和$\mathbf{A}a^2 + q$的元素、$a \in \mathbf{A} - q$和分解作为素理想的乘积和环中的应用 (a) $A/p$ 显示$Aa^2 + p = (Aa + p)^2$；然后使用(b)。 然后证明每个素理想$p \neq 0$是可逆的，通过分解为素理想的乘积一个主理想$Ab$，其中$b \in p$，注意到，这个乘积的因子是可逆的，并且通过上面的应用，证明$p$必然等于其中因子之一。 结论借助习题 8。）
