如果 $l_{m,n}$ 是 $\sin^m x \cos^n x$ 的原语（$m$ 和 $n$ 是任意实数），则证明
$$
I_{m+2,n} = -\frac{\sin^{m+1} x \cos^{n+1} x}{m + n + 2} + \frac{m + 1}{m + n + 2} I_{m,n}
$$
是 $\sin^{m+2} x \cos^n x$ if $m + n + 2 \neq 0$ 的原语。

借助公式恢复III、p. 100的公式(29)并证明公式
$$
\int_0^{\pi/2} \sin^{2n+1} x \, dx = \frac{2.4.6 \ldots 2n}{1.3.5 \ldots (2n+1)} \quad (n \text{ an integer } \geqslant 0).
$$
