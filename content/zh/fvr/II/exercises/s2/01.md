令$\alpha$和$\beta$是两个有限的实数，使得$\alpha < \beta$。证明如果 $\gamma$ 和 $\delta$ 是两个数使得 $\alpha < \gamma \leq \delta < \beta$ 则存在一个定义在区间 $[0, a]$ 上的实函数 $f$，仅取值 $\alpha$ 和 $\beta$，这样，在所有区间$[\varepsilon, a]$（对于$\varepsilon > 0$），$f$是一个步骤函数，如果有人放入$g(x) = \int_0^x f(t)\, dt$，则有
$$
\liminf_{x \to 0, x > 0} \frac{g(x)}{x} = \gamma, \qquad \limsup_{x \to 0, x > 0} \frac{g(x)}{x} = \delta;
$$
(*)
（对于$g$函数，其图形是一条折线，其连续边具有梯度$\alpha$和$\beta$，其峰值交替出现在$\gamma \neq \delta$的直线$y = \gamma x, \ y = \delta x$上，或$y = \gamma x$直线和抛物线$y = \gamma x + x^2$上$\gamma = \delta$）。

同理方法表明，无论$\gamma$和$\delta$是否有限（$\gamma < \delta$），都存在一个定义在$[0, a]$上的实数函数$f$，使得在每一个区间$[\varepsilon, a]$上（对于$\varepsilon > 0$)，$f$是函数的一步，整的$g(x) = \int_0^x f(t)\, dt$存在，并且又具有关系(*)。
