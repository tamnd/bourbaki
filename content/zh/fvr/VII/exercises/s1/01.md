令 g 为受调节的函数，且 ]0, +∞[ 上 > 0。

a) 令 u, v 为 ]0, +∞[ 上的两个递增函数，使得 u(x + 1) − u(x) = v(x + 1) − v(x) = g(x) 对于所有 x > 0。证明如果 w = u − v 则有

$$
\sup_{0 < x \leq y \leq 1} |w(y) - w(x)| \leq \inf_{x > 0} g(x).
$$

（注，对于 a ≤ x ≤ y ≤ a + 1，有 u(y) − u(x) ≤ g(a)。）特别是，如果 $\inf_{x > 0} g(x) = 0$，则方程 $u(x + 1) - u(x) = g(x)$ 中最多存在一个递增解，在给定点处取给定值。

b) 假设 g 是 ]0, +∞[ 上的递减。显示级数

$$
\varphi(x) = - g(x) + \sum_{n=1}^{\infty} (g(n) - g(x + n))
$$

绝对一致收敛于 ]0, +∞[ 中包含的每个紧区间：如果 $\lambda = \lim_{x \to +\infty} g(x)$ 则函数 $u(x) = \varphi(x) + \lambda x$ 是方程 $u(x + 1) - u(x) = g(x)$ 的递增解。证明对于该方程的每个递增解 v，对于 $0 < x < y$ 都有 $v(y) - v(x) \geq \varphi(y) - \varphi(x)$。等式 $u(x + 1) - u(x) = g(x)$ 在给定值和给定点时，递增解的集合的上（或下）包络线是多少？证明这个集合约化到单个元素当且仅当 $\lambda = 0$。

c) 证明如果 g(x) 为递增且在 [0, +∞[ 上 > 0，则方程 $u(x + 1) - u(x) = g(x)$ 有无限多个递增解，它们在给定的点处取给定的值。

d) 设$\psi(x)$为函数，由条件在]0, +∞[上定义：$0 \leq x < 1$为$\psi(x) = 0$，$1 \leq x < 2$为$\psi(x) = 1$，$n - 1 + \frac{1}{n-1} \leq x < n + \frac{1}{n}$为$\psi(x) = n$ ($n \geq 2$)；让$g(x) = \psi(x + 1) - \psi(x)$。证明 $\psi$ 是方程中唯一的递增解

$$
u(x + 1) - u(x) = g(x)
$$

这样$u(1) = 1$。
