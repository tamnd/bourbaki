令 $\mathbf{f}$ 为函数，即在区间 $I$ 包含 0 上可微的 $n - 1$ 倍，并令 $\mathbf{f}_n$ 为向量函数，通过关系在 $I$ 上为 $x \neq 0$ 定义

$$
\mathbf{f}(x) = \mathbf{f}(0) + \mathbf{f}'(0) \frac{x}{1!} + \mathbf{f}''(0) \frac{x^2}{2!} + \cdots + \mathbf{f}^{(n-1)}(0) \frac{x^{n-1}}{(n-1)!} + \mathbf{f}_n(x)x^n.
$$

a) 证明如果$\mathbf{f}$在点 0处有$(n+p)^{th}$导数，则$\mathbf{f}_n$在点 0处有$p^{th}$导数，并且$(n+p-1)^{th}$在邻域的所有点处有与0不同的0的导数；此外，对于$0 \leq k \leq p$有$\mathbf{f}_n^{(k)}(0) = \frac{k!}{(n+k)!} \mathbf{f}^{(n+k)}(0)$，对于$1 \leq k \leq n-1$，$\mathbf{f}_n^{(p+k)}(x)x^k$与$x$趋于0（借助$\mathbf{f}$的逐次导数的泰勒展开表达$\mathbf{f}_n$的导数，并使用道具6） I、p. 18）。

b) 相反，令$\mathbf{f}_n$为向量函数，承认$I$中0对邻域的$(n+p-1)^{th}$导数，使得$\mathbf{f}_n^{(p+k)}(x)x^k$对于$0 \leq k \leq n-1$有极限。证明函数 $\mathbf{f}_n(x)x^n$ 在 $I$ 上有 $(n+p-1)^{th}$ 导数；此外，如果 $\mathbf{f}_n$ 在点 0 处存在 $p^{th}$ 导数，则 $\mathbf{f}_n(x)x^n$ 在点 0 处存在 $(n+p)^{th}$ 导数。

c) 假设 $I$ 关于 0 对称，并且 $\mathbf{f}$ 是偶数（$\mathbf{f}(-x) = \mathbf{f}(x)$ 在 $I$ 上）。借助a)证明，如果$\mathbf{f}$在$I$上可微分$2n$倍，则存在定义的函数$g$且在$I$上可微分$n$倍，使得$\mathbf{f}(x) = g(x^2)$在$I$上可微分。
