a) 在框 P 上：$|t - t_0| < a,\ |x - x_0| < b$ 令 g 和 h 为两个连续实数函数，使得 P 上的 $g(t, x) < h(t, x)$。令 u（分别为 v）为 $x' = g(t, x)$（分别为 $x' = h(t, x)$）的积分，使得 $u(t_0) = x_0$（分别为 $v(t_0) = x_0$）在区间上定义$[t_0, t_0 + c[$；证明对于 $t_0 < t < t_0 + c$ 来说，有 $u(t) < v(t)$（考虑不等式所成立的 t 的上界$\tau$）。

b) 令 u 为 $x' = g(t, x)$ 相应的到点 $(t_0, x_0)$ 的最大积分（练习 10），在区间 $[t_0, t_0 + c[$ 上定义，值在 $|x - x_0| < b$ 中。证明在$[t_0, t_0 + c[$中包含的每个紧凑区间$[t_0, t_0 + d]$中，一旦$\varepsilon > 0$足够小，方程$x' = g(t, x) + \varepsilon$相应的到点$(t_0, x_0)$的最小和最大积分就被定义，并且当$\varepsilon$趋于0时均匀收敛于u通过值 > 0。

c) 令g和h为在P上定义的两个实数连续函数，并且使得P上的$g(t, x) \leq h(t, x)$。令$[t_0, t_0 + c[$为区间，在其上定义$x' = g(t, x)$的积分u，使得$u(t_0) = x_0$，并且$x' = h(t, x)$相应的的最大积分v为点$(t_0, x_0)$。证明 $u(t) \leq v(t)$ 在此区间上（约化对于情况 a) 使用 b))。
