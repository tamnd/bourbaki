(a) 令 $\alpha$ 和 $\beta$ 为两个序数词。证明不等式 $\alpha < \beta$ 等价于 $\alpha + 1 \leqslant \beta$，并且它隐含了所有序数 $\xi$ 的不等式 $\xi + \alpha < \xi + \beta$、$\alpha + \xi \leqslant \beta + \xi$、$\alpha\xi \leqslant \beta\xi$，以及 $\xi > 0$ 的不等式 $\xi\alpha < \xi\beta$。

(b) 从 (a) 推断不存在每个序数属于对应的集合（使用习题 14 (d)）。

(c) 令$\alpha$、$\beta$、$\mu$ 为三个序数词。证明关系$\mu + \alpha < \mu + \beta$、$\alpha + \mu < \beta + \mu$中的每一个都蕴涵$\alpha < \beta$；并且关系$\mu\alpha < \mu\beta$、$\alpha\mu < \beta\mu$中的每一个都意味着$\alpha < \beta$，前提是$\mu > 0$。

(d) 证明关系$\mu + \alpha = \mu + \beta$蕴含$\alpha = \beta$，并且$\mu\alpha = \mu\beta$蕴涵$\alpha = \beta$，前提是$\mu > 0$。

(e) 两个序数$\alpha$和$\beta$使得$\alpha \leqslant \beta$当且仅当存在一个序数$\xi$使得$\beta = \alpha + \xi$。那么这个序数$\xi$是唯一的并且使得$\xi \leqslant \beta$；上面写着$(-\alpha) + \beta$。

(f) 设 $\alpha$、$\beta$、$\zeta$ 为三个序数词，使得 $\zeta < \alpha\beta$。证明存在两个序数 $\xi$、$\eta$，使得 $\zeta = \alpha\eta + \xi$ 和 $\xi < \alpha$、$\eta < \beta$（cf. no. 5、定理 3，推出 3）。而且，$\xi$和$\eta$是由这些条件唯一确定的。
