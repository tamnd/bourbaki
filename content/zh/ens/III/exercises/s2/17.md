给定一个序数$\alpha_0$，项$f(\xi)$被认为是一个*序数功能符号*（*相对于*$\xi$）*定义为*$\xi \geqslant \alpha_0$，如果关系“$\xi$是一个序数并且$\xi \geqslant \alpha_0$”意味着关系 “$f(\xi)$是序数词”；如果关系 $\alpha_0 \leqslant \xi < \eta$ 暗示 $f(\xi) < f(\eta)$，并且如果对于序数 $\geqslant \alpha_0$ 的每个系列 $(\xi_\iota)_{\iota \in I}$，我们有 $\sup_{\iota \in I} f(\xi_\iota) = f(\sup_{\iota \in I} \xi_\iota)$ (cf. 习题 14 (d))，则 $f(\xi)$ 被称为“正常”。

(a) 表明，对于每个序数 $\alpha > 0$、$\alpha + \xi$ 和 $\alpha\xi$ 是为 $\xi \geqslant 0$ 定义的正常函数符号（使用习题 15 (f)）。

(b) 设$w(\xi)$为$\xi \geqslant \alpha_0$定义的序数函数符号，使得$w(\xi) \geqslant \xi$且$\alpha_0 \leqslant \xi < \eta$隐含$w(\xi) < w(\eta)$。还令$g(\xi, \eta)$为项，使得关系“$\xi$和$\eta$是序数$\geqslant \alpha_0$”意味着关系“$g(\xi, \eta)$是序数使得$g(\xi, \eta) > \xi$”。

定义项 $f(\xi, \eta)$ 具有以下属性： (1) 对于每个序数$\xi \geqslant \alpha_0$，$f(\xi, 1) = w(\xi)$； (2) 对于每个序数 $\xi \geqslant \alpha_0$ 和每个序数 $\eta > 1$、$f(\xi, \eta) = \sup_{0 < \zeta < \eta} g(f(\xi, \zeta), \xi)$（使用no. 2 的标准 C60）。证明如果 $f_1(\xi, \eta)$ 是另一个项且具有这两个属性，则 $f(\xi, \eta) = f_1(\xi, \eta)$ 对于所有 $\xi \geqslant \alpha_0$ 和所有 $\eta \geqslant 1$。证明，对于每个序数 $\xi \geqslant \alpha_0$，$f(\xi, \eta)$ 是相对于 $\eta$（为所有 $\eta \geqslant 1$ 定义）的正常函数符号。对所有 $\eta \geqslant 1$ 和 $\xi \geqslant \alpha_0$ 显示 $f(\xi, \eta) \geqslant \xi$，对所有 $\xi \geqslant \sup(\alpha_0, 1)$ 和 $\eta \geqslant 1$ 显示 $f(\xi, \eta) \geqslant \eta$。此外，对于每个对$(\alpha, \beta)$这样的序数$\alpha > 0$、$\alpha \geqslant \alpha_0$和$\beta \geqslant w(\alpha)$，都存在一个唯一的序数$\xi$使得

$$f(\alpha, \xi) \leqslant \beta < f(\alpha, \xi + 1),$$

我们有$\xi \leqslant \beta$。

(c) 如果我们取$\alpha_0 = 0$、$w(\xi) = \xi + 1$、$g(\xi, \eta) = \xi + 1$，则$f(\xi, \eta) = \xi + \eta$。如果我们取$\alpha_0 = 1$、$w(\xi) = \xi$、$g(\xi, \eta) = \xi + \eta$，则$f(\xi, \eta) = \xi\eta$。

(d) 证明如果关系$\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta \leqslant \eta'$蕴含$g(\xi, \eta) \leqslant g(\xi', \eta')$，则关系$\alpha_0 \leqslant \xi \leqslant \xi'$、$1 \leqslant \eta \leqslant \eta'$蕴含$f(\xi, \eta) \leqslant f(\xi', \eta')$。如果关系$\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta < \eta'$隐含$g(\xi, \eta) < g(\xi, \eta')$和$g(\xi, \eta) \leqslant g(\xi', \eta)$，则关系$\alpha_0 \leqslant \xi < \xi'$和$\eta \geqslant 0$隐含$f(\xi, \eta + 1) < f(\xi', \eta + 1)$。

(e) 假设$w(\xi) = \xi$和关系$\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta < \eta'$意味着$g(\xi, \eta) < g(\xi, \eta')$和$g(\xi, \eta) \leqslant g(\xi', \eta)$。此外，假设对于每个$\xi \geqslant \alpha_0$，$g(\xi, \eta)$是相对于$\eta$（为$\eta \geqslant \alpha_0$定义）的普通函数符号，并且每当$\xi \geqslant \alpha_0$，$\eta \geqslant \alpha_0$和$\zeta \geqslant \alpha_0$时，我们有结合性关系

$$g(g(\xi, \eta), \zeta) = g(\xi, g(\eta, \zeta)).$$

证明，如果 $\xi \geqslant \alpha_0$、$\eta \geqslant 1$ 和 $\zeta \geqslant 1$，则

$$g(f(\xi, \eta), f(\xi, \zeta)) = f(\xi, \eta + \zeta)$$

（$g$的“分配律”相对于$f$）和

$$f(f(\xi, \eta), \zeta) = f(\xi, \eta\zeta)$$

（$f$的“结合性”）。
