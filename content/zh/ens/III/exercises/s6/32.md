设$(M_n)$、$(P_n)$为不相交的有限集合的两个序列（不全为空），由有理数整数的集合$\mathbf{Z}$索引。设$\alpha_n = \mathrm{Card}\ (M_n)$，$\beta_n = \mathrm{Card}\ (P_n)$。假设存在整数 $k > 0$，对于每个 $n \in \mathbf{Z}$ 和每个整数 $l \geqslant 1$，我们有

$$\alpha_n + \alpha_{n+1} + \cdots + \alpha_{n+l} \leqslant \beta_{n-k} + \beta_{n-k+1} + \cdots + \beta_{n+l+k},$$
$$\beta_n + \beta_{n+1} + \cdots + \beta_{n+l} \leqslant \alpha_{n-k} + \alpha_{n-k+1} + \cdots + \alpha_{n+l+k}.$$

令 M 为家庭 $(M_n)$ 的并，令 P 为家庭 $(P_n)$ 的并。证明 P 上存在 M 的双射 $\varphi$ 使得

$$\varphi(M_n) \subset \bigcup_{i=n-k-1}^{n+k+1} P_i \quad \text{and} \quad \overset{-1}{\varphi}(P_n) \subset \bigcup_{i=n-k-1}^{n+k+1} M_i$$

对于每个$n \in \mathbf{Z}$。 （考虑每个$\mathrm{M}_n$（或$\mathrm{P}_n$）的全序，并取M（或P）作为族$(\mathrm{M}_n)_{n \in \mathbf{Z}}$（或$(\mathrm{P}_n)_{n \in \mathbf{Z}}$）的序数和（§ 1，习题 3）。 如果$n_0$是指标使得$\mathrm{M}_{n_0} \neq \emptyset$，考虑M的同构到P上，其中变换将$\mathrm{M}_{n_0}$的最小元素放入$\bigcup\limits_{j=n_0-k}^{n_0+k} \mathrm{P}_j$的元素之一，并证明其中一个同构满足要求条件。 令 $\delta$ 为数中最小的一个

$$\beta_{n-k} + \beta_{n-k+1} + \cdots + \beta_{n+l+k} - (\alpha_n + \alpha_{n+1} + \cdots + \alpha_{n+l}),$$
$$\alpha_{n-k} + \alpha_{n-k+1} + \cdots + \alpha_{n+l+k} - (\beta_n + \beta_{n+1} + \cdots + \beta_{n+l})$$

对于所有$n \in \mathbf{Z}$和所有$l \geqslant 1$。如果$n \in \mathbf{Z}$和$l \geqslant 1$是这样的，例如，$\beta_{n-k} + \beta_{n-k+1} + \cdots + \beta_{n+l+k} = \delta + \alpha_n + \alpha_{n+1} + \cdots + \alpha_{n+l}$，我们可以取$\varphi$使得$\mathrm{P}_{n-k}$的最小元素是像在$\mathrm{M}_n$的最小元素的$\varphi$之下。）
