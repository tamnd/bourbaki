设$\alpha$为序数$> 0$。如果对于每个序数 $\lambda_0 < \alpha$ 都存在一个序数 $\mu_0 < \alpha$ 使得关系 $\mu_0 \leqslant \xi < \alpha$ 意味着 $\lambda_0 \leqslant f(\xi) < \alpha$ [^1]，则序数 $\alpha$ 的映射 $f$ 被称为“发散”。

(a) 设 $\varphi$ 为 $\beta$ 到 $\alpha$ 的序数严格递增的映射，使得

$$\varphi \left( \sup_{\zeta < \gamma} \zeta \right) = \sup_{\zeta < \gamma} \varphi(\zeta) \quad \text{for all} \quad \gamma < \beta,$$

并且这样

$$\sup_{\zeta < \beta} \varphi(\zeta) = \alpha.$$ [^2]

那么存在$\alpha$的发散映射$f$自身，使得对于所有$\xi$满足$0 < \xi < \alpha$来说$f(\xi) < \xi$，当且仅当存在相同的型的$\beta$自身发散映射。

(b) 从 (a) 推导出，存在 $\omega_\alpha$ 的发散映射 ，使得对于所有 $\xi$ 满足 $0 < \xi < \alpha$ 都有$f(\xi) < \xi$，当且仅当 $\omega_\alpha$ 的最终特征标是 $\omega_0$。 （如果$\omega_\alpha$是常规序数$> \omega_0$，定义归纳严格递增的序列$(\eta_n)$如下：$\eta_1 = 1$，并且$\eta_{n+1}$是最小序数$\zeta$，使得$f(\xi) > \eta_n$对于所有$\xi \geqslant \zeta$。）

(c) 设 $\omega_{\bar{\alpha}}$ 为 $\omega_\alpha$ (习题 16) 的最终特征标。证明，如果 $\bar{\alpha} > 0$ 且 $f$ 是 $\omega_\alpha$ 的映射自身，使得 $f(\xi) < \zeta$ 对于所有 $\xi$ 且 $0 < \xi < \omega_\alpha$，则存在一个序数 $\lambda_0$ 使得方程的解的集合 $f(\xi) = \lambda_0$ 有一个基数$\geqslant \aleph_{\bar{\alpha}}$。


[^1]: If the well-ordered set $O'_\alpha$ of ordinals $\leqslant \alpha$ is endowed with the topology $\mathscr{T}_-(O'_\alpha)$ (*General Topology*, Chapter I, § 2, Exercise 5), this condition may be written $\lim_{\xi \to \alpha, \, \xi < \alpha} f(\xi) = \alpha$.
[^2]: If we extend $\varphi$ to $O'_\beta$ by defining $\varphi(\beta) = \alpha$, the conditions above signify that $\varphi$ is continuous with respect to the topologies $\mathscr{T}_-(O'_\alpha)$ and $\mathscr{T}_-(O'_\beta)$ on $O'_\alpha$ and $O'_\beta$ respectively (*loc. cit.*).
