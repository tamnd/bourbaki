设$\alpha$为序数$> 0$。如果对于每个序数 $\lambda_0 < \alpha$ 都存在一个序数 $\mu_0 < \alpha$ 使得关系 $\mu_0 \leqslant \xi < \alpha$ 蕴含 $\lambda_0 \leqslant f(\xi) < \alpha$ [^1]，则序数 $\alpha$ 的映射 $f$ 被称为“发散”。

(a) 设 $\varphi$ 为序数 $\beta$ 到 $\alpha$ 的严格递增的映射，使得

$$\varphi \left( \sup_{\zeta < \gamma} \zeta \right) = \sup_{\zeta < \gamma} \varphi(\zeta) \quad \text{for all} \quad \gamma < \beta,$$

并且这样

$$\sup_{\zeta < \beta} \varphi(\zeta) = \alpha.$$[^2]

那么存在 $\alpha$ 的发散映射 $f$ 到其自身，使得 $f(\xi) < \xi$ 对于所有 $\xi$ 满足 $0 < \xi < \alpha$，当且仅当存在 $\beta$ 的发散映射到其自身型。

(b) 从 (a) 推导出，存在 $\omega_\alpha$ 的发散映射 ，使得 $f(\xi) < \xi$ 对于所有 $\xi$ 满足 $0 < \xi < \alpha$，当且仅当 $\omega_\alpha$ 的最终特征标是 $\omega_0$。 （如果$\omega_\alpha$是常规序数$> \omega_0$，定义归纳严格递增的序列$(\eta_n)$如下：$\eta_1 = 1$，并且$\eta_{n+1}$是最小序数$\zeta$使得$f(\xi) > \eta_n$为全部$\xi \geqslant \zeta$。）

(c) 令 $\omega_{\bar{\alpha}}$ 为 $\omega_\alpha$ (习题 16) 的最终特征标。证明，如果 $\bar{\alpha} > 0$ 且 $f$ 是 $\omega_\alpha$ 的映射自身，使得 $f(\xi) < \zeta$ 对于所有 $\xi$ 使得 $0 < \xi < \omega_\alpha$，则存在序数 $\lambda_0$ 使得解的集合方程 $f(\xi) = \lambda_0$ 有一个基数 $\geqslant \aleph_{\bar{\alpha}}$。


[^1]: 如果序数$\leqslant \alpha$的良序集$O'_\alpha$被赋予拓扑$\mathscr{T}_-(O'_\alpha)$（*一般拓扑*，章I, § 2，习题5），则条件可以写成$\lim_{\xi \to \alpha, \, \xi < \alpha} f(\xi) = \alpha$。
[^2]: 如果我们通过定义$\varphi(\beta) = \alpha$将扩展$\varphi$到$O'_\beta$，则上面的条件表示$\varphi$相对于$O'_\alpha$上的拓扑$\mathscr{T}_-(O'_\alpha)$和$\mathscr{T}_-(O'_\beta)$是连续的，并且分别$O'_\beta$（*loc.cit.*）。
