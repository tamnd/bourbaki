令 $S$ 为阶 $n$ 的平方矩阵

0 0 $\cdots$ 0 1

0 0 $\cdots$ 1 0

$(\delta_{i,n+1-i}) =$ ... ... . …………

0 1 $\cdots$ 0 0

1 0 $\cdots$ 0 0

$\mathfrak{o}_S(n, k)$ 的元素是矩阵 $(a_{ij})$，它们相对于第二条对角线反对称：

每对 $(i, j)$ $a_{i,j}=-a_{n+1-j,n+1-i}$。

代数 $\mathfrak{o}_S(n, k)$ is splittable simple of 型 $D_{n/2}$ if $n$ is even and $\geq 6$, and of 型 $B_{(n-1)/2}$ if $n$ is odd and $\geq 5$. $\mathfrak{o}_S(n, k)$ 形式分裂 Cartan（或 Borel）子代数的对角线（或上三角）元素。
