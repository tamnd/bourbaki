(a) 设 K = $\mathbf{R}$ 或 $\mathbf{C}$ 或特征为剩余类域 > 0 的超度量域。令 G 为 K 上的李群，U 为 L(G) 中 0 的开邻域，且$\phi : U \to G$ 映射为在 0 处可微，对于 $U$ 中的 $\lambda b,\ \lambda'b,\ (\lambda + \lambda')b$，$\phi(0) = e,\ T_0(\phi) = \mathrm{Id}_{L(G)}$ 和 $\phi((\lambda + \lambda')b) = \phi(\lambda b)\phi(\lambda'b)$。然后 $\phi$ 重合在 0 的邻域上，指数为映射。

(b) 令$k$为特征0的域。令$K$为特征为0的域$k((X))$的值。令$G$为加法李群$k[[X]]$。令$\phi$为$G$到$G$的连续$k$线性映射，使得$\phi(X^n) = X^n + X^{2n}$对于每个整数$n \geqslant 0$。那么 $\phi$ 满足 (a) 的条件，但重合不满足 0 的邻域，且指数为映射。
