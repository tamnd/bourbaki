⁷ 设 $A$ 为集合，$\mathscr{C}$ 子集为 $\mathfrak{P}(A)$。 $\mathscr{C}$的元素称为$A$的室，$C$的室子集$F$称为小平面，$C$中$F$的余维为$C - F$的基数。如果 $F$ 是 $C$ 中的余维 1，则称面 $F$ 是 $C$ 的面板。据说两个房间$C$和$C'$是相邻的

⁷ 习题 15 至 24，以及 § 2 中的习题 3 至 17，迄今尚未发表，由 J. Tits 传达给我们。

如果他们有公共的面板 F：则 C = C' 或 F = C ∩ C'。 长度 n 的画廊是 $n + 1$ 个房间的序列 $\Gamma = (C_0, C_1, \ldots, C_n)$，使得 $C_i$ 和 $C_{i+1}$ 相邻为 $0 \leq i \leq n - 1$。那么$C_0$和$C_n$称为$\Gamma$的两端。如果 $C_i \neq C_{i+1}$ 对于 $0 \leq i \leq n - 1$，则$\Gamma$ 称为单射；如果不存在具有相同端点且长度 < n 的画廊，则称为最小。

如果属于中的每元素至少有一个房间，并且任何两个房间是画廊的末端，则集合 A（与$\mathscr{C}$一起）是一座建筑物。两个房间C和C'之间的距离是一个最小画廊的长度$d(C, C')$，两端为C和C'。

建筑物 A 的子建筑物是 A 的子集 D，使得 D 与 $\mathscr{C} \cap \mathfrak{P}(D)$ 一起构成建筑物。

a) 证明如果 A 是一座建筑物，则每个小室中的一个面具有相同的余维包含；这使我们能够谈论 A 的一个面和一个面板的余维，而无需参考特定的室。建筑物 B 到 A 的态射是从 B 到 A 的映射 $f$，因此 $f$ 到 B 的每个房间 C 的限制是从 C 到 A 的房间 $f(C)$ 双射。 B 的一个面的$f$ 下的像是相同余维的一个面。

b) 如果一栋建筑物的每个面板都恰好包含在两个房间中，则该建筑物称为公寓。证明如果 A 是一间公寓，则 A 的每个自同构（即保留 $\mathscr{C}$ 的 A 的每个置换）使房间的所有点保持固定，这就是恒等式。更一般地，令 $\varphi$ 为 A 的自同态，并令 C 为 A 的一个室，使得 $\varphi(a) = a$ 对于所有 $a \in C$。设$(C, C_1, \ldots, C_n)$是A的一个画廊。证明，要么画廊$(C, \varphi(C_1), \ldots, \varphi(C_n))$不是单射的，要么$\varphi(a) = a$对于$C_i$的所有$a$属于到并。
