令 Σ = (G, B, N, S) 为 Tits 系统。令 T = B ∩ N 并令 Ċ 为 N 的归一化器。

a) 设 b ∈ B ∩ Ċ。证明对于所有 n ∈ N 来说 bnb^{-1}n^{-1} ∈ B ∩ N（将 bn = n'b 并使用 Th.1），并且对于 n ∈ N 来说共轭 nBn^{-1} 的 b 属于到交 Ğ。证明 Ğ ∩ N = T。

如果 Ğ = T，则称 Σ 饱和。

b) 输入 Ċ̃ = N.Ġ̃。证明 Ċ̃ 是 G 包含 Ġ̃ 作为正常子群的子群，且 Ċ̃ ∩ B = Ġ̃。证明从 Σ 的 Weyl 群 W 到 Ċ̃/Ġ̃ ，将 N 的单射转化为 Ċ̃ 定义同构。

c) 证明 (G, B, Ċ̃, j(S)) 是饱和 Tits 系统，据说与 Σ 相关。
