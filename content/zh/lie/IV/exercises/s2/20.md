我们使用no. 2的记号，并假设$k$是可交换的。考虑以下情况：

(B_l) $n = 2l + 1$（与$l \geq 1$），$k$具有特征$\neq 2$，$k^n$配备二次方形式$Q = x_1x_n + \cdots + x_lx_{l+2} + x_{l+1}^2$；
(C_l)$n = 2l$（与$l \geq 1$）和$k^n$配备交错的形式$\Phi$，使得$\Phi(e_i, e_j) = 0$适用于$1 \leq i \leq n, 1 \leq j \leq n$和$i \leq j$，$i \leq l, j = n + 1 - i$时、$\Phi(e_i, e_j) = 1$时除外；
(D_l) $n = 2l$（与$l \geq 2$），$k$具有特征$\neq 2$，$k^n$配备二次方形式$Q = x_1x_n + \cdots + x_lx_{l+1}$。

在情况 (B_l) 和 (D_l) 中用 $G_1$ 表示特殊正交群 $\mathbf{SO}(Q)$，在情况 (C_1) 中用辛群 $\mathbf{Sp}(\Phi)$ 表示。放
$$
B_1 = G_1 \cap B, \quad N_1 = G_1 \cap N \quad \text{and} \quad T_1 = G_1 \cap T = B_1 \cap N_1.
$$

a) 显示$N_1$的作用位于$ke_i$定义同态行的集合上，从$N_1$开始，与核$T_1$，到$\mathfrak{S}_n$的子群$W_1$，让我们可以认同 $W_1$ 和 $N_1/T_1$。证明$W_1$是$\mathfrak{S}_n$的子群，由$1 \leq j < l$的$\sigma_j = s_j s_{n-j}$和情况(B_l)中的$\sigma_l = s_{l-1} s_l s_{l-1}$生成；
$1 \leq j < l$ 的$\sigma_j = s_j s_{n-j}$ 以及情况 (C_l) 中的 $\sigma_l = s_l$；
$1 \leq j < l$ 的$\sigma_j = s_j s_{n-j}$ 以及情况 (D_l) 中的 $\sigma_l = s_{l-1} s_l s_{l-1} s_l s_{l+1} s_l$。

b) 对于$1 \leq j \leq l$，令$S_1$为$\sigma_j$的集合。证明$(G_1, B_1, N_1, S_1)$是山雀系统（证明由$B_1$和$N_1$生成的$G_1$的子群 H是$G_1$的全部，论证如代数，第II, § 10, no. 13章），指出H 包含 $G_1$ 的下三角子群，并且对于任何 $\xi_i \in k$ ($2 \leq i \leq n$)，存在矩阵 $b = (b_{ij}) \in B_1$，使得 $b_{11} = 1, b_{1i} = \xi_i$ 对于 $2 \leq i \leq n-1$ 和 $b_{1n} = \xi_n$ 在情况 (C_l) 中，并且$b_{1n} = 0$ 在情况 (B_l) 和 (D_l) 中。然后如no. 2中那样争论，为$1 \leq j < l$引入子群$G_{1,j} = G_1 \cap (G_j; G_{n-j})$和$G_1$的元素子群$G_{1,l}$保持固定

在情况(B_l)中，由$e_l, e_{l+1}$和$e_{l+2}$生成$i \neq l, l+1, l+2$和子空间的$e_i$；

$i \neq l, l+1$的$e_i$以及情况(C_l)中由$e_l$和$e_{l+1}$生成的平面；
