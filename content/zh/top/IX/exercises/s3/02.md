If $f$ is a left-invariant pseudometric, the real-valued 函数 $g(x) = f(e, x)$ on $G$ ($e$ being 单位元素 of $G$) satisfies the following 条件:

(i) $g(x) > 0$ 对于所有 $x \in G$ 和 $g(e) = 0$；
(ii) $g(x^{-1}) = g(x)$；
（三）$g(xy) \leq g(x) + g(y)$。

Conversely, if $g$ is any real-valued 函数 on $G$ 满足 these 条件, then $f(x, y) = g(x^{-1}y)$ is a left-invariant pseudometric on $G$.
