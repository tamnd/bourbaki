a) 令$\mathfrak{M}$为有限集合，令$R \{ x, y \}$为$\mathfrak{M}$的元素$x, y$之间的对称关系。 假设$\mathfrak{M}$中存在两个不同的元素$a, b$，具有以下属性：存在$x \neq a$和$y \neq b$，使得$x$（或$y$）是唯一使$R \{ a, z \}$（或$R \{ b, z \}$）为真的元素$z \in \mathfrak{M}$；对于除了$a$和$b$之外的每个$t \in \mathfrak{M}$，使得$R \{ t, z \}$为真的所有$z \in \mathfrak{M}$的集合是由两个元素组成的集合，与$t$不同。 证明在这些条件下，存在$\mathbf{N}$的区间$[0, n]$到$\mathfrak{M}$的双射$i \to x_i$，使得$x_0 = a, x_n = b$且$R \{ x_{i-1}, x_i \}$对于$1 \leq i \leq n$成立（通过对$i$的归纳来定义$x_i$）。

b) 在$\mathbf{R}^n$($n \geq 2$)中，以$\mathbf{R}^{n-1} \times \mathbf{R}$为标识，令$L$和$L'$为两条折线，分别由两个序列、$(x_i)_{0 \leq i \leq p}$和$(x'_j)_{0 \leq j \leq q}$定义，具有以下性质： (i) 如果我们放入$x_i = (y_i, z_i)$、$x'_j = (y'_j, z'_j)$，我们有$z_0 = z'_0 = 0, z_p = z'_q = 1, 0 < z_i < 1$对应$1 \leq i \leq p - 1$，$0 < z'_j < 1$对应$1 \leq j \leq q - 1$； (ii) $p + q - 2$ 数 $z_i, z'_j$ ($1 \leq i \leq p - 1, 1 \leq j \leq q - 1$) 都是不同的； (iii) $L$（或$L'$）的两个不同边在公共的中最多有一个点 [可能是也可能不是$x_i$（或$x'_j$）之一]。证明存在两个分段满射线性映射 (习题 6) $u : I \to L, u' : I \to L'$，其中$I$是$\mathbf{R}$的区间$[0, 1]$，这样，如果我们把$u(t) = (v(t), \zeta(t))$，$u'(t) = (v'(t), \zeta'(t))$ ($t \in I$)，我们为所有 $t \in I$ 提供了 $\zeta(t) = \zeta'(t)$，

$$
\zeta(0) = \zeta'(0) = 0 \quad \text{and} \quad \zeta(1) = \zeta'(1) = 1.
$$

[令$(a_k)_{1 \leq k \leq p+q-2}$为除0和1之外的$z_i$和$z'_j$组成的严格递增的序列，并放入$a_0 = 0, a_{p+q-1} = 1$；让$B_i$表示所有$x = (y, z) \in \mathbf{R}^n$中的集合，这样

$$
a_{i-1} \leq z \leq a_i \quad (1 \leq i \leq p + q - 1);
$$

让$\mathfrak{M}$表示所有对$\gamma = (C, C')$的集合，其中$C$（分别$C'$）是同一个$B_i$的交，边为$L$（分别$L'$），这样既不$C$ 也不是 $C'$ 由单个点组成；令$R \{ \alpha, \beta \}$表示$\mathfrak{M}$的元素$\alpha, \beta$之间的以下关系：“$\alpha \neq \beta$；如果$\alpha = (C_1, C'_1), \beta = (C_2, C'_2)$，则$C_1 \cap C_2$和$C'_1 \cap C'_2$不为空，其中一个由单个点组成，如果这个点不是$x_i$（或$x'_j$）之一，则$C_1$和$C_2$（或$C'_1$和$C'_2$）都包含在$L$（或$L'$）的同一侧”。证明a)适用于关系$R.$]

c) 在$\mathbf{R}^n$中，用$\mathbf{R}^{n-1} \times \mathbf{R}$标识，令$K$为连接的紧集，使得$K \cap (\mathbf{R}^{n-1} \times \{0\})$包含至少有两个不同的点。证明如果 $K' = K - K$（所有 $x - y$ 中的集合，其中 $x \in K$ 和 $y \in K$），则 $K' \cap (\mathbf{R}^{n-1} \times \{0\})$ 包含是一个相连的集合，它不由单个点组成。 [使用 b)、应用章 II、、命题 6 和习题 15。]
