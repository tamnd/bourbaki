令$H$和$K$是$\mathbf{R}^n$的两个闭子群，使得$H + K$是闭子群。

a) 证明，如果$V$（或$W$）是最大的向量子空间包含在$H$（或$K$）中，则$V + W$ 是最大的向量子空间在$G$中，因而$d(H) + d(K) = d(H \cap K) + d(H + K)$[注意$G/(V + W)$的有理秩是有限的，因而$G$不能包含不包含在$V + W$中]。

b) 令$U$为与$V + W$互补的子空间，使得$G$是$V + W$和$M = G \cap U$的直和，并且$H \cap K$是$(V + W) \cap (H \cap K)$和$L = H \cap K \cap U$的直和（练习5）。 令$H'$（或$K'$）为$M$的子群，由$H$（或$K$）的点分量组成，将$G$分解为$V + W$和$M$的直和。 显示 $M = H' + K'$ 和 $H' \cap K' = L$。

c) 如果我们放入$H'' = H \cap (V + W)$和$K'' = K \cap (V + W)$，则证明$r(H'') + r(K'') = r(H'' \cap K'') + r(H'' + K'')$（对于$V \cap W = \{ o \}$的情况，约化，并证明$H'' \cap K''$是$V \cap K''$和$W \cap H''$的直和。

d) 表明
$$
r(H) + r(K) = r(H \cap K) + r(H + K)
$$
[使用c)和习题4，注意$r(H) = r(H') + r(H'')$和$r(K) = r(K') + r(K'')$]。
