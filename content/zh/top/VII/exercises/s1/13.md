阶 $n$ ($n$ 整数 > o) 的 *Farey 级数* 是有理数数 $p/q$ 的集合 $F_n$ 在其最低项中，使得 $0 \leq p \leq q \leq n$ 排列在递增阶（即 Farey 级数是 *序列*）。

a) 证明如果两个有理数数 $r = p/q, r' = p'/q'$ 满足$p'q - pq' = \pm 1$，则整数 $(p'', q'')$ 的每个对都可以用形式 $p'' = px + p'y, q'' = qx + q'y$ 表示，其中$x$ 和$y$ 为整数。分数 $p''/q''$ 属于到端点为 $r$ 和 $r'$ 的闭区间当且仅当 $x$ 和 $y$ 具有相同的符号。

b) 从a)推导出，如果$r = p/q$和$r' = p'/q'$是$[0, 1]$中的两个有理数数，使得$q > 0$、$q' > 0$和$qp' - pq' = \pm 1$，则$r$和$r'$在元素中是连续的序列$F_n$，其中$n = \max(q, q')$。此外，最小的整数$m$使得$F_m$的端点为$r$和$r'$包含点的开区间为$m = q + q'$，并且只有一个点该区间内的$F_{q+q'}$，即分数$(p + p')/(q + q')$。

c) 相反，如果$r$和$r'$是$F_n$的两个连续的元素，我们就有$p'q - pq' = \pm 1$（使用归纳法在$n$上）。

d) 从 c) 中推出，对于每个实数 $\theta \in [0, 1]$ 和每个整数 $n \geq 1$，在其最低的项中至少存在一个分数 $p/q$，使得 $1 \leq q \leq n$ 和 $|\theta - p/q| \leq 1/(n + 1)q$ (cf.) 习题10)。

e) 如果 $p/q$ 是其最低项中的一个分数，使得 $|\theta - p/q| < 1/q^2$，则 $\theta$ 属于到开区间，其端点是与 $p/q$ 连续的 Farey 级数 $F_q$ 的两个项。
