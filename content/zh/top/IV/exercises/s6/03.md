a) 对于每个区间 $I \subset \mathbf{R}$，令 $G(I)$ 表示 $I$ 自身同胚的群。证明如果$I$和$J$是$\mathbf{R}$中的任意两个区间，每个包含多于一个点，则$G(I)$和$G(J)$同构的。在$G(I)$中，递增同胚的集合$F(I)$是指标2的正规子群。

b) 设 $G = G(\mathbf{R})$ 和 $F = F(\mathbf{R})$。对于每个$f \in G$和每个$x \in \mathbf{R}$，让$\sigma(x; f)$表示$\operatorname{sgn}(f(x) - x)$。令 $T^+$（分别为 $T^-$）为所有 $f \in F$ 的集合，使得 $\sigma(x; f)$ 是常数，并且在 $\mathbf{R}$ 上等于 1（分别为 $-1$）。证明$T^+$（或$T^-$）的每个元素在$F$到翻译$x \to x + 1$（或$x \to x - 1$）中都是共轭。 [如果$f \in T^+$，则考虑点$f^n(o), n \in \mathbf{Z}$中的序列]。

c) 令$T = T^+ \cup T^-$。表示$T_*$的两个元素中的$F$中不存在属于到$T$的每个$f \in F$为乘积。 [将$f = f_1 f_2$写入$F$，其中$f_1(x) = \sup (x, f(x))$和$f_2(x) = \inf (x, f(x))$；如果$g$是$x \to x + 1$的翻译，那么$f_1 g$和$g^{-1} f_2$属于到$T$]。

d) 两个元素$f, g$在$F$中是共轭当且仅当存在$s \in F$使得$\sigma(x; f) = \sigma(s(x); g)$对于所有$x \in \mathbf{R}$。 [考虑所有$x$的开集合中的分量$I_n$使得$\sigma(x; f) \neq 0$；观察$F(I_n)$和$F$同构的（$a$）并使用$b$]。特别地，如果$[a, b]$是$\mathbf{R}$的区间，使得$\sigma(a; f) = \sigma(b; f) = 0$对于某些f \in F，则$F$的元素$f'$，其中重合与$f$对于$x \leq a$或$x \geq b$，并且$a < x < b$的$f'(x) = x + \varepsilon(f(x) - x)$，其中$0 < \varepsilon < 1$，是$F$中的共轭到$f$。

e) 令$f \in F$和$a, b, c, d$为四个实数，使得$a < c < b < d$和$f(x) - x = 0$代表$x = a, x = b, x = c, x = d$，$\sigma(x; f) = 1$代表$a < x < c$和$b < x < d$。令$a', b'$为两个数，使得$a \leq a' < c$和$b < b' \leq d$；令$J = [a, b], J' = [a', b']$，令$f_1$表示$f$至$J$中的限制；因此$f_1 \in F(J)$。证明$J$在$J'$上存在递增同胚$s$，使得$F(J')$的元素$f_2 = s f_1 s^{-1}$使得每当$a' < x < b'$时$f_2(x) > f^{-1}(x)$[使用$d$]。

f) 设$f \in F$且$[a, b]$为$\mathbf{R}$的区间，使得$x = a$和$x = b$为$f(x) - x = 0$，$x < a$为$\sigma(x; f) = -1$，$x > b$为$\sigma(x; f) = +1$。证明$F$中存在$g \in F$、共轭到$f$，使得$g(x) > f(x)$适用于所有$x \in \mathbf{R}$（同样的方法）。

g) 让$H^+$（或$H^-$）表示所有$f \in F$的$F$由……组成的正常子群，使得$f(x) = x$位于$+\infty$（或$-\infty$）的邻域中。证明$H^+, H^-$和$H = H^+ \cap H^-$是$F$除了$F$和$\{e\}$之外的唯一正规子群。 [如果$N$是$F$的正常子群，而不是$F$，并且如果$f \in N$不是属于到$H^+$，则表明存在元素$g \in N$使得所有集合 $x \in \mathbf{R}$，其中$\sigma(x; g) = +1$是区间$]a, +\infty]$，并且我们有$g(x) = x$对应$x \leq a$。为此，请使用 e) 和 f) 以及 b) 和 c) 的构造。为了表明$N$包含没有子群，除了$H$和$\{e\}$（在$F$中正常），请考虑元素$f \in H$与$e$不同；令$a$和$b$为下确界且$x \in \mathbf{R}$的集合中的至少上界（均由假设有限），使得$\sigma(x; f) \neq 0$。然后观察$F([a, b])$与$F$同构并使用前面的结果]。

h) 证明群 $H$ 是简单的。 （与方法与证明相同，$H$包含在$F$中没有不平凡的子群正常）。
