令$(u_n)$为有限实数的序列，使得其一般项为$u_n$的级数是收敛的，但不是绝对收敛的。证明存在 $\mathbf{N}$ 满足条件章 III, § 5、习题 6 a) 的置换 $\sigma$，但不存在级数，其通项为$u_{\sigma^{-1}(n)}$收敛。 [令$h, k, m$为三个整数，具有以下属性：如果$p_1, \ldots, p_r$是整数$n$，使得$h \leq n < h + m$和$u_n \geq 0$，则$u_{p_1} + \cdots + u_{p_r} > 2$和$h + m < k - r$；此外，如果$\mu, \nu$是任何整数使得$h + m \leq \mu \leq \nu$，则$\left| \sum_{n=\mu}^{\nu} u_n \right| \leq 1$。放置$s = m - r$并让$q_1, \ldots, q_s$表示整数$n$，使得$h \leq n < h + m$和$u_n < 0$。考虑$\mathbf{N}$的区间$[h, k + s]$的置换$\pi$，使得$\pi(p_i) = k - i + 1$为$1 \leq i \leq r$，$\pi(q_j) = k + j$为$1 \leq j \leq s$，$\pi(k + j) = h + s - j$为$1 \leq j \leq s$，$\pi(k - i + 1) = h + s + i - 1$为$1 \leq i \leq r$，最后$\pi(n) = n$，$h + m \leq n \leq k - r$；表明我们有
$$
\left| \sum_{i=h}^k u_i - \sum_{i=h}^k u_{\pi^{-1}(i)} \right| \geq 1.
$$
