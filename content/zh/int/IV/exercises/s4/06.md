a) 令 $f$ 为数值函数，使得 $\mu^*(f)$ (Exer. 5) 是有限的。证明存在可积函数 $f_1 \geq f$ 使得 $\mu(f_1) = \mu^*(f)$；如果$f_2$是第二个可积函数，使得$f_2 \geq f$和$\mu(f_2) = \mu^*(f)$，则$f_1$和$f_2$是等价的。

b) 对于数值函数 $f$ 可积，$\mu^*(f)$ 和 $\mu_*(f)$ 有限且相等是必要且充分的。

c) 令$f$为数值函数，使得$\mu^*(f)$和$\mu_*(f)$都是有限的；令$g$和$h$是两个可积函数，使得$g \leq f \leq h$和$\mu(g) = \mu_*(f)$、$\mu(h) = \mu^*(f)$。表明

$$
\mu_*(f - g) = \mu_*(h - f) = 0 \quad \text{and} \quad \mu^*(f - g) = \mu^*(h - f) = \mu^*(f) - \mu_*(f).
$$

d) 令$f_1, f_2$为两个数值函数，使得数、$\mu^*(f_1), \mu^*(f_2), \mu_*(f_1)$和$\mu_*(f_2)$都是有限的；表明

$$
\mu_*(f_1 + f_2) \leq \mu_*(f_1) + \mu_*(f_2) \leq \mu^*(f_1 + f_2)
$$

（如果 $g_2$ 是可积函数，使得 $f_2 \leq g_2$ 和 $\mu^*(f_2) = \mu(g_2)$，请注意，对于每个可积函数 $h$，使得 $h \leq f_1 + f_2$，都有 $h - g_2 \leq f_1$）。由此推论，如果 $f_1$ 可积，则

$$
\mu^*(f_1 + f_2) = \mu(f_1) + \mu^*(f_2), \quad \mu_*(f_1 + f_2) = \mu(f_1) + \mu_*(f_2),
$$

和$\mu^*(f_1 + f_2) = \mu^*(\sup(f_1, f_2)) + \mu^*(\inf(f_1, f_2))$（对于后者关系，请使用§1的Exer.1）。

e) 设$f$为可积函数。在阶中，函数$g$，使得$\mu^*(g)$是有限的，可积的，$\mu(f) = \mu^*(g) + \mu^*(f - g)$是充分必要的（如果$g_1$是可积函数使得$g \leq g_1$和$\mu^*(g) = \mu(g_1)$，请注意$f - g_1 \leq f - g$）。
