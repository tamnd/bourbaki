令 $G$ 为局部紧致阿贝尔的群，可加写，$\mu$ $G$ 上的 Haar 测度，$A, B$ $G$ 的两个可积子集。

⁴从第二版开始被抑制，引理断言，如果$f, g$是数值函数$\geq 0$且$g$可测量，则$\int^* fg d\mu = \inf \int^* \varphi g d\mu$作为$\varphi$运行超过可测量的函数的集合 $\geq f$。

a) 对于每个$s \in G$，让

$$
A' = \sigma_s(A, B) = A \cup (B + s), \quad B' = \tau_s(A, B) = (A - s) \cap B.
$$

证明 $\mu(A') + \mu(B') = \mu(A) + \mu(B)$ 和 $A' + B' \subset A + B$。

b) 假设 0 属于到 $A \cap B$。如果存在$G$的元素的序列$(s_k)_{1 \leq k \leq n}$和两个序列，则$G$的可积子集的对$(A', B')$被认为是从$(A, B)$“派生”的$(A_k)_{0 \leq k \leq n}, (B_k)_{0 \leq k \leq n}$/子集/$G$，使得$A_0 = A, B_0 = B, A_k = \sigma_{s_k}(A_{k-1}, B_{k-1}), B_k = \tau_{s_k}(A_{k-1}, B_{k-1})$对于$1 \leq k \leq n, s_k \in A_{k-1}$对于$1 \leq k \leq n$，以及$A' = A_n, B' = B_n$。证明存在对 $(E_n, F_n)$ 的序列，使得$E_0 = A, F_0 = B, (E_{n+1}, F_{n+1})$源自$(E_n, F_n)$，并且对于每个$n$和每个$s \in E_n$都存在$\mu((E_n - s) \cap F_n) \geq \mu(F_{n+1}) - 2^{-n}$。 集合$E_\infty = \bigcup_n E_n, F_\infty = \bigcap_n F_n$。证明对于每个 $s \in E_\infty$，

$$
\mu((E_\infty - s) \cap F_\infty) = \mu(F_\infty).
$$

c) 假设$\mu(F_\infty) > 0$。显示函数

$$
f(s) = \mu((E_\infty - s) \cap F_\infty)
$$

只能取值 0 和 $\mu(F_\infty)$，并且 $s \in G$ 的集合 $C$ 使得 $f(s) = \mu(F_\infty)$ 是 *开* 和 *闭*，使得 $\mu(C) = \mu(E_\infty)$ 是 $E_\infty$ 的闭包（使用 Exer.20 a）并且b））。另一方面，令$D$为$s \in F_\infty$的集合，使得$F_\infty$的交与$s$的每个邻域都有测度$> 0$。显示 $\mu(D) = \mu(F_\infty)$ 以及

$$
E_\infty + D \subset C;
$$

由此推断$D$包含在Exer中定义的子群$H(C)$中。 22，并且$H(C)$是紧凑的，而$G$是开放的。最后，证明$C + H(C) = C$、$\mu(C) \geq \mu(A) + \mu(B) - \mu(H(C))$和$C \subset A + B$（考虑每个$c \in C$的$E_\infty \cap (c - F_\infty)$度量）。

d) 从 c) 推出，对于 $G$ 的两个可积子集 $A, B$：*任一* $\mu_*(A + B) \geq \mu(A) + \mu(B)$； *否则*存在$G$的紧开子群$H$，使得$A + B$包含是$H$的陪集，在这种情况下是$\mu_*(A + B) \geq \mu(A) + \mu(B) - \mu(H)$。 $G$相连的情况。
