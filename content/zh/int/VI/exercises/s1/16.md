令 $F$ 为 Banach 空间，$F'$ 为其对偶。 对于每个$p$，使得$1 \leq p \leq +\infty$，用$\Lambda_{F'}^p(T, \mu)$（或简单地用$\Lambda_{F'}^p$）表示映射的集合，$T$的$f$到$F'$，这样，对于每个$z \in F$，数值函数 $\langle z, f \rangle$属于至$L^p(T, \mu)$。 一个具有$\Lambda_{F'}^p \supset L_{F'}^p$，并且$\Lambda_{F'}^1$是$\mu$的标量可积函数的空间，其中值位于$F'$（$F'$配备有$\sigma(F', F)$）。 可知，用$L^p(\mu)$中$\langle z, f \rangle$的$\theta(z)$类表示，映射$z \mapsto \theta(z)$是连续的（No. 4，引理2）；令$M_p(f)$为其范数；这是空间$\Lambda_{F'}^p$的半范数。 在阶和 $M_p(f) = 0$ 中，$f$ 局部标量可忽略不计是必要且充分的。

a) 在阶和 $f \in \Lambda_{F'}^p$ 中，对于每个数值函数 $g \in L^q$，函数 $gf$ 本质上$\mu$ 是标量可积的；那么就有$M_1(gf) \leq M_p(f) N_q(g)$。

b) 在空间$\Lambda_{F'}^1$中，证明半范数$M_1$等价于半范数$M'_1(f) = \sup |\int_A f d\mu|$，其中$A$超过了$T$的可测子集的集合；更准确地说，$M'_1 \leq M_1 \leq 2M'_1$。由此推论$M_p$是等价于$M'_p(f) = \sup_{N_q(g) \leq 1} M'_1(gf)$的半范数。

c) 将 $F$ 视为具有可数正交标准基的希尔伯特空间，并将 $\mu$ 视为$T = [0, 1]$ 上的勒贝格测度。证明$T$的映射存在于$F$中，不可积但可标量可积，即可测步长函数的序列的半范数$M_1$为极限（cf.Exer.11）；由此推论，在$\mu$可积函数的空间$L_{F'}^1$上，半范数$M_1$定义的拓扑严格比$N_1$定义的更粗糙。对于半范数 $M_p$ 和 $N_p$，对于 $1 \leq p < +\infty$ 也有类似的结果。

d) 在空间 $L_{F'}^\infty$、$M_\infty = N_\infty$ 上证明。

e) 取$F$一个希尔伯特空间，其具有可数正交基，排列在双序列$(e_{mn})$中。令 $\mu$ 为$T = [0, 1]$ 上的勒贝格测度。令$u_m$为$T$到$F$的映射，使得$u_m(t) = e_{mn}$对于$(n-1)2^{-m} \leq t < n2^{-m}$和$1 \leq n \leq 2^m$，以及$u_m(1) = 0$； 集合$f_n = \sum_{i=0}^n u_i$。证明，对于$1 \leq p < +\infty$，$(f_n)$是$\Lambda_{F'}^p$中的柯西序列，但不收敛于$\Lambda_{F'}^p$中的任何函数。

f) 设$(f_n)$为空间$\Lambda_{F'}^p$($1 \leq p \leq +\infty$)中的柯西序列；假设$T$中存在映射$f$进入$F'$，使得对于每个$z \in F$，函数$\langle z, f_n \rangle$中的序列收敛到$\langle z, f \rangle$（第IV, §5, No. 11）。证明 $f \in \Lambda_{F'}^p$ 和序列 $(f_n)$ 在 $\Lambda_{F'}^p$ 中有极限 $f$。

g) 取$F$绝对收敛级数的Banach空间$L^1(\mathbf{N})$；它的对偶是$F' = L^\infty(\mathbf{N})$（TVS，IV, §1，Exer.1）。令 $\mu$ 为$T = [0, 1]$ 的勒贝格测度。令$f$为$T$的映射进入$F'$，使得$f(0) = 0$，并且对于$2^{-n-1} < t \leq 2^{-n}$，$f(t)$为序列，其所有项均为零，项除外指标 $n$，等于 $2^n/p$ $1 \leq p < +\infty$。证明$f$对于$F'$上的强拓扑是可测的，并且属于到$\Lambda_{F'}^p$是可测的，但是不存在任何步骤函数的序列$(f_n)$趋向于$f$ 空间$\Lambda_{F'}^p$。
