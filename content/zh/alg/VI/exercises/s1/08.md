令 x 为有序群的元素，从而定义 y = inf(x, 0)；如果 n > 0 是整数，那么 nx ≥ 0 意味着 x ≥ 0 （我们有

$$
ny = \inf(nx, (n-1)x, ..., 0) \geq \inf((n-1)x, ..., 0) = (n-1)y;
$$

因此 nx = 0 意味着 x = 0。
