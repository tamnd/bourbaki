设$(a_i)_{i \leq n}$为$n$元素或有序域K的有限序列，不全为零；令 $(a_{i_k})_{k \leq p}$ 为非零的 $a_i$ ($i_1 < i_2 < \ldots < i_p$) 的$(a_i)$ 由……组成的子序列；那么指标$k \leq p - 1$的数使得$a_{i_k}$和$a_{i_{k-1}}$具有相反的符号，称为序列$(a_i)$的变体*数*。
设K为极大有序域，$f$为非零的在次数$n > 0$的$K[T]$中的多项式；对于所有$a \in K$，让$w(a)$表示数的变体序列$(f''(a))_{i \leq n}$。若$v$是$f$的根数，以重数计数，在区间]$a, b$(a < b)中，证明$v \leq w(a) - w(b)$与$w(a) - w(b) - v$是偶数（《Budan-Fourier规则》； 分裂的区间]$a, b$除以$f$的根，并评估当$x$通过其中一个根时$w(x)$的变化量）。
推论如果$f(T) = a_0 + a_1 T + \ldots + a_n T^n$，则$f$的根$> 0$的数，与重数一起计算，至多等于序列$(a_i)_{0 \leq i \leq n}$变体的数，且两者之差数是偶数（“笛卡尔规则”）。
