我们用$\mathbf{Q}[[X, T]]$的$(1 + X)^T$元素$\exp(T \log (1 + X))$来表示。
a) 证明$(1 + X)^T = \sum_{n \geq 0} \frac{T(T-1) \ldots (T-n+1)}{n!} X^n$。 （$X^n$的系数是$T$中的多项式，其值已知为$T = n \in N.$）
b) 显示$(1 + X)^l (1 + X)^T = (1 + X)^{T+l}$。明确写下如此获得的二项式系数之间的恒等式。显示$(1 + X + Y + XY)^T = (1 + X)^T (1 + Y)^T$。
