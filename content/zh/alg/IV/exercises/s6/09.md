a) 令 K 为域且 $X_1, \ldots, X_n$ 不确定。证明对于任何指数 $v_1 < v_2 < \ldots < v_n$，行列式 $\det(X_i^{v_j})$ 在 $K(X_1, \ldots, X_n)$ 中都不为零。

b) 令$s_k$ ($1 \leq k \leq n$) 为域 $K(X_1, \ldots, X_n)$ 的$X_i$ 和$r_1, \ldots, r_n$ n 元素中的初等对称多项式。我们（用一个新的不确定 T）

$$
R(T) = \frac{1 + r_1 T + \cdots + r_n T^n}{1 + s_1 T + \cdots + s_n T^n} = 1 + u_1 T + \cdots + u_k T^k + \cdots.
$$

证明如果系数 $u_k$ 中的 $n$ 为零，则所有 $u_k$ 均为零。 （将$R(T)$分解为简单的分数。）

*c) 假设 K 为特征零。令$\{v_1, v_2, \ldots, v_n\}$为$\mathbf{N}$的n元素$\geq 1$的集合，并令M为$\mathbf{N}$中这个集合的补集；还假设 M 在加法下稳定。证明如果 $y_1, \ldots, y_n$ 是 $K(X_1, \ldots, X_n)$ 的 n 元素使得

$$
P_{v_j}(y_1, \ldots, y_n) = P_{v_j}(X_1, \ldots, X_n)
$$

对于 $1 \leq j \leq n$，则 $y_j = X_j$ 对于 $1 \leq j \leq n$，可能除了置换。 （考虑$\log R(T) = v_1 T + v_2 T^2 + \cdots + v_k T^k + \cdots$中的展开，观察$v_{v_j} = 0$对应$1 \leq j \leq n$，并检查$v_k$和$u_k$之间的关系。）
