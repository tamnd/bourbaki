设$K$为有限域，其中$q$元素。
a) 在环$K[X_1, X_2, \ldots, X_n]$中，令$a$为由$n$多项式生成的理想值

X_i^q - X_i \quad (1 \leq i \leq n)。证明如果$f \in a$，则$f(x_1, x_2, ..., x_n) = 0$对于所有$(x_i) \in K''$（观察乘法群$K^*$等于阶$q - 1$）。
b) 如果 $f$ 是 $K[X_1, X_2, ..., X_n]$ 的任意多项式，则表明精确存在一个多项式 $\overline{f}$，使得 $\deg, \overline{f} \leq q - 1$ 对于 $1 \leq i \leq n$ 且使得 $f \equiv \overline{f} \pmod{a}$。因此我们有 $\deg \overline{f} \leq \deg f$；如果$f$使得$f(x_1, x_2, ..., x_n) = 0$对于每个$(x_i) \in K''$、$f$属于到理想的$a$，因此在同态$f \mapsto \overline{f}$下逆像为0（使用习题1）。
c) 令$f_1, f_2, ..., f_m$为$K[X_1, X_2, ..., X_n]$的非零多项式，使得$f_i$的总次数中的$f_i(0, 0, ..., 0) = 0$ ($1 \leq i \leq m$) 和和 < $n$。证明存在元素 $(x_1, x_2, ..., x_n) \in K''$ 与 $(0, 0, ..., 0)$ 不同，使得
$$
f_i(x_1, x_2, ..., x_n) = 0 \quad \text{for} \quad 1 \leq i \leq m .
$$
（请注意，如果不是这样，则多项式 $\prod_{i=1}^m (1 - f_i^{q-1})$ 将与多项式 $\prod_{i=1}^n (1 - X_i^{q-1})$ 模 $a$ 全等。并使用 b)）。
