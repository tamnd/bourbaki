如果 A 的每个元素都是幂等的，则环 A 被称为布尔值环（在其他字中，如果 $x^2 = x$ 对于所有 $x \in A$）。
(a) 在集合 E 的子集集合 $\mathscr{P}(E)$ 中，表明布尔值环结构由设定 $AB = A \cap B$ 和$A + B = (A \cap \complement B) \cup (B \cap \complement A)$ 定义。这个环与E的映射的环$K^E$同构为整数模2的环$K = \mathbf{Z}/(2)$（考虑每个子集$X \subset E$其“特征函数” $\phi_X$，使得$\phi_X(x) = 1$（如果$x \in X$），$\phi_X(x) = 0$（如果$x \notin X$）。
(b) 每个布尔值环 A 都是可交换的，因此 $x + x = 0$ 对应 $x \in A$（将 $x + x$ 写为幂等，然后将 $x + y$ 写为幂等）。
(c) 如果布尔值环包含没有 0 的除子，则它减少为 0 或同构于 $\mathbf{Z}/(2)$（如果 $x$ 和 $y$ 是 A 的任意两个元素，则表明 $xy(x + y) = 0$）。推断出布尔值环中的每个素理想都是最大的。
(d) 在布尔环 A 中，每个理想 $a \neq A$ 都是素理想包含 a 的交（应用习题 7(c)）。推断每个不可约理想都是极大的（在其他字中，不可约理想、素理想和布尔值环中的极大理想重合的概念）。

(e) 证明每个布尔值环都同构于乘积环 $K^E$ 的子环，其中 $K = \mathbf{Z}/(2)$（使用 (d)）。

(f) 如果 $p_i$ ($1 \leq i \leq n$) 是布尔值环 $A$ 和 $a = \bigcap_{1 \leq i \leq n} p_i$ 中的 $n$ 不同最大理想，则证明商环 $A/a$ 同构于乘积环 $K^n$。推断每个有限布尔值环都是形式 $K^n$。

(g) 在布尔值环 $A$ 中，关系 $xy = x$ 为序关系；如果用$x \leq y$表示，则表明关系$A$是一个分配格（集合理论，III, § 1，习题16），具有至少元素$\alpha$并且对于每个有序对元素的$(x, y)$使得$x \leq y$，存在元素$d(x, y)$使得$\inf(x, d(x, y)) = \alpha$，$\sup(x, d(x, y)) = y$。相反，如果有序集合 $A$ 具有这三个属性，则显示合成 $xy = \inf(x, y)$ 和 $x + y = d(\sup(x, y), \inf(x, y))$ 定义的律 $A$ 上的布尔值环结构。
