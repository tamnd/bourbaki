With the same hypotheses as in 习题 7, let $x \top y = xy + yx$;那么律 $\top$ 相对于加法是可交换的和双重分配的，但不是一般结合律。

(a) 对于所有$x \in E$，证明$\top^{m+n} x = \left( \top^m x \right) \top \left( \top^n x \right)$。

(b) If we write $[x, y, z] = (x \top y) \top z - x \top (y \top z)$ (deviation from 结合性 of 律 $\top$), prove the identities

$$
[x, y, z] + [z, y, x] = 0
$$

$$
[x, y, z] + [y, z, x] + [z, x, y] = 0
$$
$$
[x \top y, u, z] = [u, [(x \top y), z)]]
$$
(记号 $[x, y]$ meaning the same as in 习题 7)
$$
[x \top y, u, z] + [y \top z, u, x] + [z \top x, u, y] = 0.
$$
