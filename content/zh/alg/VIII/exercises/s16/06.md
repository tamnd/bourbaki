令L为交换域K的有限伽罗瓦扩张，伽罗瓦群G。令V和$V'$为K-向量空间和$w$（分别为$w'$）张量为型 $(p, q)$ 于V（或$V'$）。从$(V, w)$到$(V', w')$的L同构是L线性同构$u: V_{(L)}\rightarrow V'_{(L)}$，使得$u^{\otimes p}\otimes (^tu^{-1})^{\otimes q}$将$w$的像发送到$w'$。我们用L的Aut$_L(V, w)$群表示$(V, w)$的自同构，G通过$^{\sigma}\varphi = (1_V\otimes \sigma )\circ \varphi \circ (1_V\otimes \sigma )^{-1}$作用于它。

a) 令$u$为G从$(V, w)$到$(V', w')$和$\sigma$元素的L同构； 映射 $^{\sigma}u= (1_{V'}\otimes \sigma )\circ u\circ (1_V\otimes \sigma )^{-1}$ 是从 $(V, w)$ 到 $(V', w')$ 的 L 同构的，因此 $c(\sigma ) =u^{-1}\circ^{\sigma}u$ 是 Aut$_L(V, w)$ 的元素。证明映射 $c: G\rightarrow$ Aut$_L(V, w)$ 属于到 $Z^1(G$、Aut$_L(V, w))$ 并且$H^1(G$、Aut$_L(V, w))$ 中的类 $\theta (V', w')$ 不依赖于选择 $u$。

b) 证明映射$(V', t')\mapsto \theta (V', t')$定义双射从对$(V', w')$L的K-同构类集合同构到$(V, w)$到集合 $H^1(G$，自动$_L(V, w))$。 （给定 $Z^1(G$ 的元素 $c$，Aut$_L(V, w)$），从习题 5，d) 推导出 $V_{(L)}$ 的 L 自同构 $f$，使得 $c(\sigma ) =f^{-1}\circ^{\sigma}f$。证明从$f$推导出自同构对$w$的像$w'$在K上是有理数，并考虑对$(V, w').)$

$*$c) 例：集合 $H^1(G,\mathbf{S}\mathbf{p}_{2n}(L))$ 减少为 1 元素。如果 Q 是 K 上的二次方形式，则集合 $H^1(G,\mathbf{O}(Q_{(L)}))$ 可以用 K 上的二次方形式的等价类的集合等同于 Q 上的 $L.*$

d) 令A为L-代数$A_{(L)}$的K-代数和M自同构群，赋予上面定义的G的作用。 The construction in b) defines a bijection from the set of isomorphism classes of pairs $(B, u)$, where B is a K-algebra and $u$ is an isomorphism from $B_{(L)}$ to $A_{(L)}$, to the set $Z^1(G,M)$. 每$\sigma \in G$，逆双射将$Z^1(G,M)$的元素$c$发送到元素$a$满足$c(\sigma )(\sigma (a)) =a$$A_{(L)}$由……组成K-子代数。
