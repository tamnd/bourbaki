令$\varphi : H\rightarrow G$为群同态，M为$\mathbf{Z}$[G]-模，N为$\mathbf{Z}$[H]-模，以及阿贝尔的群的$u: M\rightarrow N$同态。如果对于每个$h\in H$和$x\in M$都有$u(\varphi (h)x) =hu(x)$，我们就说$\varphi$和$u$是兼容的。

a) 对于$n\geqslant 0$，令$\varphi^n: H^n\rightarrow G^n$为由$\varphi$推出的映射；如果$\varphi$和$u$相容的，则同态$c\mapsto u\circ c\circ \varphi^n$从$C^n(G,M)$到$C^n(H,N)$将$Z^n(G,M)$发送到$Z^n(H,N)$并将$B^n(G,M)$发送到$B^n(H,N)$，因此诱导同态$H^n(\varphi , u)$从$H^n(G,M)$到$H^n(H,N)$。 b) 设$\psi : K\rightarrow H$为另一个群同态，Pa$\mathbf{Z}$[K]-模，$v: N\rightarrow P$同态为阿贝尔的群。如果$\varphi$和$u$相容的，并且$\psi$和$v$也兼容，那么我们有$H^n(\varphi \circ \psi , v\circ u) = H^n(\psi , v)\circ H^n(\varphi , u)$。

c) 考虑交换律图表

0 // $M'$ // 中号 // $M''$ // 0

$u'uu''$

0 // $N'$ // N // $N''$ // 0 ,

其中第一行（或第二行）是$\mathbf{Z}$[G]-模块的正合序列（分别是$\mathbf{Z}$[H]-模块），并且其中$u', u, u''$与$\varphi$相容的。证明图表

$\cdots$ // $H_n(G,M')$ // $H_n(G,M)$ // $H_n(G,M'')$ // $H_{n+1}(G,M')$ /$/\cdots$

$H^n(\varphi ,u')H^n(\varphi ,u)H^n(\varphi ,u'')H^{n+1}(\varphi ,u)$

$\cdots$ // $H_n(H,N')$ // $H_n(H,N)$ // $H_n(H,N'')$ // $H_{n+1}(H,N')$ /$/\cdots$

（其水平线是习题 1, c) 中定义的长正合序列）是可交换的。

d) 例：如果 H = G，则映射 $u$ 与 Id$_G$ 兼容当且仅当它是 $\mathbf{Z}$[G]-线性，并且我们有 $H^n$(Id$_G, u$) $= H^n(G, u)$。如果N等于M，且具有从$\varphi$推导出来的$\mathbf{Z}$[G]-模结构，则同态$\varphi$和$1_M$是兼容的；我们用 Res$^q: H^q(G,M)\rightarrow H^q(H,M)$ 同态 $H^q(\varphi ,1_M)$ (“限制同态”) 表示。

e) 令 H 为 G 的正规子群，并令 $M^H$ 为 H 下元素不变量的 M 由……组成的子群，赋予 $G/H$ 的作用由 G 的经过商推导出来。 典范满射 $p: G\rightarrow$ $G/H$ 和典范嵌入 $j: M^H\rightarrow M$ 相容的；我们用 Inf$^q: H^q(G/H,M^H)\rightarrow H^q(G,M)$ 同态 $H^q(p, j)$（“膨胀同态”）表示。证明序列

$$
0\rightarrow H^1(G/H,M^H)\longrightarrow^{Inf^1}H^1(G,M)\longrightarrow^{Res^1}H^1(H,M)
$$

是准确的。此外，如果 $H^1(H,M)$ 是零，则序列

$$
0\rightarrow H^2(G/H,M^H)\longrightarrow^{Inf^2}H^2(G,M)\longrightarrow^{Res^2}H^2(H,M)
$$

是准确的。
