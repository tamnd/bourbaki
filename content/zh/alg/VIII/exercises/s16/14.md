设 A 为诺特交换局部环，$\mathfrak{m}$ 其最大理想，$\kappa$ 域 $A/\mathfrak{m}$，以及 A 上的 S 和 Azumaya 代数。

a) 设$e$是S中的幂等，而$S/\mathfrak{m}S$中的像是不可分解的幂等。从中山引理 (cf. VIII, p. 168, 习题 16) 推出典范同态 $S\rightarrow$ End$_A(Se)$ 是双射的。

b) 假设 $\mathfrak{m}$ 是幂零的 $*$（或者，更一般地，A 对于 $\mathfrak{m}$-adic 拓扑）$*$ 是完备的。证明同态 $r_{\kappa /A}:$ Br(A) $\rightarrow$ Br($\kappa$ ) 是单射的。

$*$c) 假设从现在开始A是完整的。令 L 为 $\kappa$ 的可分扩张

有限次数对于$\kappa$-代数$S/\mathfrak{m}S$ 来说是分裂域。设$x$是$L,f$的最小多项式的原语元素，F是A[X]中的一元多项式，其$\kappa [X]$中的像是$f$和$B = A[X]/(F)$。证明B是局部A-代数，自由且有限生成为A-模，极大理想$\mathfrak{m}B$和剩余类域同构于L； B 代数 $S_{(B)}$ 与矩阵代数同构。

d) 此外，假设L是$\kappa$的伽罗瓦扩张，其中伽罗瓦群 G。 证明G在L提升上的作用到A-代数B上的作用（让$G'$是这个代数的自同构群；从Hensel的引理（Comm. Alg., III, §4, No. 3, p. 215, 定理 1) 自然的同态 $G'\rightarrow G$ 是双射的）。 由中山引理推出习题13中定义的同态$\psi : B\otimes_AB\rightarrow B^G$是双射的。

e) 证明同态$H^q(\pi ) : H^q(G,B^*)\rightarrow H^q(G,L^*)$对于每个$q\geqslant 1$都是双射的。 （对于$i\geqslant 1$，令$U^i$为$B^*$的元素$b$的子群，使得$b\equiv 1$（mod$\mathfrak{m}^iB$）。观察$\mathbf{Z}$[G]-模块$U^i/U^{i+1}$同构于$\mathfrak{m}^iB/\mathfrak{m}^{i+1}B$，因此到 L 的幂，并从习题 5, d) 推出 $H^q(G,U^i/U^{i+1})$ 对于 $q\geqslant 1$ 来说是零。让$c\in Z^q(G,U^1)$。 构造，通过归纳，序列$(b_n)$与$b_n\in Z^{q-1}(G,U^n)$，使得$c-d^{q-1}(\sum^n_{i=1}b_i)$属于到$Z^q(G,U^{n+1})$。 结论 $H^q(G,U^1)$ 是零 $q\geqslant 1.)$

f ) 结论典范同态 Br(B$/A$)$\rightarrow$ Br(L$/\kappa$ ) 和 Br(A) $\rightarrow$ Br($\kappa$ ) 是双射。$*$
