令 k 为特征 2 的域。
a) 令$A_1, \ldots, A_n$为不定式，E中多项式$P = X^n + A_1 X^{n-1} + ... + A_n \in K[X]$的K域$k(A_1, ..., A_n)$、E分裂域和P的$X_1, ..., X_n$根，因此$E = k(X_1, ..., X_n)$(V、p. 21)。我们将 E/K 的认同伽罗瓦群与对称的群 $S_n$ 通过变量 $X_1, ..., X_n$ (V, p. 59) 的置换作用。放
$$
\beta(X_1, ..., X_n) = \sum_{i < j} X_i/(X_i + X_j) \in E \quad \text{and} \quad C(A_1, ..., A_n) = \sum_{i < j} (X_i X_j)/(X_i^2 + X_j^2) \in K.
$$
然后 $\beta \notin K$ 和
$$
\beta^2 + \beta + C = 0.
$$
我们有 $\sigma(\beta) = \beta$ 对应 $\sigma \in U_n$，$\sigma(\beta) = \beta + 1$ 对应 $\sigma \in S_n - U_n$。推出$K(\beta)$是$E/K$的唯一二次次扩张。
b) 令 $D \in \mathbf{Z}[T_1, ..., T_n]$ 为多项式 $X^n + T_1 X^{n-1} + ... + T_n$ 的判别式。证明存在 Q, R, S $\in \mathbf{Z}[T_1, ..., T_n]$ 且
$$
D = Q^2 - 4R + 8S
$$
和
$$
C = C(A_1, ..., A_n) = \frac{R(A_1, ..., A_n)}{Q^2(A_1, ..., A_n)} = \frac{R(A_1, ..., A_n)}{D(A_1, ..., A_n)}.
$$
对于元素 U、V、W $\mathbf{Z}[T_1, ..., T_n]$ 的每个三元组，使得 $D = U^2 - 4V + 8W$ 存在 $M \in \mathbf{Z}[A_1, ..., A_n]$ 使得
$$
C = \frac{V(A_1, ..., A_n)}{D(A_1, ..., A_n)} + \left( \frac{M}{D(A_1, ..., A_n)} \right)^2 + \frac{M}{D(A_1, ..., A_n)}
$$
c) 令$f = X^n + a_1 X^{n-1} + ... + a_n$为$k[X]$和分裂扩张的G伽罗瓦群的可分离多项式。证明 $(a_1, ..., a_n)$ 在 C 中是可替换的，并且以下条件是等价的
(i) G 诱导的每个元素和 f 的根的偶数置换；
(ii) 存在$a \in k$使得$C(a_1, ..., a_n) = a^2 + a$。
\* d) 从此假设k是有限的并且选择元素U，V，$\mathbf{Z}[T_1, ..., T_n]$的W任意到b)中所述的满足条件。
证明 c) 的 (i) 和 (ii) 等价于以下条件 ：
(三)
$$
\operatorname{Tr}_{k/\mathbf{F}_2}(C) = 0;
$$
（四）
$$
\operatorname{Tr}_{k/\mathbf{F}_2}\left( \frac{V(a_1, ..., a_n)}{D(a_1, ..., a_n)} \right) = 0.
$$
(v) f 的不可约因子的数与 n 模 2 全等（使用 V、p. 165 的例 22）。 \*
