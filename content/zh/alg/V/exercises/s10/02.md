令 K 为域，$f_0$ $K[X]$ 中次数 n 的不可约可分多项式；设$\alpha_i$($1 \leq i \leq n$)为$f_0$的分裂域N中的根。设 F 为有理分式 $N(X_1, X_2, ..., X_n)$ 的域，E 为 F 的子域 $K(X_1, X_2, ..., X_n)$； F 是 E 的伽罗瓦扩张，$\mathrm{Gal}(E/F)$ 与 $\mathrm{Gal}(N/K)$ 典型同构（V、p. 71、Th. 5；V、p. 154、Ex. 8）。证明如果 $8 = \alpha_1 X_1 + \alpha_2 X_2 + ... + \alpha_n X_n$ 那么 $F = E(8)$ 并且 $E[T]$ 中 8 的最小多项式 $g_1$ 是该多项式的不可约因子

$$
f(T) = \prod_{\sigma \in S_n} (T - \alpha_1 X_{\sigma(1)} - \alpha_2 X_{\sigma(2)} - \cdots - \alpha_n X_{\sigma(n)})
$$

每个置换 $\sigma \in S_n$、定义都是 E 的 K-自同构，再次用 a 表示，用条件 $\sigma(X_i) = X_{\sigma(i)}$ 表示 $1 \leq i \leq n$；证明$\mathrm{Gal}(N/K)$同构于$S_n$的子群、置换的由……组成，使得$\sigma(g_1) = g_1$。此外，如果$f = g_1 g_2 ... g_r$是f的分解在$E[T]$中不可约因子，则表明对于每个指标j使得$1 \leq j \leq r$存在置换$\sigma_j \in S_n$，使得$\sigma_j(g_1) = g_j$。
