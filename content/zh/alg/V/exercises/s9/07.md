令 K 为特征为 0、a、β、5 的域，K 的代数闭包的三个元素使得 $[K(\alpha):K] = 2,\ [K(\beta):K] = 3,\ [K(\xi):K] = n > 1$；用 a'（分别为 $\beta', \beta''$）表示 a 的唯一共轭$\neq a$（分别为 β 的共轭$\neq \beta$）。
a) 如果$a \in K(\xi)$则证明$[K(\alpha, \xi):K] = n$，否则证明$[K(\alpha, 5):K] = 2n$。
b) 证明如果$\beta \in K(\xi)$则证明$[K(\beta, 5):K] = n$，如果$\beta \in K(\xi)$则证明$[K(\beta, 5):K] = 2n$，并且仅$\beta', \beta''$之一属于$K(\xi)$，最后证明$[K(\beta, \xi):K] = 3n$，如果$\beta, \beta', \beta''$的三个元素都不属于$K(\xi)$。
c) 如果 d 是 β 的最小多项式的判别式，则证明 $K(\beta, \beta') = K(\beta, \sqrt{d})$。
d) 显示$K(\beta, \beta') = K(\beta - \beta')$。
e) 如果$n = 2$和$a \notin K(\xi)$，则证明$K(\alpha, \xi) = K(\alpha + \xi)$。
f) 显示$K(\alpha, \beta) = K(a + \beta)$。
g) 证明$K(\alpha, \beta) = K(\alpha \beta)$，除了当$a = aj$和$\beta^3 = b$时，其中a、b是K和$j^3 = 1$的元素。
