令$m, n$为整数，使得$0 \leq n \leq m$。令$p$为素数数，并令$m = a_r + \alpha_1 p + \ldots + \alpha_n p'$和$n = \beta_0 + \beta_1 p + \ldots + \beta_n p'$为基$p$中$m$和$n$的展开，因此我们对$0 \leq i \leq r$有$0 \leq \alpha_i < p, \ 0 \leq \beta_i < p$；假设$a_r \neq 0$。证明 $\binom{m}{n} \equiv 0 \pmod{p}$ 如果 $\beta_i > a_r$ 至少有一个指标 $i$。另一方面，如果 $\beta_i \leq \alpha_i$ 对应 $0 \leq i \leq r$，则

$$
\left( \begin{array}{c} m \\ n \end{array} \right) \equiv \left( \begin{array}{c} \alpha_0 \\ \beta_0 \end{array} \right) \cdots \left( \begin{array}{c} \alpha_r \\ \beta_r \end{array} \right) \pmod{p}
$$

（在$(\mathbf{Z}/p\mathbf{Z})[X]$我们有$(1 + X)^m = (1 + X)^{\alpha_0}(1 + X^p)^{\alpha_1} \ldots (1 + X^{p'})^{\alpha_r}$。）
