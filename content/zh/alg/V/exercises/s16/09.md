与Ex的记号。 8 let M ⊂ L be a subextension.将 m = tr. deg_kM，n = tr。 deg_kL，r = n - m。令 L 中的 x_1, ..., x_r 使得 L 是 k(x_1, ..., x_r) = K 的可分离代数扩张。
a) 表明，如果需要，之后对 x_i 重新编号，我们可以假设 L 是 M(x_1, ..., x_r) 上的代数。
b) 证明存在一个有限生成的子扩展 N ⊂ M 使得：
   a) L is algebraic over N(x_1, ..., x_r);
   β) K' = K(N(x_1, ..., x_r)) 是 N(x_1, ..., x_r) 的有限扩张；
   γ) 典范同态 K' $\otimes_{N(x_1, ..., x_r)} M(x_1, ..., x_r) \to K(M(x_1, ..., x_r)) = K''$ is bijective.
c) Let N be a subextension as in b).依次证明 K'' 是 K' 的可分代数扩张（因为 L 在 K 上可分），M(x_1, ..., x_r) 是 N(x_1, ..., x_r) 的可分代数扩张（使用 b), γ)），并且 M 是可分代数N 的扩张。
d) 证明 M 是纯超越扩张的可分离代数扩张（使用 c），并且事实 N 是 k 的有限生成的可分扩张）。
