假设Ex的假设。 6 成立，并且进一步证明 $E$ 超过 $K$ 的不完美性次数（*V*，p. 170，例 1）是*有限*（如果 $E$ 是 $K$ 的有限生成的扩张，情况总是如此）。

*a*) 令$B$为$F$在$K(F^p)$上的p基，这也是$F$在$K$上的分离超越基（以及$E$在$K$上的超越基）。证明对于每个整数 $k > 0$，$B^{p^k}$ 是 $K(E^{p^k})$ 超过 $K(E^{p^{k+1}})$ 的 p 独立子集。让$q = \operatorname{tr.deg}_K E$；如果$m_k + q$是$K(E^{p^k})$超过$K(E^{p^{k-1}})$的不完美的次数，则表明$p^f$（其中$f = \sum_{k=0}^{h-1} m_k$）等于次数$[E : F]$，因此独立于可区分子扩展$F$的选择 $E$。 整数$p^f$在$K$之上称为$E$不可分**阶写为$[E : K]_i$；这个数重合与不可分割的次数表示为$[E : K]$，在*V*中，当$E$是有限次数时，p. 46。

*b*) 对于 $0 \leq k \leq h - 1$，$[K^{p^{-k}}(E) : K^{p^{-k}}]$ 等于 $p^{f_k}$，其中 $f_k = \sum_{j=k}^{h-1} m_j$。

*c*) 令 $L$ 为 $E$ 的子扩展，可在 $K$ 上分离，并且使得 $E$ 为 p 根式，并且有限次数超过 $L$；显示$[E : L] \geq [E : K]$，（如果$[L(E^{p^k}) : K(E^{p^k})] = p^{r_k}$，则通过考虑$L(E^{p^k})$的基超过$K(E^{p^k})$和$L$的基超过$K(L^p)$）显示$r_{k+1} \leq r_k + q$）。

*d*) 令$K'$为$K$的扩张，使得$K'$和$E$包含在$K$的同一个代数闭扩张$\Omega$中。证明如果$K'(F)$可在$K'$上分离，则它是$K'$的扩张$K'(E)$的显着子扩展。当$K'$和$E$在代数上不相交的超过$K$时，我们就有$[K'(E) : K'] \leq [E : K]$，；当$K'$和$E$在$K$上线性不相交的或当$K'$是$K$的可分代数扩张时，等式成立。

*e*) 对于$E$的所有超越基$B$超过$K$，证明$[E : K]_i$是$[E : K(B)]_i$中最小的值；如果$K$是$\Omega$中$K$的相对代数闭包（即$K$的代数闭包），则$[E : K(B)]_i = [E : K]_i [\bar{K}(E) : \bar{K}(B)]_i$。如果$L$是$E$的子扩展，使得$E$是$L$的代数扩张，并且$\bar{K}(E)$是$\bar{K}(L)$的可分离（代数）扩张，则最大的区分$E$中包含的$L$的可分扩张$F$。

*f*) 假设$E$是$K$的有限生成的扩张；证明对于$E$的每个子扩展$L$，我们都有$[L : K]_i \leq [E : K]_i \leq [L : K]_i [E : L]_i$。给例哪里

$$
[L : K]_i = [E : K]_i \quad \text{and} \quad [E : L]_i > 1
$$
