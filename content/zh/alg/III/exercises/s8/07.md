设$\Delta = \det(\alpha_{ij})$为阶$n$的矩阵$U$的行列式；对于每个指标 $i$ ($1 \leq i \leq n$) 让$\Delta_i$表示通过将$U$中的元素$\alpha_{ij}$乘以$1 \leq j \leq n$的$\beta_j$获得的行列式。证明 $n$ 行列式 $\Delta_i$ ($1 \leq i \leq n$) 中的和等于 $(\beta_1 + \beta_2 + \cdots + \beta_n)\Delta$（将 $\Delta_i$ 扩展指标 $i$ 行）。
