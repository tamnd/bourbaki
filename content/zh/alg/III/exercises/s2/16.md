设 A 为交换环，且环 A[X] 中 u = \和_{k=0}^m a_k X^k 除子为 0。证明如果 v = \和_{k=0}^n b_k X^k 是次数 n 的 A[X] 的元素 ≠0，且 uv = 0，则存在次数 ≤ n − 1 的多项式 w ≠ 0，使得 uw = 0。（约化对应于 b_0 ≠ 0 的情况；如果 0 ≤ k ≤ m − 1 时 a_kv = 0，则表明我们可以取 w = b_0；如果 0 ≤ k < p ≤ m − 1 时 a_kv = 0 且 a_p v ≠ 0，则表明 a_p b_0 = 0，因此我们可以取 w = \和_{k=0}^{n-1} a_p b_{k+1} X^k。）推论A 存在元素 c ≠ 0，使得cu = 0。
