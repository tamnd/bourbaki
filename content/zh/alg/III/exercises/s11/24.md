令C为环A上的余代数。如果$c(S) \subset \operatorname{Im}(S \otimes C)$（或$c(S) \subset \operatorname{Im}(C \otimes S)$），C的子A模S称为*右*（或*左*）*共理想*。

(a) 子余代数 (习题 23) 是右共理想和左共理想。如果 A 为域，则逆命题为真。

(b) 每个和右（左）共理想都是右（左）共理想。

(c) 如果 S 是 C 的右（或左）共理想，则正交 $S^0$ 是对偶代数 $C^*$ 的右（或左）理想。

(d) 如果 A 是域和 $\mathfrak{J}'$ 对偶代数 $C^*$ 的右（或左）理想，则 C 中的正交 $\mathfrak{{J}'}^0$ 是 C 的右（或左）共理想。 （通过*reductio adabsurdum*进行论证，假设存在一个$x \in \mathfrak{{J}'}^0$使得$c(x) \notin \mathfrak{{J}'}^0 \otimes C$；写出$c(x) = \sum_i y_i \otimes z_i$，其中$z_i$是线性独立的，并表明存在$y' \in \mathfrak{J}'$和$z' \in C^*$使得$\langle y'z', x \rangle \neq 0.$）

推出，要使 C 的向量子空间 S 成为右（或左）共理想，则 $S^0$ 是 $C^*$ 的右（或左）理想是充分必要的。

(e) 从 (d) 推导出，如果 A 是域，则 C 的每一个交右余理想（分别是左余理想、子余代数）都是右余理想（分别是左余理想、子余代数）。对于 S 为子余代数或 C，其正交 S^0 是代数 C* 的双面理想是充分必要的。
