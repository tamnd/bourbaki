在域$K$上的$n$维射影空间$\mathbf{P}(V)$中，*射影基*是$n + 2$点的集合$S$，其中形式是射影自由的系统。如果$S = (a_i)_{0 \leq i \leq n+1}$和$S' = (a'_i)_{0 \leq i \leq n+1}$是$\mathbf{P}(V)$的任意两个射影基，则证明存在一个变换$f \in \mathbf{PGL}(V)$，使得$f(a_i) = a'_i$对于$0 \leq i \leq n + 1$。为了使这个变换是唯一的，$K$是可交换的是必要且充分的。 （约化适用于所有$i$为$a'_i = a_i$的情况，并注意总是可以写（在no. 6的记号中）$a_i = \pi(b_i)$，其中$(b_i)_{1 \leq i \leq n+1}$是$V$和$b_0 = b_1 + b_2 + \cdots + b_{n+1}$的基。） *给出例，其中$K$是四元数的域，并且存在$\mathbf{P}(V)$的点的无限集合$T$，其中$n + 1$其中形式有一个射影自由的系统和一个变换$f \in \mathbf{PGL}(V)$，与恒等式不同，使$T$的所有点保持不变。*
