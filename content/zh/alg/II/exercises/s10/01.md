(a) 令$E$为右$A$模。在加法群$E^r$（与$r \geq 1$）合成的外法则与$\mathbf{M}_r(A)$定义为集合运算符，用$x.P$表示，对于$E^r$的每个元素$x = (x_i)_{1 \leq i \leq r}$和每个平方矩阵 $P = (\alpha_{ij}) \in \mathbf{M}_r(A)$, 元素 $y = (y_i)$ $E^r$ 使得
$$
y_i = \sum_{j=1}^r x_j \alpha_{ji} \qquad (1 \leq i \leq r).
$$
这个外法则定义与$E^r$上的附加律是$E^r$上的右$\mathbf{M}_r(A)$模块结构；通过限制标量矩阵$I.\alpha$的环的运算符环，恢复乘积$A$-$E^r$上的模块结构。证明对于 $A$ 模 $E$ 具有 $r$ 元素的生成的系统，$\mathbf{M}_r(A)$ 模 $E^r$ 是单生的是充分必要的。

(b) 设$(x_i)_{1 \leq i \leq n}$为$E$中的生成的系统，且$(y_j)_{1 \leq j \leq m}$为$E$中的元素家庭（分别为$E$中的生成的系统）。令$z, z', z''$为$E^{m+n}$的三个元素，使得$1 \leq i \leq n$为$z_i = x_i$，$1 \leq j \leq m$为$z_{n+j} = 0$，$z'_i = x_i$为1 $\leq i \leq n,\ z'_{n+j} = y_j$为$1 \leq j \leq n,\ z''_i = 0$为$1 \leq i \leq n,\ z''_{n+j} = y_j$为$1 \leq j \leq n$。证明 $\mathbf{M}_{n+m}(\mathbf{A})$ 存在两个可逆的矩阵 $P, Q$，使得 $z' = z.P$（或 $z'' = z.Q$）。

(c) 如果$\mathbf{A}$是可交换的，则$u_P : x \mapsto x.P$是$\mathbf{A}$模$E'$的自同态，并且映射$P \mapsto u_P$是环$\mathbf{M}_r(\mathbf{A})$到环的同态 $\operatorname{End}_\mathbf{A}(E')$。如果$E$是忠实的$\mathbf{A}$模，则同态是单射的。
