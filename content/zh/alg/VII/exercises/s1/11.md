我们研究二次域 Q(\sqrt{d})，其中映射 a \mapsto |N(α)|是域的整数上的欧氏函数（例 7）。
a) 证明对此的必要且充分的条件是，对于所有 a \in Q(\sqrt{d})，存在域的整数 β 使得 |N(a - β)| < 1 ;写下这个条件，用整数基的项表达域的项（例8，c））。
b) 在虚二次域 (d < 0) 的情况下，证明 d 中唯一的值满足 |N(α)| 欧氏函数为−1、−2、−3、−7、−11。
c) 对于实二次域，我们将限制在 d ≠ 2 或 3 (mod 4) 的情况。证明只有有限多个 d 的值使得 |N(α)|是欧氏函数。 （如果 |N(α)| 为欧氏函数并且 a 为自然数，使得 0 ≤ a ≤ d 且 a ≡ t^2(d)，则证明 a 或 d − a 具有形式 x^2 − dy^2，其中 x 和 y 是有理数整数，通过考虑元素 t / \sqrt{d} of Q(\sqrt{d}) ；接下来表明，对于足够大的 d，存在奇数整数 z 使得 5 d < z^2 < 6d （如果 d == 3 mod 4）或 2d < z^2 < 3d （如果 d == 2 mod 4）；然后取 a = z^2 − d[z^2/d] 并证明，在这些条件下，a 和 d − a 都不具有形式 x^2 − dy^2，通过检查剩余类 mod 8)。证明 d 中不存在这样的整数 z 的唯一值是 3、7、11、19、35、47 和 59（对于 d == 3 mod 4）以及 2、6、14 和 26（对于 d == 2 mod 4）。证明对于 d = 2 和 d = 3 确实存在欧氏函数。
