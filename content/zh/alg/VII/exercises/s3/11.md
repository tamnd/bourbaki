设 A 和 B 为有理素数数的两个无限集合，没有公共的元素，且没有包含数 5. 令 $(e_i)_{1 \leq i \leq 4}$ 为 $\mathbf{Q}$ 向量空间 $\mathbf{Q}^4$ 的典范基。
a) 令M为元素$e_1/m$为$m \in A$生成的$\mathbf{Q}^4$的Z子模；令 N 为元素$e_2/m$与$m \in A$、$e_3/n$与$n \in B$和$(e_1 + e_3)/5$生成的$\mathbf{Q}^4$的Z子模。然后$M \cap N = 0$。输入$e'_1 = 8e_1 + 3e_2$和$e'_2 = 5e_1 + 2e_2$。设$M'$为元素$e'_1/m$与$m \in A$生成的$\mathbf{Q}^4$的Z子模；令$N'$为$\mathbf{Q}^4$的Z子模，由元素$e'_2/m$与$m \in A$、$e_4/n$与$n \in B$和$(3e'_2 + e_3)/5$生成。证明$M' \cap N' = 0$，即$M \oplus N = M' \oplus N'$； M 和 $M'$ 同构且不可分解；并且 N 和 N' 不可分解但不同构（比较 VII、p. 69、例 23）。
b) 令 M 为由元素 e_1/m 生成的 Q^4 的 Z 子模，其中 m \in A、e_2/n、n \in B 和 (e_1 + e_2)/5；令 N 为由元素 e_3/m（其中 m \in A、e_4/n、n \in B 和 (e_1 + e_4)/5）生成的 Q^4 的 Z 子模。将 e'_1 = 2e_1 + e_3、e'_2 = e_2 + 3e_4、e'_3 = 17e_1 + 9e_3 和 e'_4 = e_2 + 2e_4。令 M' 为 Q^4 的 Z 子模，由元素 e'_1/m（对于 m \in A）、e'_2/n（对于 n \in B）和 (e'_1 + 2e'_2)/5 生成；令 N' 为 Q^4 的 Z 子模，由元素 e'_3/m（对于 m \in A）、e'_4/n（对于 n \in B）和 (e'_3 + 2e'_4)/5 生成。证明 M \oplus N = M' \oplus N'，即 M 与 N 同构的，M' 与 N' 同构的，但 M' 与 M 不同构。
c) 令 M 为由 e_1/5^n (n \geq 0) 生成的 Q^4 的 Z 子模；令 N 为由 e_2/5^n、e_3/2^n、e_4/3^n (n \geq 0)、(e_2 + e_3)/3 和 (e_2 + e_4)/2 生成的 Q^4 的子模。将 e'_1 = 3e_1 - e_2 和 e'_2 = 2e_1 - e_。设 M' 为由元素 e'_1/5^n、e_3/2^n (n \geq 0) 和 (e'_1 - e_3)/8 生成的 Q^4 的 Z 子模；令 N' 为由元素 e'_2/5^n、e_4/3^n (n \geq 0) 和 (e'_2 - e_4)/2 生成的 Q^4 的 Z 子模。证明 M \oplus N = M' \oplus N'，M 和 N' 不可分解为秩 2，并且 M 具有秩 1。
