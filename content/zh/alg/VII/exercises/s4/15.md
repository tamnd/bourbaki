a) 令M为主理想整环A上有限长度和秩n的模，并令Aα_i(1≤i≤n)为其在递减阶中的不变量因子。令 (β_i) (1 ≤ i ≤ n) 为 A 的元素的序列，使得 β_i 除 a，对于 1 ≤ i ≤ n 和 a，除 β_{i−1}，对于 1 ≤ i ≤ n − 1。令 (M_i)_{≤ i ≤ n} 为M 的子模的序列，使得 M 是 M_i 的直和，并且每个 M_i 与 A/Aα_i 同构的；令 a_i 为 M_i 的生成元，其中 1 ≤ i ≤ n。放

$$
b = \beta_1 a_1 + \frac{\beta_1 \beta_2}{\alpha_1} a_2 + \frac{\beta_1 \beta_2 \beta_3}{\alpha_1 \alpha_2} a_3 + \cdots + \frac{\beta_1 \beta_2 \ldots \beta_n}{\alpha_1 \alpha_2 \ldots \alpha_{n-1}} a_n
$$

证明 M 与循环子模 Ab 的商同构于 n 模 A/Aβ_i (1 ≤ i ≤ n) 的直和。
b) 令 M 和 N 为 A 上的有限长度之二模；设Aα_i (1 ≤ i ≤ n)和Aβ_k (1 ≤ k ≤ p)分别为M和N的不变量因子，排列在递减阶；假设 p ≤ n，β_k 除 α_{k+n−p}（1 ≤ k ≤ p），a_i 除 β_{k+(p+q−n)}（1 ≤ k ≤ n − q），其中 q 为整数，使得

$$
q \leq n \leq p + q
$$

证明 M 存在子模 P，与 N 同构的，使得 M/P 具有秩 ≤ q（将两个模 M 和 N 分别分解为 q 模的直和，使得约化问题达到 q = 1 的情况；然后使用a) 和Ex。 13，g))。
c) 为了使 A 上的模 N 同构于有限长度的模 M 的直因子，N 的每个初等除子都是 M 的除子初等，并且 N 中的重数至多等于其重数是充分必要的。 M. 因此获得有限长度的模M的例和M的子模N，使得M的秩等于N的秩和M/N的和，并且使得N不允许M中的补集（使用a））。
