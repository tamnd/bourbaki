令A为主理想整环，令τ为A的不可约元，并令M为A上的π主模。令I为序数a的集合（集合理论，III，p. 225，例14），这样的基数序数 < a 的集合至多等于 M 的序数。 对于所有 a ∈ I by 超限归纳，M 的定义子模 M^{(α)} 如下：取 M^{(0)} = M；取 M^{(α + 1)} = πM^{(α)}；如果 a 是极限序数，则当 β < a 时，将 M^{(α)} 设为所有 M^{(β)} 中的交。

a) 证明存在最小序数 τ ε I 使得 M^{(τ + 1)} = M^{(τ)} （M 的终结序数）。证明 M^{(τ)} 承认 M 中的补集，并且子模的直和与 U_π 同构的（例 3）。如果 M^{(τ)} = 0，则称 M 减少。
b) 令 M 为简化的 τ 模。对于所有 x ∈ M，证明存在最大的序数 γ(x) ≤ τ 使得 x ∈ M^{(γ(x))} （特别是 γ(0) = τ）。概括Ex中的定义。 8，我们说γ(x)是x在M中的高度。证明如果γ(x) < γ(y)，则γ(x + y) = γ(x)，如果γ(x) = γ(y)，则γ(x + y) ≥ γ(x)。如果对于所有 y ∈ N，高度 γ(x + y) 至多等于 γ(x)，则我们说 x 对于 M 的子模 N 是正确的；证明 γ(x + y) = inf(γ(x), γ(y))，对于所有 y ∈ N。
c) 令 a < τ 为序数，并令 M^{(α)} 为 x 的 M^{(α)} 由……组成的子模，使得 πx = πy 对于某些 y ∈ M^{(α + 1)}。对于那些 y ∈ M^{(α + 1)} 具有性质, 元素 of 形式 u = x − y 形式类 mod M(π) ∩ M^{(α − 1)} in M(τ) ∩ M^{(α)};如果 φ 是典范同态，从 M(π) ∩ M^{(α)} 到模与 M(π) ∩ M^{(α + 1)} 的商，则证明将 x 发送到 φ(u) 的映射 ψ 是同态，其中核 M^{(α − 1)}，因而 M^{(α)}/M^{(α + 1)} 同构于 (M(π) ∩ M^{(α)})/(M(π) ∩ M^{(α + 1)})。
d) 令 N 为 M 的子模，并令 x ∈ M^{(α)} 为高度 α 的元素；表明 x 对于 N 是正确的当且仅当 M(π) ∩ M^{(α)} (cf. c)) 的相应的元素 u = x − y 对于 N 来说是正确的。存在这样的元素 x 当且仅当 N ∩ M^{(α)} 的像在同态 ψ 不同于 (M(π) ∩ M^{(α)})/(M(π) ∩ M^{(α − 1)})。
