设 A 为空间 $\mathbf{R}^n$ 中的子集。
a) 证明 A 的凸包络与点 $\sum_{i=0}^n \lambda_i x_i$ 的集合相同，其中$x_i \in A$、$\lambda_i \geq 0$ $0 \leq i < n$、$\sum_{i=0}^n \lambda_i = 1$。 （建立以下引理；如果$p + 1$点$x_i$（$0 \leq i \leq p$）形式是一个亲和依赖的系统（也就是说存在关系$\sum_{i=0}^p \beta_i x_i = 0$，其中$\beta_i$不全） 零和$\sum_{i=0}^p \beta_i = 0$），如果$x = \sum_{i=0}^p \alpha_i x_i$，其中$\alpha_i$是$\geq 0$和$\sum_{i=0}^p \alpha_i = 1$，则存在指标$k \leq p$和$p$数$\gamma_i$ ($0 \leq i \leq p, i \neq k$)使得$\gamma_i \geq 0$对于所有$i$、$\sum_{i \neq k} \gamma_i = 1$和$x = \sum_{i \neq k} \gamma_i x_i$；为此比较那些定义的$\alpha_i / \beta_i$。)
b) 令 $a$ 为 A 的凸包络线的点，且它不属于到最多 $n$ 点的任何子集的凸包络线。然后证明包含至少有$n + 1$连通分量。 （我们可以假设$a = 0$；让$(b_i)_{0 \leq i \leq n}$是A的$n + 1$亲和独立的点族，使得0属于到$b_i$（cf.a）的凸包络）。对于每个指标$i$，令$C_i$为由$b_j$与指标$j \neq i$生成的顶点0的尖凸锥体；表明 A 不满足任何锥体的边界 — $C_i$。
c) 如果 C 是 $\mathbf{R}^n$ 中顶点为 0 的尖锥体，则证明 C 的凸包络线是点 $\sum_{i=1}^n x_i$ 的集合，其中 $x_i \in C$ 对应 $1 \leq i \leq n$。
