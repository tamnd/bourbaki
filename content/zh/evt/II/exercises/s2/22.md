In $\mathbf{R}^2$ consider a set of $2m$ points of the form $(a_i, b'_i), (a_i, b''_i)$ where $b'_i \leq b''_i$ for $1 \leq i \leq m$. 设$n$为整数$< m - 2$。 在阶中，应该存在次数$\leq n$的多项式$P(x)$，使得$b'_i \leq P(a_i) \leq b''_i$对于$1 \leq i \leq m$，对于$n + 2$指标$i$的每个族$(i_k)_{1 \leq k \leq n+2}$，存在一个多项式就足够了次数$\leq n$的$Q(x)$使得$b'_{i_k} \leq Q(a_{i_k}) \leq b''_{i_k}$对于每个整数$k$使得$1 \leq k \leq n + 2$。 （使用练习21，a）。）
