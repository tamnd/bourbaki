令H为向量空间E中的超平面且不包含0，并令S为H中包含的凸集合。
a) 假设 S 的交与 H 中的每一行是紧段。令 $a, b$ 为 E 的两个不同的点，则存在两个数 $\lambda > 0, \mu > 0$，其中 $b + \mu S \subset a + \lambda S$；证明如果 c 是点，其中连接 a 和 b 的线与平行于 H 的超平面 H' 相交，其中包含 $a + \lambda S$，则 $c \in b + \mu S$ 和 $b + \mu S$ 是 $a + \lambda S$ 的像，通过中心 c 的位似将 a 变换为b. （约化对于E为维数2的情况。）
b) 对 S 进行相同的假设，令 $a, b$ 为 E 的两个不同的点，并假设存在点 $c \in E$ 和三个数 $\lambda > 0, \mu > 0, v \geq 0$，使得$(a + \lambda S) \cap (b + \mu S) = c + vS$。证明如果 A（或 B）是由 $a + \lambda S$（或 $b + \mu S$）生成的顶点 $a$（或 $b$）的圆锥体，且 $H''$ 超平面通过 c 平行于 H 经过，则 $H'' \cap A \cap B = \{ c \}$（使用 a））。
c) 假设H是S生成的仿射线性簇。令C为S生成的顶点为0的圆锥体。证明以下两个条件是等价的：
$\alpha)$ E 是 E 上阶的格子，其中 C 是元素 $\geq 0$ 的集合。
$\beta)$ 对于 E 和数 $\lambda > 0, \mu > 0$ 的任意点 $x, y$，且集合 $(x + \lambda S) \cap (y + \mu S)$ 不为空，则存在 $z \in E$ 和 $v \geq 0$，使得集合为$z + vS$。
（为了证明$\alpha$蕴含$\beta$），将约化应用于$y = 0$，并使用以下事实：如果$(s_i)$是S的点的有限族，并且$(\lambda_i)$是实数的族，使得$\sum_i \lambda_i s_i = 0$，则$\sum_i \lambda_i = 0$。
要证明$\beta$蕴含$\alpha$，请使用$b$）。
当S满足等价条件$\alpha$和$\beta$时，我们说S是E中的单纯形。当E为有限维时，点在H和生成的H中仿射独立的有限集合的凸包络是单纯形\* （逆命题也是正确的：$cf.$ INT、II、第二版、§ 2、练习 7））。 \*
