令 T 为可交换幺半群 (A, I, § 2.1)，携带预序关系 $x \leq y$，使得对于所有 $z \in T$，如果 $x \leq y$ 则$x + z \leq y + z$。 如果我们有，则 $\mathbf{R} \cup \{ -\infty \}$ 中 T 的映射 f 称为可加性（或次加性，或超加性）
$$
f(x + y) = f(x) + f(y) \quad (\text{resp. } f(x + y) \leq f(x) + f(y), \quad \text{resp. } f(x + y) \geq f(x) + f(y))
$$
对于 T 中的任意 $x, y$。
a) 如果 g 是次可加性且递增在 T 中，则函数 $h(x) = \inf_{n > 0} g(nx)/n$ 是次可加性且递增；如果$g(0) \geq 0$，我们有$h \leq g$和$h(0) = 0$。
b) 在同样的假设下，假设T存在两个元素$x_1, x_2$和两个实数$\xi_1, \xi_2$，使得$\xi_1 < g(x_1), \xi_2 < g(x_2)$和$g(x_1 + x_2) < \xi_1 + \xi_2$。 令$y_1, y_2, z_1, z_2$为T的四个元素，令$n_1, n_2$为两个整数$\geq 0$，令$\alpha_1, \alpha_2$为两个实数，使得
$$
\begin{align*}
n_1 \xi_1 + g(z_1) &< \alpha_1, \quad y_1 \leq n_1 x_1 + z_1 \\
n_2 \xi_2 + g(z_2) &< \alpha_2, \quad y_2 \leq n_2 x_2 + z_2 .
\end{align*}
$$
然后证明$g(n_2 y_1 + n_1 y_2) < n_2 \alpha_1 + n_1 \alpha_2$。
c) 令$\omega$为T上的超加函数，使得$\omega(0) = 0$，并令$\Omega$为T上的递增次加函数，使得T中的$\omega(x) \leq \Omega(x)$。 证明 T 上存在递增加性函数 f，使得 T 中存在 $\omega(x) \leq f(x) \leq \Omega(x)$。（注意 T 上递增子加法函数 g 的集合，使得 T 中的 $\omega(x) \leq g(x) \leq \Omega(x)$ 对于关系 $\geq$ 非空且可归纳，并取其中的最小值元素 f 为集合；使用 a) 表示 $f(0) = 0$。 为了证明不存在 T 的元素对，$(x_1, x_2)$ 使得 $f(x_1 + x_2) < f(x_1) + f(x_2)$ 说明，如果 $\xi_j \in \mathbf{R}$ 和 $h_j(x) = \inf(n \xi_j + f(y))$，其中 n 在整数集合 $\geq 0$ 中变化，并且 y 在 T 的元素集合中变化，使得 $x \leq nx_j + y$，则 $h_j$ 在 T ($j = 1, 2$) 中递增且次可加， $h_j(x_j) \leq \xi_j$ 和 $h_j(x) \leq f(x)$ 对于所有 $x \in T$。 然后使用 f 的定义和部分 b) 得到矛盾。）
