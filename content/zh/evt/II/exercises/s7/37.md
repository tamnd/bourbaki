设 F 为实数的可求和序列 x = (x_n) 的 Banach 空间 l^1(N)，并令 E 为序列 y = (y_n) 的空间，趋向于 0；我们给 F 弱拓扑 σ(F, E)，其中 E 和 F 使用形式 B(x, y) = Σ x_n y_n 分离对偶性。
a) 令 C 为 F 中由点 x = (x_n) 组成的凸锥体，使得对于所有 n，x_n ≥ 0。证明 C 在 F 中是闭集。
b) 令 A 为 x = (x_n) ε C 的集合，使得 $\sum^n x_n \leq 1$。证明 A 是 C 的上限，对于由 F 引起的拓扑是可度量的，并且当 n > 0 时，C 是集合 nA 的并。
c) 证明 C 的鞋底不是紧致的（例如集合 S 是 x = (x_n) ε C 的集合，使得 $\sum^n z_n x_n = 1$，其中 (z_n) ε E 且 z_n > 0 对于所有 n。如果 e_m = (δ_{mn})_{n≥0}， 点 $z_n^{-1} e_n$ 属于到 S，但不将形式相对于 F 中的紧集）。
d) 表明 C 对于由 F 引起的拓扑是不可度量的（使用 Baire th.，注意 A 中没有点是相对于子空间 C 的内部点）。
