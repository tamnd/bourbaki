考虑空间 E = R^{(N)}，弱拓扑 σ(R^{(N)}, R^N)；令 C 为 E 中由点 x = (x_n) 形成的封闭凸锥，使得对于所有 n，x_n ≥ 0。
a) 令 x = (x_n) 为 C 的点，并令 J 为整数 n 的有限集合，其中 x_n > 0；如果 m 是 J 的元素的数，则令 A 是点的集合 y = (y_n) of C，使得 y_n = 0（对于 n ∈ J 和 $\sum_{k\in J} y_k x_k^{-1} \leq m$）。证明 A 是 C 包含 x 的上限。
b) 表明 C 中不存在上限 B，使得当 n > 0 时，C 是集合 nB 的并。（令 p 为 B 到 C 规格的限制；p 在 C 中将是有限的，并且，如果 (e_n) 为E 的典范基，对于所有 n（II，p. 58，道具 4），我们有 p(e_n) > 0，并且对于 B 点 z^{(n)} = e_n/p(e_n) 属于；但证明存在 z' ∈ R^N，使得序列 (⟨z^{(n)}, z'⟩) 是无界的。）
