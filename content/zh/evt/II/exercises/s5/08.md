在 Hausdorff 局部凸空间中，令 A 和 B 为两个闭凸集合，没有公共的点，使得 $C_A \cap C_B = \{ 0 \}$ (II, p. 67, 执行 14)，并且使得 B 是局部紧致的。证明存在一个封闭的超平面将 A 与 B 分开（$cf.$ II，p. 67，练习 16）。类似地，如果 A 和 B 是顶点 0 的两个闭合凸锥，使得 $A \cap B = \{ 0 \}$ 和 B 是局部紧致的，则存在通过 0 并将 A 与 B 分开的闭合超平面经过（使用 II、p. 39 的引理 1）。
