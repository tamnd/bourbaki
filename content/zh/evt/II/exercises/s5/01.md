*a*) 令 E 为向量空间。如果 C 是顶点 0 和 $\neq E$ 的凸尖锥的集合的极大元素（按包含排序），我们就说 E 中的尖凸锥 C（顶点 0 的）是*最大*。证明尖凸锥 C 最大当且仅当它是由超平面定义且穿过 0 的闭半空间。为了建立该结果，请依次证明最大尖凸锥 C 的以下性质；

α) 我们有$C \cup (-C) = E$（通过获得矛盾来论证）。

β) 如果 $z$ 是 $C$ 的非内部 (II, p. 26) 点，则 $-z \in C$（相同方法）。推导出$C$包含内部点。

γ) $C$中包含的最大的向量子空间$H = C \cap (-C)$为超平面。 （经过到商空间$F = E/H$，这个约化来演示，用β）如果$C$除顶点之外的所有点都是内部的，那么$E$必然是维数1。）

b) 给出一个最大无尖凸锥的例（在顶点0的无尖凸锥的集合中），它没有内部点（cf.II，p. 65，练习5）。
