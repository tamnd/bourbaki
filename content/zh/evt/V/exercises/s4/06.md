令$E$为希尔伯特空间，$M, N$$E$和$M^{\circ}, N^{\circ}$各自的正交补集的两个闭子空间；令$p_M, p_N$分别表示$M$和$N$上的正交投影，使得$1_E - p_M, 1_E - p_N$分别是$M^{\circ}$和$N^{\circ}$上的正交投影。把$u_{NM} = (1_E - p_N) p_M$和$\delta(M, N) = \|u_{NM}\|$；我们有$\delta(M, N) = \delta(N^{\circ}, M^{\circ}) \leq 1$； 关系 $\delta(M, N) < 1$ 意味着 $M \cap N^{\circ} = \{0\}$。
a) 设$\tilde{M}$表示$M \cap N^{\circ}$在$M$中的正交补，并设$\varepsilon(M, N) = \delta(\tilde{M}, N)$。显示（使用记号练习 5）$\ell(u_{NM}) = M \cap N^{\circ}$ 并推导出 $\varepsilon(M, N) = \langle u_{NM} \rangle \leq \delta(M, N)$；此外，如果$M \cap N^{\circ} = \{0\}$（特别是如果$\delta(M, N) < 1$），则$\varepsilon(M, N) = \delta(M, N)$。
b) 对于从$E$到自身的连续线性映射$u$，我们通过$u$数$c(u) = \inf \|u(x)\| / \|x\|$的*conorm*来指定，其中$x$范围超过所有向量$\neq 0$的集合与$u^{-1}(0)$正交（如果$u = 0$，则放置$c(u) = 1$）。为了使$u(E)$在$E$关闭，$c(u) > 0$（I，p. 17，第1）是必要且充分的。我们有$c(u^*) = c(u)$。
c) 设 $v_{NM} = p_N p_M$。表明
$$
\varepsilon(M, N)^2 + c(v_{NM})^2 = 1
$$
（观察$\|u_{NM}(x)\|^2 + \|v_{NM}(x)\|^2 = \|p_M \cdot x\|^2$，并且$v_{NM}$的核是$M^{\circ} + (M \cap N^{\circ})$，并推断出$\langle u_{NM} \rangle^2 \leq 1 - c(v_{NM})^2$）。
d) 从 b) 和 c) 推导出 $\varepsilon(N, M) = \varepsilon(M, N)$，并使用 a) 推导出 $\varepsilon(M^{\circ}, N^{\circ}) = \varepsilon(M, N)$。
e) 输入 $g(M, N) = \|p_M - p_N\|$ (*cf.* V, p. 64, 练习 17)。表明
$$
g(M, N) = \sup(\delta(M, N), \delta(N, M))
$$
（观察$p_M - p_N = (1_E - p_N) p_M - p_N (1_E - p_M)$）；推断出$\varepsilon(M, N) \leq g(M, N)$。如果$M \cap N^{\circ} = N \cap M^{\circ} = \{0\}$，我们有关系$\varepsilon(M, N) = \delta(M, N) = \delta(N, M) = g(M, N)$。如果$g(M, N) < 1$，则$M \cap N^{\circ} = N \cap M^{\circ} = \{0\}$。
f) 令$Q_M, Q_N$为$E$中两个连续的投影，分别为像、$M$和$N$；给出关系$g(M, N) \leq \|Q_M - Q_N\|$中的另一个证明（V，p. 64，练习17）。 （注对于所有$x \in E$，我们有$\|(1_E - Q_M) \cdot x\|^2 + \|Q_M^* \cdot x\|^2 = \|x\|^2 + \|(Q_M - Q_M^*) \cdot x\|^2$，并将这个关系应用于$x = (p_M - p_N) \cdot y$，注意到关系$(1_E - Q_M) (p_M - p_N) = (Q_M - Q_N) p_N$和$(p_M - p_N) Q_M = (1_E - p_N) (Q_M - Q_N)$。）
