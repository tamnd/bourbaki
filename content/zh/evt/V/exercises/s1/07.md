令 E 为实数或复数范数空间，其中维数$\geq 2$，具有以下性质：存在不同于 0 和$\pm 1$ 的实数$\gamma$，使得关系$\|x + y\| = \|x - y\|$ 蕴含$\|x + \gamma y\| = \|x - \gamma y\|$。
a) 证明如果$\|x + y\| = \|x - y\|$，从$\mathbf{R}$到$\mathbf{R}$的凸映射$\phi : \xi \mapsto \|x + \xi y\|$在任何区间上都不是常数。 （通过反证论证；令$[\alpha, \beta]$为$\phi$恒定的最大的区间，证明存在$\delta > \beta$足够接近$\beta$且$\phi(\delta) = \phi(\beta)$，通过注意到，如果$\|u + v\| = \|u - v\|$，则$\|u + \gamma^n v\| = \|u - \gamma^n v\|$ 对于每个有理整数 $n$。）
b) 证明如果$\|x + y\| = \|x - y\|$，则对于每个实数$\xi$，$\|x + \xi y\| = \|x - \xi y\|$。 （对于 a 的记号），观察 $\phi$ 在点 $\xi = 0$ 处有一个相对最小值，使用对于每个有理数整数 $n$ $\phi(\gamma^n) = \phi(-\gamma^n)$ 的事实；推断我们有相同的 $\phi(\xi) = \phi(-\xi)$，否则，我们会得到两个数 $\lambda, \mu$ 的 $\phi(\lambda) = \phi(\mu)$，这样 $\lambda + \mu \neq 0$ 并且在这种情况下 $\phi$ 在点 $\frac{1}{2}(\lambda + \mu)$ 处具有相对最小值。）
c) 从 b) 中推导出 E 上的范数是前希尔伯特式的（首先证明，如果 $\|x\| = \|y\|$，对于实数 $\alpha, \beta$ 中的每一个对，我们都有 $\|\alpha x + \beta y\| = \|\beta x + 2y\|$，并且等式 $\|x + y\| = \|x - y\|$ 意味着对于每个$\|\alpha x + \beta y\| = \|\alpha x - \beta y\|$ 实数$\alpha, \beta$的对。接下来，利用前面的结果证明，如果$\|x\| = \|y\| = 1$和$\|x + y\| = \|x - y\|$，我们有关系$\|(\alpha^2 - \beta^2)x + 2\alpha\beta y\| = \alpha^2 + \beta^2$，并推出结论）。
