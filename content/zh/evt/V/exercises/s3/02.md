令E为无限维希尔伯特空间，并令$p, q$为两个整数$\geq 1$；让$p' = \left[ \frac{p}{2} \right], q' = \left[ \frac{q}{2} \right]$（积分部分）。 证明从$\hat{\Lambda}^p(E) \times \hat{\Lambda}^q(E)$到$\hat{\Lambda}^{p+q}(E)$的双线性映射$(u, v) \mapsto u \wedge v$的范数至少等于$\left( \frac{(p'+q')!}{p'! \ q'!} \right)^{1/2}$。 （当$p = 2p'$和$q = 2q'$为偶数时，考虑E中的2n维子空间$E_n$，具有正交基$(e_j)_{1 \leq j \leq 2n}$；让$e'_j = e_{2j-1} \wedge e_{2j}$代表$1 \leq j \leq n$；考虑乘积$u \wedge v$，其中$u = \sum_H e'_H$，$v = \sum_{\mathbf{K}} e'_\mathbf{K}$其中$\mathbf{H}$（分别$\mathbf{K}$）范围涵盖$\{1, 2, ..., n\}$的$p'$（分别$q'$）元素的所有子集的集合
如果$i_1 < ... < i_p$（分别$j_1 < ... < j_q$）是$\mathbf{H}$（分别$\mathbf{K}$）的元素递增序列，则$e'_\mathbf{H} = e'_{i_1} \wedge ... \wedge e'_{i_p}$（分别$e'_\mathbf{K} = e'_{j_1} \wedge ... \wedge e'_{j_q}$）。 推出$\Lambda(\mathbf{E})$不能中的乘法通过连续性扩展到$\hat{\Lambda}(\mathbf{E})$。）
