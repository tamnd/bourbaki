a) 设 L 为维数 n = dim E 的 E 的自由子 A 模。对于所有 x ∈ E \ {0}，a ∈ A 的集合，使得 ax ∈ L 是形式 m^h 的 K 的分数理想（h 为正或负整数）；将 α(x) = q^h 和 α(0) = 0，表明 α 是 E 上的超范数。据说它与自由A-模 L 相关。

b) 相反，如果 α 是 E 上的超范数，则 x ∈ E 的集合 L_α 使得 α(x) ≤ 1 是维数 n 的自由A-模。如果 [α] 是与 L_α 相关的范数，则有 α ≤ [α] ≤ qα，并且 [α] 是与自由A-模相关的范数中的下界，且 ≥ α。对于所有 x ∈ E，我们有 [qα] = q.[α]，并且 α(x) = inf(q^{-t}[q^tα] (x))，其中 t 在区间 [0, 1] 中变化。此外，函数 t ↦ [q^tα] (x) 在该区间内保持连续。

c) 使用相同的记号，证明对于 0 ≤ t ≤ 1，[q^tα] 中最多有 n 个不同的超范数。相反，令 L 为与维数 n 的自由A-模相关的超范数集合，并令 (α_t)_{0 ≤ t ≤ 1} 为 L 的超范数族递增，使得 α_1 = qα_0。证明存在 E 的基，所有 α_t 都具有标准形式（如果 u ∈ A 是评估 1 的元素，并且 x ∈ E 的 L_t 自由A-模使得 α_t(x) ≤ 1，则考虑 k 上的向量空间 L_t/uL_0）。进一步推论，如果对于所有 x ∈ E，t ↦ α_t(x) 在 [0, 1] 中左连续，则存在唯一的超范数 α，使得对于所有 t ∈ [0, 1] α_t = [q^tα]。
