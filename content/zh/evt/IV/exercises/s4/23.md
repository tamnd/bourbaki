令X为真正的无限维Banach空间。
a) 假设对于每个 λ > 0，存在 X 的有限维子空间 E_λ，使得 X 上不存在连续的投影算子 P 和像 E_λ，且 \|P\| ≤ λ。证明 X 与有限余维的每个闭子空间 Y 与 X 具有相同的性质。
b) 通过n上的归纳，表明存在X、有限余维的闭子空间的递减序列(X_n)，并且对于每个n，X的有限维子空间E_n使得：1°和E_1 + E_2 + ⋯ + E_n 是直接的，X_n 上存在连续投影算子 P_n，且范数 ≤ 2，其中像为 E_1 + E_2 + ⋯ + E_n； 2° 空间 E_n 包含在 (I − P_{n−1})(X_{n−1}) 中； 3° X 上不存在连续的投影算子，且像 E_n 且范数 ≤ n + 2。
c) 令 Z 为由 E_n 的并生成的 X 的闭子空间。证明 X 中不存在 Z 的拓扑补集（观察如果 Q 是 X 上的连续投影算子，其中像 Z，则 (I − P_{n−1})P_nQ 将是 X 上的连续投影算子，其中像E_n)。
