Soit C un cône convexe de sommet 0 dans un espace vectoriel E ; si $(x_i)_{1 \leq i \leq n}$ est une famille finie de points de C tels que $\sum_{i=1}^n \lambda_i x_i = 0$ pour une famille de nombres $\lambda_i > 0$, alors C contient le sous-espace vectoriel de E engendré par les $x_i$.
