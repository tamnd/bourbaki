Dans $\mathbf{R}^n$, soit $(C_i)_{1 \leq i \leq m}$ une famille de $m \geq n + 1$ cônes convexes de sommet 0 ; montrer que si, pour $n + 1$ quelconques de ces cônes, il existe un hyperplan H passant par 0 et tel que tous ces cônes soient d’un même côté de H, alors il existe un hyperplan $H_0$ tel que *tous* les cônes $C_i$ ($1 \leq i \leq m$) soient d’un même côté de $H_0$ (*cf.* II, p. 73, exerc. 21, *a*)).
