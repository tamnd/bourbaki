Soient E, $F_1$, $F_2$ trois espaces vectoriels topologiques, $f$ une application linéaire continue de $F_1$ dans $F_2$, $\mathcal{S}$ un ensemble de parties bornées de E ; montrer que $u \mapsto f \circ u$ est une application linéaire continue de $\mathcal{L}_{\mathcal{S}}(E ; F_1)$ dans $\mathcal{L}_{\mathcal{S}}(E ; F_2)$.
