Soient K un corps algébriquement clos de caractéristique 0, F = K((X¹/n!)) le corps des séries formelles en X¹/n!, E = K((X)) où X = (X¹/n!)ⁿ!, le sous-corps F, corps des séries formelles en X. Pour toute série formelle f ∈ K((X)), on note ω(f) son ordre.
a) Soit P(Y) = a₀Yⁿ + a₁Yⁿ⁻¹ + ⋯ + aₙ un polynôme de E[Y] de degré n, tel que aₙ ≠ 0, montrer qu’il existe une suite strictement croissante (iₖ)₀≤k≤r, d’entiers de l’intervalle [0, n] telle que : 1° i₀ = 0, iᵣ = n ; 2° ω(aᵢₖ) est fini pour 0 ≤ k ≤ r ; 3° pour tout indice j tel que 0 ≤ j ≤ n, distinct des iₖ et tel que ω(aⱼ) soit fini, le point (j, ω(aⱼ)) ∈ ℝ² est au-dessus de la droite passant par les points (iₖ, ω(aᵢₖ)), (iₖ₋₁, ω(aᵢₖ₋₁)), et strictement au-dessus si j < iₖ₋₁ ou j > iₖ (1 ≤ k ≤ r). On dit que la réunion des segments joignant les points (iₖ₋₁, ω(aᵢₖ₋₁)) et (iₖ, ω(aᵢₖ)) pour 1 ≤ k ≤ r est le polygone de Newton de P, les segments précédents en sont appelés les côtés et les points (iₖ, ω(aᵢₖ)) (0 ≤ k ≤ r) les sommets.
b) On pose ρₖ = iₖ − iₖ₋₁, σₖ = (ω(aᵢₖ) − ω(aᵢₖ₋₁))/ρₖ ; montrer que P admet exactement ρₖ zéros (comptés avec leur ordre de multiplicité) appartenant au corps K((X¹/(ρₖ!))) et dont les ordres sont égaux à σₖ (déterminer par récurrence les coefficients d’une série formelle de ce type vérifiant l’équation P(z) = 0).

c) En conclure que la réunion des corps $K((X^{1/n}))$ pour tous les entiers $n > 0$ est une clôture algébrique du corps $E = K((X))$ (« théorème de Puiseux »).
d) Si $K'$ est un corps de caractéristique 2 et si $E' = K'((X))$, le polynôme $Y^2 + XY + X$ de $E'[Y]$ n’a pas de racines dans la réunion des corps $K'((X^{1/n!}))$. \*
