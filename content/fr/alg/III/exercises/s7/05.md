Soient $K$ un corps commutatif, $E, F$ deux espaces vectoriels sur $K$, $u$ une application linéaire de $E$ dans $F$, de rang fini $r$. Montrer que si $p \leq r$, le rang de $\wedge^p u$ est égal à $\binom{r}{p}$, et que si $p > r$, $\wedge^p u$ est identiquement nulle (prendre dans $E$ une base dont $r$ vecteurs forment une base d’un sous-espace supplémentaire de $u^{-1}(0)$, les autres une base de $u^{-1}(0)$).
