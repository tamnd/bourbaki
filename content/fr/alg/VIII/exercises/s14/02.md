Soient K un corps commutatif, A la K-algèbre $\mathbf{M}_5$(K), B la sous-algèbre des matrices de la forme

$x$ 0 0

0 Y 0

0 0 Y

et C la sous-algèbre des matrices de la forme

$x$ 0 0 0

0 $x$ 0 0

0 0 $x$ 0

0 0 0 Y

où $x$ parcourt K et Y l’algèbre $\mathbf{M}_2(K)$. Prouver que B et C sont des algèbres semi-simples contenant le centre Z de A et qu’il existe un isomorphisme de K-algèbres $f: B\rightarrow C$ laissant invariants les éléments de Z, mais qu’il n’existe pas d’automorphisme de A prolongeant $f$ (remarquer qu’un tel automorphisme doit transformer un composant simple de B en un composant simple de C).
