On note $(1 + X)^T$ l’élément $\exp(T \log(1 + X))$ de $\mathbf{Q}[[X, T]]$.
a) Montrer que $(1 + X)^T = \sum_{n \geq 0} \frac{T(T-1) \cdots (T-n+1)}{n!} X^n$. (Le coefficient de $X^n$ est un polynôme en $T$, dont on connaît la valeur pour $T = n \in \mathbf{N}$.)

b) Montrer que $(1 + X)^T (1 + X)^{T'} = (1 + X)^{T + T'}$. Expliciter l’identité obtenue entre coefficients binomiaux. Montrer que $(1 + X + Y + XY)^T = (1 + X)^T (1 + Y)^T$.
