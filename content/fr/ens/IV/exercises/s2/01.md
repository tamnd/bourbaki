Soit S l’ensemble des signes P, P⁻, X, X⁻, x₁, ..., xₙ les lettres xᵢ étant de poids 0, P et P⁻ de poids 1, X et X⁻ de poids 2. Pour tout mot Λ de L₀(S) (I, p. 42) on définit la variance de Λ de la façon suivante: chacune des lettres xᵢ ainsi que les signes P, X ont pour variance 0, les signes P⁻, X⁻ ont pour variance 1; la variance de Λ est la somme *(dans le corps F₂)* des variances des signes qui y figurent (autrement dit, elle est 0 s’il y a un nombre pair de ces signes ayant la variance 1, et 1 dans le cas contraire).

On appelle type d’échelon signé un mot équilibré A de L₀(S) (I, p. 42) qui vérifie l’une des conditions suivantes:
1° A est une des lettres xᵢ;
2° Si A est de la forme fA₁A₂...Aₚ (I, p. 45, cor. 2), où f est l’un des signes P, P⁻, X, X⁻, p est égal à 1 ou 2 et les Aᵢ (1 ≤ i ≤ p) sont des mots équilibrés, alors chacun des Aᵢ est un type d’échelon signé; en outre, si f = X, A₁ et A₂ ont pour variance 0, et si f = X⁻, A₁ et A₂ ont pour variance 1.

Un type d’échelon signé est dit covariant s’il est de variance 0, contravariant s’il est de variance 1. Si, dans un type d’échelon signé A, on remplace P⁻ et X⁻ par P et X respectivement, on obtient un type d’échelon A* (IV, § 1, exerc. 1); toute réalisation du type d’échelon A* sur n termes E₁, ..., Eₙ est dite réalisation du type d’échelon signé A sur E₁, ..., Eₙ, et notée A(E₁, ..., Eₙ).

Soient E₁, ..., Eₙ, E₁', ..., Eₙ' des ensembles, fᵢ une application de Eᵢ dans Eᵢ' (1 ≤ i ≤ n). Montrer qu’à chaque type d’échelon signé S sur x₁..., xₙ, on peut associer une application {f₁, ..., fₙ}^S ayant les propriétés suivantes:
1° Si S est covariant (resp. contravariant), {f₁, ..., fₙ}^S est une application de S(E₁, ..., Eₙ) dans S(E₁', ..., Eₙ') (resp. de S(E₁', ..., Eₙ') dans S(E₁, ..., Eₙ)).

E IV.29

2° Si S est une lettre $x_i$, $\{ f_1, \ldots, f_n \}^S$ est $f_i$.
3° Si S est PT (resp. P\textsuperscript{-}T), et si $g = \{ f_1, \ldots, f_n \}^T$ est une application de F dans F', $\{ f_1, \ldots, f_n \}^S$ est l'extension de g aux ensembles de parties (resp. l'extension réciproque de g aux ensembles de parties).
4° Si S est XTU ou X\textsuperscript{-}TU, si $\{ f_1, \ldots, f_n \}^T$ est une application g de F dans F' et $\{ f_1, \ldots, f_n \}^U$ une application h de G dans G', $\{ f_1, \ldots, f_n \}^S$ est l'extension $g \times h$, application de F × G dans F' × G'.

L'application $\{ f_1, \ldots, f_n \}^S$ est appelée l'extension canonique signée de $f_1, \ldots, f_n$, correspondant au type d'échelon signé S. Lorsque S est un type d'échelon (autrement dit, lorsque P\textsuperscript{-} et X\textsuperscript{-} ne figurent pas dans S), l'extension canonique signée $\{ f_1, \ldots, f_n \}^S$ est égale à $\langle f_1, \ldots, f_n \rangle^S$.

Montrer que, si $f_i$ est une application de $E_i$ dans $E'_i$, $f'_i$ une application de $E'_i$ dans $E''_i$ ($1 \leq i \leq n$), on a, pour un type d'échelon signé covariant S
$$
\{ f'_1 \circ f_1, \ldots, f'_n \circ f_n \}^S = \{ f'_1, \ldots, f'_n \}^S \circ \{ f_1, \ldots, f_n \}^S
$$
et, pour un type d'échelon signé contravariant S
$$
\{ f'_1 \circ f_1, \ldots, f'_n \circ f_n \}^S = \{ f_1, \ldots, f_n \}^S \circ \{ f'_1, \ldots, f'_n \}^S.
$$
En déduire que si $f_i$ est une bijection de $E_i$ sur $E'_i$, $f'_i$ la bijection réciproque ($1 \leq i \leq n$), $\{ f_1, \ldots, f_n \}^S$ est une bijection et $\{ f'_1, \ldots, f'_n \}^S$ la bijection réciproque. En outre, si S* est le type d'échelon (non signé) correspondant au type d'échelon signé S, $\{ f_1, \ldots, f_n \}^S$ est égale à $\langle f_1, \ldots, f_n \rangle^{S*}$ ou à $\langle f'_1, \ldots, f'_n \rangle^{S*}$ suivant que S est covariant ou contravariant.
