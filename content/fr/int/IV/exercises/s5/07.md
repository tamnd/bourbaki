Soient X l’intervalle $(0, 1)$ dans $\mathbf{R}$, et F l’espace hilbertien ayant une base orthonormale $(e_t)_{0 \leq t \leq 1}$ équipotente à X.

a) Montrer que l’application f de X dans F, telle que $f(t) = e_t$ pour $0 \leq t \leq 1$, n’est pas mesurable pour la mesure de Lebesgue, mais que l’image réciproque par f de toute boule fermée dans F est mesurable et que, pour toute forme linéaire a’ continue sur F, $\langle f, a' \rangle$ est négligeable.

b) Soit H un ensemble non mesurable dans X (§ 4, exerc. 8); montrer que si $g = f \varphi_H$, la fonction $\langle g, a' \rangle$ est négligeable pour toute forme linéaire continue a’ sur F, mais que la fonction numérique $|g|$ n’est pas mesurable.
