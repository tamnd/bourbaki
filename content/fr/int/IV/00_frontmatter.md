## CHAPITRE IV

# PROLONGEMENT D’UNE MESURE. ESPACES $L^p$

Dans ce chapitre, X désigne un espace localement compact, $\mu$ une mesure sur X ; lorsqu’il est question d’une fonction (sans préciser l’ensemble où cette fonction est définie), il est sous-entendu qu’il s’agit d’une fonction définie dans X.

Pour toute partie A de X, on désignera par $\varphi_A$ la fonction caractéristique de A (égale à 1 dans A, à 0 dans $\complement A$).
