On suppose le groupe G presque simple ; soit H un sous-groupe principal de G, de rang ≥ 2.
a) Montrer que H est semi-simple de type B_h, C_h, F_4 ou G_2 (utiliser l'exerc. 19).
b) On suppose que H est de rang ≥ 3. Montrer que G est de type A_l, D_l, E_6, E_7 ou E_8 (considérer les sommets terminaux du graphe de Dynkin de R(G, T), et appliquer l'exerc. 19).

c) Si $\mathrm{rg}\, H \geqslant 3$, montrer qu’on est dans l’une des situations suivantes :

$$
G \text{ est de type } A_{2l} \quad (l \geqslant 3) \text{ et } H \text{ de type } B_l ;
$$
$$
G \text{ est de type } A_{2l-1} \quad (l \geqslant 3) \text{ et } H \text{ de type } C_l ;
$$
$$
G \text{ est de type } D_l \quad (l \geqslant 4) \text{ et } H \text{ de type } B_{l-1} ;
$$
$$
G \text{ est de type } E_6 \qquad \text{et } H \text{ de type } F_4 .
$$

d) Si $H$ est de type $B_2$, montrer que $G$ est de type $A_3$ ou $A_4$.
e) Si $H$ est de type $G_2$, montrer que $G$ est de type $B_3, D_4$ ou $A_6$.
(Pour une description plus explicite de ces situations, voir § 5, exerc. 5.)
f) Soit $K$ un sous-groupe fermé connexe de $G$ contenant $H$; montrer qu’on a $K = G$ ou $K = H$, ou bien que $H$ est de type $G_2$, $K$ de type $B_3$ et $G$ de type $D_4$ ou $A_6$.
