Soit $ G = \mathrm{SU}(2, \mathbf{C}) $, et soit $ \sigma $ la représentation identique de $ G $ dans $ \mathbf{C}^2 $.
a) Les représentations irréductibles de $ G $ sont les représentations $ \tau^n = S^n \sigma $ pour $ n \geq 0 $.
b) Soit $ e_1, e_2 $ la base canonique de $ \mathbf{C}^2 $; montrer que les coefficients de $ \tau^n $ dans la base $ (e_1^{i} e_2^{n-i})_{0 \leq i \leq n} $ sont les fonctions $ \tau^n_{ij} $ telles que, pour $ g = \begin{pmatrix} \alpha & \beta \\ -\overline{\beta} & \overline{\alpha} \end{pmatrix} \in G $, on ait
$$
\tau^n_{ij}(g) = \frac{(-1)^i}{j!} \alpha^{i+j-n} \beta^{j-i} P^n_{ij}(|\alpha|^2), \text{ avec } P^n_{ij}(t) = \frac{d^j}{dt^j} [t^{n-i}(1-t)^i] \text{ (« polynômes de Jacobi »)}.
$$
c) Déduire de b) que les fonctions $ (n+1)^{1/2} \left( \frac{j!(n-j)!}{i!(n-i)!} \right)^{1/2} \tau^n_{ij} $ pour $ i, j, n $ entiers avec $ 0 \leq i \leq n, 0 \leq j \leq n $, forment une base orthonormale de $ L^2(G) $.
d) Pour $ g = \begin{pmatrix} \alpha & \beta \\ -\overline{\beta} & \overline{\alpha} \end{pmatrix} \in G $, on pose $ \alpha = t^{1/2} e^{-i(\varphi+\psi)/2}, \ \beta = (1-t)^{1/2} e^{i(\varphi+\psi)/2} $, avec $ 0 \leq t \leq 1, 0 \leq \varphi < 2\pi, -2\pi \leq \psi < 2\pi $. Montrer que la mesure de Haar normalisée $ dg $ sur $ G $ est alors égale à $ (8\pi^2)^{-1} dtd\varphi d\psi $.
e) Soient $ a, b $ dans $ \frac{1}{2}\mathbf{Z} $, tels que $ a-b \in \mathbf{Z} $. Déduire de d) que les polynômes $ P^n_{n/2-a,n/2-b}(t) $, pour $ n $ entier de même parité que $ 2a, n \geq \max(2a, 2b) $, forment une base orthogonale de $ L^2([0,1]) $ pour la mesure $ t^{-a-b}(1-t)^{a-b} dt $.
