Soient k un corps, n un entier ≥ 1. Pour chaque entier r ∈ {0, n}, soit M_r le sous-espace vectoriel de k(X_1, ..., X_n) engendré par les monômes X_1^{\alpha_1} ... X_r^{\alpha_r} avec α_1, ..., α_r dans Z et α_r > 0. Posons a_r = M_r + ... + M_n, pour 0 ≤ r ≤ n + 1. Alors a_0 est un sous-anneau de k(X_1, ..., X_n), et les a_r sont des idéaux premiers de a_0. Posons A = (a_0)_{a_1} et p_r = (a_r)_{a_1} pour 1 ≤ r ≤ n + 1. Montrer que les seuls idéaux premiers de l’anneau local A sont les p_r, que l’on a ht(p_r) = n + 1 − r et dim(A) = n. De plus p_1 est principal.
