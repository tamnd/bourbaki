Soient $Y$ un espace irréductible admettant un seul point générique $y$, $X$ un espace topologique, $f : X \to Y$ une application continue.

a) Pour toute composante irréductible $Z$ de $X$ rencontrant $f^{-1}(y)$, $f(Z)$ est dense dans $Y$.

b) Donner un exemple où $f(X)$ est dense dans $Y$ mais $f^{-1}(y)$ est vide (prendre pour $X$ un sous-espace de $Y$).

c) Montrer que, si $Z$ admet un point générique $z$ et si $f(Z)$ est dense dans $Y$, on a $f(z) = y$ et $z$ est point générique de $Z \cap f^{-1}(y)$.
