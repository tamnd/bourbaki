Soit $K$ une extension de type fini d’un corps $k$ ; prouver que les conditions suivantes sont équivalentes :

(i) la $k$-algèbre $K$ est formellement nette ;
(ii) la $k$-algèbre $K$ est formellement étale ;
(iii) $K$ est une extension finie séparable de $k$.
