Si $x$ et $y$ sont réels, on a
$$
[x + y] = [x] + [y] + \varepsilon \quad \text{avec } \varepsilon = 0 \text{ ou } \varepsilon = 1;
$$
$$
[x - y] = [x] - [y] - \varepsilon \quad \text{avec } \varepsilon = 0 \text{ ou } \varepsilon = 1;
$$
$$
[x] + [x + y] + [y] \leq [2x] + [2y];
$$
$$
[x] + \left[ x + \frac{1}{n} \right] + \left[ x + \frac{2}{n} \right] + \cdots + \left[ x + \frac{n-1}{n} \right] = [nx]
$$
$$
\left[ \frac{[nx]}{n} \right] = [x]
$$
pour $n$ entier $> 0$.
