Soient X un espace topologique, Y, Z deux espaces métriques, d, d’ les distances dans Y, Z respectivement. Soit f une application de X × Y dans Z telle que, pour tout x_0 ∈ X, y ↦ f(x_0, y) soit continue dans Y, et que, pour tout y_0 ∈ Y, x ↦ f(x, y_0) soit continue dans X.

a) Pour tout ε > 0, tout point b ∈ Y et tout x ∈ X, on désigne par g(x; b, ε) la borne supérieure des nombres α > 0 tels que la relation d(b, y) < α entraîne d’(f(x, b), f(x, y)) ≤ ε. Montrer que x ↦ g(x; b, ε) est une fonction semi-continue supérieurement.

b) Si X est un espace de Baire, déduire de a) et du th. 2 que pour tout b ∈ Y, il existe dans X un ensemble S_b dont le complémentaire est maigre, tel que pour tout a ∈ S_b, la fonction f soit continue au point (a, b).
