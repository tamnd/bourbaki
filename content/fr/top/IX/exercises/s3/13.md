Soit $E$ un espace normé sur le corps $R$. Montrer que si $x, y, z$ sont trois points linéairement dépendants dans $E$, on a

$$
\|x + y\| + \|y + z\| + \|z + x\| \leq \|x\| + \|y\| + \|z\| + \|x + y + z\|.
$$

(En considérant éventuellement les points $x' = x, y' = y, z' = -x - y - z$, montrer qu’on peut se ramener au cas où $x + \beta y + \gamma z = 0$ avec $0 \leq \beta \leq 1, 0 \leq \gamma \leq 1$; écrire alors $x + y = (1 - \beta)y - \gamma z, -(x + z) = \beta y - (1 - \gamma)z.$)
