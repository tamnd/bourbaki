a) Soient $X, X'$ deux espaces métrisables, $X'$ étant de type dénombrable, et soit $(U'_n)$ une base dénombrable pour la topologie de $X'$. Soit $\alpha$ un ordinal dénombrable pair (resp. impair); si une application $f$ de $X$ dans $X'$ est telle que $f^{-1}(U'_n)$ appartienne à $\mathfrak{G}_\alpha(X)$ (resp. $\mathfrak{F}_\alpha(X)$), $f$ est de classe $\alpha$.
b) Soit $(X_n)$ une suite d’espaces métrisables de type dénombrable. Pour qu’une application $f = (f_n)$ de $X$ dans $\prod_n X'_n$ soit de classe $\alpha$, il faut et il suffit que chacune des $f_n$ soit de classe $\alpha$ (utiliser a)). En déduire que si $X$ est de type dénombrable, les fonctions numériques finies de classe $\alpha$ sur $X$ forment un anneau.
c) Soient $X, X'$ deux espaces métrisables de type dénombrable, $\alpha$ un ordinal dénombrable pair (resp. impair). Si une application $f$ de $X$ dans $X'$ et de classe $\alpha$, montrer que son graphe appartient à $\mathfrak{F}_\alpha(X \times X')$ (resp. $\mathfrak{G}_\alpha(X \times X')$) (utiliser b) et l’exerc. 20 b)).
