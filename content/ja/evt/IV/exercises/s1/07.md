F を直和空間 $\mathbf{R}^{(\mathbf{N})}$、G 空間 $\ell^1(\mathbf{N})$ (I, p. 4, 例) とします。 F と G は双一次形式により双対関係に置かれます
$$
(x, y) \mapsto \sum_n \xi_n \eta_n
$$
$x = (\xi_n) \in F$ と $y = (\eta_n) \in G$ の場合。
a) F において、σ(F, G) に対して凸でコンパクトなすべての集合 K が有限次元であることを示します。 (逆のことを仮定します。$(n_k)$ を 0 より大きい厳密に増加する整数列、$(a_k)$ を K の点の列とし、インデックス > $n_k$ の $a_k$ の成分は 0 ですが、インデックス $n_k$ の成分は ≠ 0 であるとします。 $\sum_k t_k < + \infty$ と、実数、点 $\sum_k t_k a_k$ のすべての有界数列のバナッハ空間 $\mathscr{B}(\mathbf{N})$ に、数 > 0 の数列 $(t_k)$ が存在することを示します。 成分は添字 $n_i$、すべての私に。部分和 $s_p = \sum_{k=1}^p t_k a_k$ できないの数列は、σ(F, G) の F に極限点があると推測します。)
b) F では、無限次元である σ(F, G) に対してコンパクトな集合が存在することを示します (G は、正規化された空間 $\mathscr{B}(\mathbf{N})$ の位相によって誘起される位相の F の双対であることに注目してください)。 比較的コンパクトではない σ(F, G) の F にプレコンパクト集合が存在することを示します。

c) a) と b) から、$\tau(G, F) = \sigma(G, F)$ が、$\tau(G, F)$ は、$\sigma(F, G)$ に対してコンパクトである$F$ の部分集合に対する一様収束の位相とは異なると推定します。
