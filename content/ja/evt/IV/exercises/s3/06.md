a)** E を (DF) 空間 (IV, p. 57, exerc. 2) とし、U を凸集合とし、E のすべての有界、凸、バランスの取れた部分集合 A について、$U \cap A$ は位相に対して 0 の近傍となるA による E のそれ。 U が A の 0 の近傍であることを示します。($(A_n)$ を、E の正規の生まれつき (III、p. 3、定義 5) の可算基底とします)。 帰納法によって、数値$> 0$のシーケンス$(\lambda_n)$と、$n$ごとに$\lambda_n A_n \subset \frac{1}{3} U, \lambda_n A_n \subset \bigcap_{j=1}^\infty V_j, V_n \cap A_n \subset U$となるような、Eの閉じた凸状の平衡近傍0のシーケンス$(V_n)$を定義できることを示してください。

まず、$j \leq n$ に対して $\lambda_j$ と $V_j$ が構築されている場合、$j \leq n$ に対して $\lambda_{n+1} A_{n+1} \subset \frac{1}{3} U$ と $\lambda_{n+1} A_{n+1} \subset V_j$ が成り立つような $\lambda_{n+1}$ を見つけることができることを示します。 次に、$j \leq n + 1$ と $V_{n+1} \cap A_{n+1} \subset U$ に対して $\lambda_j A_j \subset V_{n+1}$ となる $V_{n+1}$ を見つけられることを証明します。この場合、A を $j \leq n + 1$ の $\lambda_j A_j$ の凸包絡線を表すとすると、0 の適切な凸平衡近傍 V に対して $V_{n+1} = \overline{A + V}$ を取得できることがわかります。このためには、$B = A_{n+1} \cap \complement U$ の場合、集合 $B + 2A$ の閉包に 0 が存在しないことを示すだけで十分であることに注意してください。
b) a) から、$u$ が E から局所凸空間 F への線形写像であり、E のすべての有界部分集合に対する $u$ の制限が連続である場合、$u$ は連続であると推定します ($cf.$ IV, p. 50、演習 15)。
