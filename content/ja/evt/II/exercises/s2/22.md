$\mathbf{R}^2$では、$2m$の集合、形の点、$(a_i, b'_i), (a_i, b''_i)$、$1 \leq i \leq m$の$b'_i \leq b''_i$を考慮します。 $n$ を整数 $< m - 2$ とします。 位数では、$1 \leq i \leq m$ に対して $b'_i \leq P(a_i) \leq b''_i$ となるような次数 $\leq n$ の多項式 $P(x)$ が存在する必要があり、$n + 2$ 添字 $i$ のすべての族 $(i_k)_{1 \leq k \leq n+2}$ に対して、多項式が存在するだけで十分です。 次数 $\leq n$ の $Q(x)$ は、整数 $k$ ごとに $b'_{i_k} \leq Q(a_{i_k}) \leq b''_{i_k}$ となり、$1 \leq k \leq n + 2$ になります。 (演習 21、a) を使用してください。)
