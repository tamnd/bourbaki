$E$ において、$E$ をハウスドルフ位相幾何学的ベクトル空間とし、$C$ を頂点 0 を持つ空でない開いた凸の尖っていない円錐とします。 $E$の0の凸近傍は$V$で表されます。 $f$ が、上で $C \cap V$ で定義され境界付けられている凸の写像である場合、$x$ が 0 に向かう傾向があるのと同様に、$f(x)$ が有限の極限に向かう傾向があることを示します。ここで、$x \in C \cap V$ です。 ($\beta = \limsup_{x \to 0, x \in C \cap V} f(x)$; いくつかの $\alpha > 0$ と 0 のすべての近傍 W に対して、$f(y) < \beta - \alpha$ となるような点 $y \in C \cap V \cap W$ が存在すると仮定して、矛盾を求めます。$0 < \rho \leq 1$ に対して $f(\rho a) \geq \beta - \frac{1}{2}\alpha$ となるような $a \in C \cap V$ が存在することを示します。 形 $\rho a$ ($\rho$ 十分に小さい) の点と $C \cap V$ の点 $y$ を結ぶ線上に、$f(y) < \beta - \alpha$ が存在し、それが 0 に十分近い場合、点が存在すると推測します。 $C \cap V$ ここで、$f$ は任意の大きさです。)
