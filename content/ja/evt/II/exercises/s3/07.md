T を、事前順序関係 $x \leq y$ を運ぶ可換モノイド (A, I, § 2.1) とし、$x \leq y$ の場合、すべての $z \in T$ について $x + z \leq y + z$ となるようにします。 $\mathbf{R} \cup \{ -\infty \}$ の T の写像 f は、次の場合、加法 (それぞれ副加法、それぞれ超加法) と呼ばれます。
$$
f(x + y) = f(x) + f(y) \quad (\text{resp. } f(x + y) \leq f(x) + f(y), \quad \text{resp. } f(x + y) \geq f(x) + f(y))
$$
T の任意の $x, y$ に対して。
a) g が準加法的であり、T が増加するである場合、写像 $h(x) = \inf_{n > 0} g(nx)/n$ は準加法的であり、増加する; $g(0) \geq 0$なら$h \leq g$と$h(0) = 0$があります。
b) 同じ仮説の下で、T の 2 つの元 $x_1, x_2$ と、$\xi_1 < g(x_1), \xi_2 < g(x_2)$ と $g(x_1 + x_2) < \xi_1 + \xi_2$ のような 2 つの実数 $\xi_1, \xi_2$ が存在すると仮定します。 $y_1, y_2, z_1, z_2$ を T の 4 元とし、$n_1, n_2$ を 2 整数 $\geq 0$ とし、$\alpha_1, \alpha_2$ を 2 実数とします。
$$
\begin{align*}
n_1 \xi_1 + g(z_1) &< \alpha_1, \quad y_1 \leq n_1 x_1 + z_1 \\
n_2 \xi_2 + g(z_2) &< \alpha_2, \quad y_2 \leq n_2 x_2 + z_2 .
\end{align*}
$$
それを見せてください$g(n_2 y_1 + n_1 y_2) < n_2 \alpha_1 + n_1 \alpha_2$。
c) $\omega$ を $\omega(0) = 0$ となるような T 上の超加法関数とし、$\Omega$ を T における $\omega(x) \leq \Omega(x)$ となるような T 上の増加する準加法関数とする。 T に $\omega(x) \leq f(x) \leq \Omega(x)$ となるような T 上に増加する加法的関数 f が存在することを示してください。 (T の $\omega(x) \leq g(x) \leq \Omega(x)$ が空ではなく、関係 $\geq$ に対して帰納的であるように、増加するの集合が T 上で副加法関数であることに注意してください。そして、これの最小の元を取ります集合 for f; a) を使用してその $f(0) = 0$ を示します。 T の元の対ができない存在することを示すために、$f(x_1 + x_2) < f(x_1) + f(x_2)$ が $\xi_j \in \mathbf{R}$ および $h_j(x) = \inf(n \xi_j + f(y))$ の場合、n は整数 $\geq 0$ の集合と y で変化することを指摘するような $(x_1, x_2)$ T の元の集合は、$x \leq nx_j + y$ である場合、$h_j$ は増加するであり、すべての $x \in T$ に対して T ($j = 1, 2$)、$h_j(x_j) \leq \xi_j$、$h_j(x) \leq f(x)$ で準加法的です。 次に、f の定義と部分 b) を使用して矛盾を取得します。)
