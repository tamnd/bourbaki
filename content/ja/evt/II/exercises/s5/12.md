$\mathbf{R}^3$ で、関係 $\xi_1 \geq 0, \xi_2 \geq 0, \xi_3^2 \leq \xi_1 \xi_2$ によって定義される閉じた凸円錐 C を考えてみましょう。方程式 $\xi_1 = 0, \xi_3 = 1$ の直線 D が C と交わらないが、原点 0 含む D を通り、$C - \{ 0 \}$ と交わらない平面は存在しないことを示してください。
