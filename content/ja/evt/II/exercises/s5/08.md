ハウスドルフ局所凸型空間では、A と B を 2 つの閉じた凸型集合とし、共通の点を持たず、$C_A \cap C_B = \{ 0 \}$ (II、p. 67、例題 14) となり、B が局所的にコンパクトになるようにします。 A と B を分離する閉じた超平面が存在することを示します ($cf.$ II、p. 67、演習 16)。同様に、A と B が頂点 0 の 2 つの閉じた凸円錐である場合、$A \cap B = \{ 0 \}$ と B が局所的にコンパクトである場合、0 を介して閉じた超平面移行が存在し、A から B を分離します (II、p. 39 の補題を使用)。
