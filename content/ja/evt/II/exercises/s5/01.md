*a*) E をベクトル空間とします。 We say that a pointed convex cone C (of vertex 0) in E is *maximal* if C is a maximal element of the set of convex pointed cones of vertex 0 and $\neq E$, ordered by inclusion. 尖った凸円錐 C が、0 を通過する超平面によって定義される閉じた半空間である場合に限り、最大であることを示します。 この結果を確立するには、最大の尖った凸円錐 C の次の特性を連続して証明します。

α) $C \cup (-C) = E$ (矛盾を得て議論する) があります。

β) $z$ が$C$ の非内部 (II、p. 26) 点の場合、$-z \in C$ (同じ方法)。 $C$ 含む内部点であると推測します。

γ) $C$ に含まれる最大のベクトル部分空間 $H = C \cap (-C)$ は超平面です。 (移行から商空間 $F = E/H$、この簡約するは、β を使用して、頂点以外の $C$ のすべての点が内部にある場合、$E$ は必ず次元 1 であることを示します。)

b) 内部点を持たない最大の非尖った凸円錐の例 (頂点 0 の非尖った凸円錐の集合内) を与えます (cf. II, p. 65、練習問題 5)。
