弱い位相 σ(R^{(N)}, R^N) を使用した空間 E = R^{(N)} を考えてみましょう。 C を、すべての n について x_n ≥ 0 となるように、点 x = (x_n) によって形成される E の閉じた凸円錐とします。
a) x = (x_n) を C の点とし、J を x_n > 0 である整数 n の有限集合とする。 m が J の元の数である場合、A を点の集合 y = (y_n) の C とし、n ∈ J および $\sum_{k\in J} y_k x_k^{-1} \leq m$ に対して y_n = 0 とします。 A が C 含む x の上限であることを示します。
b) n > 0 の場合、C が集合 nB の和集合となるようなキャップ B が C に存在しないことを示します。 (p を B から C までのゲージの制限とします。p は C で有限になります。また、(e_n) がE の標準基底では、すべての n (II、p. 58、提案 4) に対して p(e_n) > 0 であり、B に対して点 z^{(n)} = e_n/p(e_n) 属するですが、次のような z' ∈ R^N が存在することを示します。 数列 (⟨z^{(n)}, z'⟩) は有界ではありません。)
