F を加算可能数列 x = (x_n) の実数の Banach 空間 l^1(N) とし、E を 0 になる傾向のある数列 y = (y_n) の空間とします。 F に弱い位相 σ(F, E) を与えます。ここで、E と F は形 B(x, y) = ∑ x_n y_n を使用して分離双対関係にあります。
a) C を、すべての n について x_n ≥ 0 となるように、点 x = (x_n) で形成される F の凸円錐とします。 C が F で閉じていることを示します。
b) A を、$\sum^n x_n \leq 1$ となる x = (x_n) ∈ C の集合とします。 A が C の上限であり、F の上限によって誘導される位相について測定可能であること、および n > 0 の場合、C が集合 nA の和集合であることを示してください。
c) C の靴底がコンパクトではないことを示します (たとえば、集合 S は、$\sum^n z_n x_n = 1$ となる x = (x_n) ∈ C の集合になります。ここで、(z_n) ∈ E およびすべての n について z_n > 0 です。 e_m = (δ_{mn})_{n≥0} の場合、 点 $z_n^{-1} e_n$ 属するは S に移行しますが、形は比較的コンパクトな集合 F）に移行します。
d) C は、F のそれによって引き起こされる位相に対して計量可能ではないことを示します (Baire の計算を使用し、部分空間 C に対する内部点である点が A に存在しないことに注意してください)。
