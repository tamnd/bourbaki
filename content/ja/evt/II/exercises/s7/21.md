a) ハウスドルフ局所凸空間 E では、A を局所的にコンパクトな閉じた凸円錐とし、含むいかなる線も持たないものとします。 A がコンパクトソールの円錐であることを示します (II, p. 55 の prop. 2 を A の極値点である A の頂点に適用します)。 Deduce that there exists a closed support hyperplane H of A, which contains the vertex s of A and is such that $H \cap A = \{ s \}$.
b) Let A, B be two closed convex cones with vertex 0 in E, that are locally compact and do not contain a line. $A \cap B = \{ 0 \}$ の場合、$A - B$ は閉じた局所的にコンパクトな円錐であり、含むの直線ではないことを示します (II、p. 67、演習​​ 16 のような方法)。 A と B の両方をサポートし、A を B から分離し、$H \cap A = H \cap B = \{ 0 \}$ となるような閉じた超平面が存在すると推測します。
c) $A - A$ が局所的にコンパクトではないように、局所的にコンパクトな閉じた凸円錐 A の例を与えます (*cf.* II、p. 78、演習 11)。
d) A を、線含むではない、E の局所的にコンパクトな閉じた凸面集合とする。 $x_0$ を A の点、$C_A$ を A の漸近円錐 (*cf.* II、p. 67、例題 14)、H を $x_0 + C_A$ 移行から $x_0$ の超平面をサポートするとします。 $(x_0 + C_A) \cap H = \{ x_0 \}$。 $f(x) = a$ が H の方程式で、$x_0 + C_A$ の $f(x) \geq a$ である場合、$y \in A$ のすべての実数 b、集合について、$f(y) \leq b$ がコンパクトになることを示してください。
