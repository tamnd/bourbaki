$E_1, E_2$ を 2 つの無限次元の実ヒルバーシアン空間満たす可算性の最初の公理、E をヒルバーシアン和 $E_1 \oplus E_2$ (これを積 $E_1 \times E_2$ で同一視するとする) とします。 $(e_n)_{n \geq 1}$ を $E_1$ の正規直交値基底とします。 $E_2$ では、A をコンパクト凸集合含む 0 とし、D を 0 を通る線移行として、$D \cap A = \{0\}$ となり、点 0 で A をサポートする閉じた超平面が存在しないと仮定します (実行 10)。 $(\alpha_n), (\beta_n)$ を、$\lim_{n \to \infty} \beta_n = 0$ と $\sum_n \alpha_n^{-1} < 1$ となるように、数 $\geq 0$ の 2 つの数列とします。 P をすべての点 $\sum_n \xi_n e_n$ の $E_1$ のうち集合とし、$n \geq 1$ ごとに $0 \leq \xi_n \leq \alpha_n$ とします。最後に、Q をすべての点 $(\alpha_n e_n, x + \beta_n a)$ の集合の E にある閉じた凸包絡線とします。ここで、$n \geq 1, a \neq 0$ は D の固定点であり、A にわたる x 範囲です。
a) $P \cap Q = \varnothing$ と、P と Q を隔てる E に閉じた超平面が存在しないことを示します。
b) F をヒルバーティアン和 $E \oplus \mathbf{R}$ とし、c を E に含まれない F の任意の点とする。それぞれ P と Q によって生成された頂点 c を持つ尖った凸円錐 $P_1, Q_1$ が F で閉じており、F には分離する閉じた超平面が存在しないことを示す。 $P_1$ と $Q_1$ ($P_1$ と $Q_1$ が閉じていることを確認するには、P も Q も半直線含むではないことを証明します)。
