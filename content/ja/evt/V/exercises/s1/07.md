E を実数または複素ノルム空間とし、次元 $\geq 2$ を持ち、以下の性質を持ちます。 0 および $\pm 1$ とは異なる実数 $\gamma$ が存在し、関係 $\|x + y\| = \|x - y\|$ は $\|x + \gamma y\| = \|x - \gamma y\|$ を意味します。
a) $\|x + y\| = \|x - y\|$ の場合、$\mathbf{R}$ から $\mathbf{R}$ への凸写像 $\phi : \xi \mapsto \|x + \xi y\|$ は、どの区間でも一定ではないことを示します。 (不合理な還元による議論; $[\alpha, \beta]$ を $\phi$ が定数である最大の区間とすると、$\beta$ に十分近く、$\phi(\delta) = \phi(\beta)$ である$\delta > \beta$ が存在することを示し、$\|u + v\| = \|u - v\|$ であれば、観察するとまでに、次に、すべての有理数整数 $n$ に対して $\|u + \gamma^n v\| = \|u - \gamma^n v\|$ となります。)
b) $\|x + y\| = \|x - y\|$ の場合、実数 $\xi$ ごとに $\|x + \xi y\| = \|x - \xi y\|$ になることを示します。 (a の記法について)、すべての有理数整数 $n$ に対して $\phi(\gamma^n) = \phi(-\gamma^n)$ であるという事実を使用して、$\phi$ が点 $\xi = 0$ に相対最小値を持つことを観察します。同様に $\phi(\xi) = \phi(-\xi)$ があると推測します。そうでない場合、2 つの数 $\lambda, \mu$ に対して $\phi(\lambda) = \phi(\mu)$ が得られ、$\lambda + \mu \neq 0$ となり、この場合 $\phi$ は点 $\frac{1}{2}(\lambda + \mu)$ に相対最小値があります。)
c) b) から、E 上のノルムはプレヒルバーティアンであると推測します ($\|x\| = \|y\|$ の場合、実数 $\alpha, \beta$ のすべての対に対して $\|\alpha x + \beta y\| = \|\beta x + 2y\|$ があり、等式 $\|x + y\| = \|x - y\|$ はすべての$\|\alpha x + \beta y\| = \|\alpha x - \beta y\|$ を意味します。 実数 $\alpha, \beta$ の対。 次に、前の結果を使用して、$\|x\| = \|y\| = 1$ と $\|x + y\| = \|x - y\|$ の場合、関係 $\|(\alpha^2 - \beta^2)x + 2\alpha\beta y\| = \alpha^2 + \beta^2$ が成り立つことを示し、結論を導き出します。
