E を無限次元ヒルベルト空間とし、$p, q$ を 2 整数 $\geq 1$ とします。 $p' = \left[ \frac{p}{2} \right], q' = \left[ \frac{q}{2} \right]$ (整数部分) とします。 $\hat{\Lambda}^p(E) \times \hat{\Lambda}^q(E)$ から $\hat{\Lambda}^{p+q}(E)$ への双線形写像 $(u, v) \mapsto u \wedge v$ のノルムが少なくとも $\left( \frac{(p'+q')!}{p'! \ q'!} \right)^{1/2}$ に等しいことを示します。 ($p = 2p'$ と $q = 2q'$ が偶数の場合、正規直交基底 $(e_j)_{1 \leq j \leq 2n}$ を持つ 2n 次元の E の部分空間 $E_n$ を考慮します。$1 \leq j \leq n$ を $e'_j = e_{2j-1} \wedge e_{2j}$ とします。積 $u \wedge v$ を考慮します。 $u = \sum_H e'_H$、$v = \sum_{\mathbf{K}} e'_\mathbf{K}$ ここで、$\mathbf{H}$ (それぞれ $\mathbf{K}$) は、すべての $p'$ の部分集合 (それぞれ $q'$) の集合 、$\{1, 2, ..., n\}$ の元の範囲に及びます。
$i_1 < ... < i_p$ (それぞれ $j_1 < ... < j_q$) が $\mathbf{H}$ (それぞれ $\mathbf{K}$) の元の増加する数列の場合、$e'_\mathbf{H} = e'_{i_1} \wedge ... \wedge e'_{i_p}$ (それぞれ $e'_\mathbf{K} = e'_{j_1} \wedge ... \wedge e'_{j_q}$)。 $\Lambda(\mathbf{E})$ できないの乗法は連続性により $\hat{\Lambda}(\mathbf{E})$ まで拡張されると推測します。)
