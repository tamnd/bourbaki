$(a_{ij})_{(i,j) \in I \times I}$ を複素数の可算無限二重族とする。 2 つの数 $\beta > 0$、$\gamma > 0$ と、数 $> 0$ 満たす関係の家族 $(p_i)_{i \in I}$ が存在すると仮定します。
(*) $$
\sum_i p_i |a_{ij}| \leq \beta p_j, \quad \sum_j |a_{ij}| p_j \leq \gamma p_i
$$
$I$ のすべての $i, j$ に対して。
a) $\ell^2_c(I)$ からノルム $\leq (\beta \gamma)^{1/2}$ までの連続自己準同型 $u$ が存在し、$\ell^2_c(I)$ のすべての $x = (x_i)_{i \in I}$ に対して $u(x) = y$ が得られます。ここで、$y = (y_i)$ は $y_i = \sum_j a_{ij} x_j$ で与えられます ( $\mathbf{C}^I$ に $x = (x_i)$ と $y = (y_i)$)、$v_{ij} = |x_i| (p_j |a_{ij}| / p_i)^{1/2}$、$w_{ij} = |y_j| (p_i |a_{ij}| / p_j)^{1/2}$ を入れて、$\sum_{i,j} v_{ij} w_{ij}$ の境界を見つけます。
b) $I$ の場合、すべての整数 $\geq 1$ のうち集合を取り、$a_{ij} = (i + j)^{-1}$ とします。 条件 (*) が $p_i = i^{-1/2}$ と $\beta = \gamma = \pi$ (これらは考えられる最良の定数) を満たしていることを示します ((*) の系列を積分と比較します)。 同様の方法で、$I = \mathbf{N}$ と $a_{ij} = (i + j + 1)^{-1}$ (「ヒルベルトの行列」) の場合を扱います。
\* c) $\mathscr{H} = \mathbf{H}^2(D)$ を、すべての写像 $f(z) = \sum_{n=0}^\infty a_n z^n$ の *Hardy 空間*、からなるとし、オープンディスク $D : |z| < 1$ などの $\|f\|^2 = \sum_n |a_n|^2 < +\infty$ を分析します。このとき、$\|f\|$ は $\mathscr{H}$ 上のノルムであり、$\mathscr{H}$ は $\ell^2_c(\mathbf{N})$ と同型です。 $\mathscr{H}$ に 2 つの写像 $f, g$ が与えられた場合、実変数 $t$ の写像 $t \mapsto f(t) g(t)$ がルベーグ測度に関して $[0, 1]$ で積分可能であること、および公式 $B(f, g) = \int_0^1 f(t) g(t) \, dt$ 定義するが連続であることを示します。 $\mathscr{H} \times \mathscr{H}$ の双線形形式 (形 $f(z) = \sum_{n=0}^N a_n z^n$ の写像 $f \in \mathscr{H}$ に対する $B(f, f) = \int_0^1 f(t)^2 \, dt$ と、$0 \leq n \leq N$ に対する $a_n \geq 0$ を考慮します。コーシーの定理を使用して関係を確立します
$$
\int_{-1}^1 f(t)^2 \, dt = -i \int_0^\pi f(e^{i\theta})^2 e^{i\theta} d\theta
$$
そこから $B(f, f) \leq \frac{1}{2} \int_{-\pi}^\pi |f(e^{i\theta})|^2 d\theta = \pi \|f\|^2$ が得られます。 このようにして、b) の結果を取得します。これに従って、ヒルベルト空間 $\ell^2_c(\mathbf{N})$ のヒルベルトのノルム $\leq \pi$ の行列定義する自己準同型が求められます。)
