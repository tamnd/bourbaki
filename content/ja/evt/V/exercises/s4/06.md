$E$ をヒルバーシアン空間、$M, N$ $E$ と $M^{\circ}, N^{\circ}$ のそれぞれの直交補数の 2 つの閉じた部分空間とします。 $p_M, p_N$ は、それぞれ $M$ と $N$ 上の直交射影を表し、$1_E - p_M, 1_E - p_N$ はそれぞれ $M^{\circ}$ と $N^{\circ}$ 上の直交射影となります。 $u_{NM} = (1_E - p_N) p_M$ と $\delta(M, N) = \|u_{NM}\|$ を入れます。 $\delta(M, N) = \delta(N^{\circ}, M^{\circ}) \leq 1$があります。 関係 $\delta(M, N) < 1$ は $M \cap N^{\circ} = \{0\}$ を意味します。
a) $\tilde{M}$ を $M \cap N^{\circ}$ の $M$ の直交補数を表し、$\varepsilon(M, N) = \delta(\tilde{M}, N)$ とします。 (演習 5 の記法を使用して) $\ell(u_{NM}) = M \cap N^{\circ}$ を示し、$\varepsilon(M, N) = \langle u_{NM} \rangle \leq \delta(M, N)$ を推測します。さらに、$M \cap N^{\circ} = \{0\}$ の場合 (特に $\delta(M, N) < 1$ の場合)、$\varepsilon(M, N) = \delta(M, N)$ です。
b) $E$ からそれ自体への連続線形写像 $u$ については、$u$ 数 $c(u) = \inf \|u(x)\| / \|x\|$ の *conorm* によって指定します。ここで、$x$ はすべてのベクトル $\neq 0$ の集合を超えます。 $u^{-1}(0)$ に直交します ($u = 0$ の場合は、$c(u) = 1$ を置きます)。 $u(E)$が$E$でクローズされるためには、$c(u) > 0$(I、p. 17、th.1)が必要かつ十分です。 $c(u^*) = c(u)$ があります。
c) $v_{NM} = p_N p_M$ とします。それを見せてください
$$
\varepsilon(M, N)^2 + c(v_{NM})^2 = 1
$$
($\|u_{NM}(x)\|^2 + \|v_{NM}(x)\|^2 = \|p_M \cdot x\|^2$ と、$v_{NM}$ の核が $M^{\circ} + (M \cap N^{\circ})$ であることに注目し、$\langle u_{NM} \rangle^2 \leq 1 - c(v_{NM})^2$ を推測します)。
d) b) と c) から $\varepsilon(N, M) = \varepsilon(M, N)$ を推定し、a) を使用して $\varepsilon(M^{\circ}, N^{\circ}) = \varepsilon(M, N)$ を推定します。
e) $g(M, N) = \|p_M - p_N\|$ (*cf.* V、p. 64、練習問題 17) を入力します。それを見せてください
$$
g(M, N) = \sup(\delta(M, N), \delta(N, M))
$$
($p_M - p_N = (1_E - p_N) p_M - p_N (1_E - p_M)$ に注目してください); $\varepsilon(M, N) \leq g(M, N)$ と推測します。 $M \cap N^{\circ} = N \cap M^{\circ} = \{0\}$ の場合、関係 $\varepsilon(M, N) = \delta(M, N) = \delta(N, M) = g(M, N)$ になります。 $g(M, N) < 1$の場合は、$M \cap N^{\circ} = N \cap M^{\circ} = \{0\}$。
f) $Q_M, Q_N$ を $E$ の 2 つの連続する射影とし、それぞれ像 $M$ と $N$ とする。 関係 $g(M, N) \leq \|Q_M - Q_N\|$ のうち他の証明を与えます (V、p. 64、練習問題 17)。 (すべての $x \in E$ に対して、$\|(1_E - Q_M) \cdot x\|^2 + \|Q_M^* \cdot x\|^2 = \|x\|^2 + \|(Q_M - Q_M^*) \cdot x\|^2$ があり、この関係を $x = (p_M - p_N) \cdot y$、観察すると関係 $(1_E - Q_M) (p_M - p_N) = (Q_M - Q_N) p_N$、$(p_M - p_N) Q_M = (1_E - p_N) (Q_M - Q_N)$ に適用することに注意してください。)
