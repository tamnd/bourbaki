合計順序で$X$を集合とします。 $X$ に対してホール集合が存在し、$H \cap M^3(X)$ が積 $z(yx)$ と $y < x$、$y \leqslant z$ で構成され、$H \cap M^4(X)$ が積 $w(z(yx))$ と $w \geqslant z \geqslant y$ で構成されることを示します。 $y < x$ と積 $(ab)(cd)$ と $a < b, c < d$ と $a < c$ または $a = c$ と $b < d$。
