⁷ $A$ を $\mathfrak{P}(A)$ の集合と $\mathscr{C}$ 部分集合とします。 $\mathscr{C}$ の元は $A$ のチャンバーと呼ばれ、$C$ のチャンバーの部分集合 $F$ はファセットと呼ばれ、$C$ の $F$ の共次元は $C - F$ の基数です。 ファセット $F$ は、$F$ が $C$ の共次元 1 である場合、$C$ のパネルであると言われます。 2つの部屋$C$と$C'$は隣接していると言われています

⁷ 練習問題 15 から 24 と § 2 の練習問題 3 から 17 はこれまで未公開であり、J. ティッツから私たちに伝えられました。

共通のパネル F がある場合: C = C' または F = C ∩ C'。 長さ n のギャラリーは、$C_i$ と $C_{i+1}$ が $0 \leq i \leq n - 1$ で隣接しているように、$n + 1$ 室の数列 $\Gamma = (C_0, C_1, \ldots, C_n)$ です。そして、$C_0$と$C_n$は$\Gamma$の端と呼ばれます。 $0 \leq i \leq n - 1$ に対して $C_i \neq C_{i+1}$ の場合、ギャラリー $\Gamma$ は単射的と呼ばれ、同じ端を持つギャラリーがなく、長さ < n の場合は極小と呼ばれます。

集合 A ($\mathscr{C}$ と合わせて) は、属するの元ごとに少なくとも 1 つの部屋があり、いずれかの 2 つの部屋がギャラリーの端にある場合、建物です。 2 つの部屋 C と C' の間の距離は、端が C と C' である最小ギャラリーの長さ $d(C, C')$ です。

建物 A の子建物は A の部分集合 D であり、D と$\mathscr{C} \cap \mathfrak{P}(D)$ が建物になります。

a) A が建物の場合、ファセットはそれを含むすべての部屋で同じ寸法を持つことを示します。これにより、特定のチャンバーを参照せずに、ファセットと A のパネルの共次元について話すことができます。 建物 B から A への射は、B から A への写像 $f$ であるため、B のすべての部屋 C への $f$ の制限は、A の C からの部屋 $f(C)$ への全単射になります。 B のファセットの $f$ の下の像が同じ共次元のファセットであることを示します。

b) すべてのパネルがちょうど 2 つの部屋に含まれている場合、その建物はアパートと呼ばれます。 A がアパートの場合、部屋のすべての点を固定したままにする A のすべての自己同型 (つまり、$\mathscr{C}$ を保存する A のすべての置換) がアイデンティティであることを示します。より一般的には、$\varphi$ を A の自己準同型とし、C をすべての $a \in C$ に対して $\varphi(a) = a$ となるような A の部屋とします。 $(C, C_1, \ldots, C_n)$ を A のギャラリーとします。ギャラリー $(C, \varphi(C_1), \ldots, \varphi(C_n))$ が単射的でないこと、または $C_i$ のすべての $a$ 所属から和集合に対して $\varphi(a) = a$ のいずれかであることを示します。
