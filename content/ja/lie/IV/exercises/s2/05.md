Σ = (G, B, N, S) をおっぱい系とします。 T = B ∩ N と置き、Ċ を N の正規化子とします。

a) b ∈ B ∩ Ċ とします。すべての n ∈ N に対して bnb^{-1}n^{-1} ∈ B ∩ N (bn = n'b と置き、Th. 1 を使用) と、n ∈ N に対して共役 nBn^{-1} の b 属するから共通部分 Ğ であることを示します。Ğ ∩ N = T であることを示します。

Ğ = T の場合、Σ は飽和していると言われます。

b) Ċ̃ = N.Ġ̃ と置きます。 Ċ̃ は通常の部分群としての G 含む Ġ̃ の部分群であり、Ċ̃ ∩ B = Ġ̃ であることを示します。 Σ のワイル群 W から Ċ̃/Ġ̃ まで、N の単射が Ċ̃ 定義する同型になることを示してください。

c) (G, B, Ċ̃, j(S)) が飽和シジュウカラ系であり、Σ に関連付けられていると言われていることを示します。
