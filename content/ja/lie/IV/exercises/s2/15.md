Exerc の仮説と記法を使用します。 10. さらに、$(G, B)$ のワイル群 W が有限であり、W の最長元を$w_0$ で表すと仮定します (§ 1、例題 22)。 $t(C, C') = w_0$の場合、Cと$C'$の2議院が対立すると言われています。

a) C と C' が対立する場合、C' と C も対立することを示します。任意のチャンバー C に対向するチャンバーが存在することを示します。 G の室 C の固定群が、C と反対の部屋の集合に推移的に作用することを示してください。

b) C と C を 2 つの対立する議場とする。すべての $w \in W$ に対して、次の性質を持つ固有のチャンバー $C_w$ が存在することを示します。$(s_1, \ldots, s_k)$ (それぞれ $(s'_1, \ldots, s'_h)$) が w (それぞれ $w' = w_0 w^{-1}$) の縮小分解である場合、型の最小ギャラリー $(C_0 = C, C_1, \ldots, C_n = C')$ が存在します。 $(s_1, \ldots, s_k, s'_1, \ldots, s'_h)$ ($n = h + k$ を使用) は、$C_{w'} = C_k$ (§1 の演習 22 と演習 10、d) および e) を使用します)。 $C_w$ と $C_{w w_0}$ が対立していることを示します。

c) $\mathscr{M}$ を対立する議院の対のうち集合とする。 $m = (C, C') \in \mathscr{M}$ について、$A_m$ を上で構築した部屋 $C_w$ の和集合とします。 $m \in \mathscr{M}$ に $A_m$ の集合 $\mathscr{U}$ を備えた I が構造化された建物 ($§ 1$、演習 24) であること、および Coxeter 系 $(W, S)$ と I の番号付けが、 $(I, \mathscr{U})$; 定義する $\mathscr{M}$ から集合までの正規の全単射は、Exerc の $J$ で示されます。 $§ 1$の24。私たち同一視するこの二人集合です。

d) $m = (C, C') \in \mathscr{M}$ を $C = C_e$ とし、N を G の $A_m$ の固定群とします。 $N/(B \cap N)$ は W と識別でき、$(G, B, N, S)$ は飽和したシジュウカラ系であることを示します (演習 13 を使用)。
