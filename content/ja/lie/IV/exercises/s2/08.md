$(G, B, N, S)$ をおっぱい系とします。 $T = B \cap N$と$W = N/T$を入れます。 $\tilde{G}$ を通常の部分群として群含む G とします。すべての $h \in \tilde{G}$ に対して、$hBh^{-1} = gBg^{-1}$ と $hNh^{-1} = gNg^{-1}$ のような $g \in G$ が存在すると仮定します。 $\hat{B}$ (それぞれ $\hat{N}$) を $\tilde{G}$ の B (それぞれ N) の正規化子とします。 $\Gamma = \hat{B} \cap \hat{N}$、$\tilde{N} = \Gamma N$、$\tilde{T} = \tilde{N} \cap B$を入れます。

a) $\tilde{G} = \Gamma.G$、$\hat{B} = \Gamma.B$、$\Gamma \cap B = \Gamma \cap G$、$\tilde{T} = (\Gamma \cap B).T$ を示してください。したがって、群 $\Omega = \Gamma/(\Gamma \cap B)$、$\tilde{G}/G$、および $\hat{B}/B$ は標準的に同型です。 $\Phi \subset \Omega$ で、H が G 含む $\Gamma \cap B$ の部分群である場合、$\varphi \in \Phi$ を部分集合 $\varphi H$ の $\Phi H$ 和集合で表します。

b) $\tilde{N}$ で $\tilde{T}$ が正常であることを示します ($n \in \tilde{N}$ と $\gamma \in \Gamma \cap B$ で $n \gamma n^{-1} \in \tilde{N}$ を示すには、演習 5 a) を使用します)、$N \cap \tilde{T} = T$ および $\Gamma \cap \tilde{T} = \Gamma \cap B$ で正常であることを示します。したがって、N の単射 (それぞれ $\Gamma$) を $\tilde{N}$ にすると、W (それぞれ $\Omega$) を $\tilde{W} = \tilde{N}/\tilde{T}$ の部分群と識別できます。 $\Omega$ が S を正規化し、$\tilde{W}$ が $\Omega$ と W の半直接積であることを示してください。

c) すべての $s \in S$ とすべての $u \in \tilde{W}$ について、

$$
BsBuB \subset (BuB) \cup (BsuB).
$$

d) 写像 $u \mapsto BuB$ が $\tilde{W}$ から $B \setminus \tilde{G}/B$ までの全単射であることを示します (Th. 1 と $\Gamma$ が B を正規化するという事実を使用します)。

e) $\mathscr{B}$ を対 $(\Phi, X)$ の集合とします。ここで、$\Phi$ は $\Omega$ の部分群で、X は $\Phi$ で正規化された X の部分集合です。 $G_{(\Phi, X)} = \Phi G_X = B \Phi W_X B$を入れます（no. 5の記法と）。 写像 $(\Phi, X) \mapsto G_{(\Phi, X)}$ が $\tilde{G}$ 含むの部分群の $\mathscr{B}$ から集合までの全単射であることを示します。 B. Th の主張 b) と c) を一般化します。 no. 5の3および提案2。

$\tilde{G}$ の $G_{(\Phi, X)}$ の正規化器が部分群 $G_{(\Phi', X)}$ であることを示します。ここで、$\Phi'$ は、$\Phi$ と X の両方を正規化する $\Omega$ の元の集合です。

f) 次の 2 つの条件のうちの 1 つが満たされる場合に限り、$G_{(\Phi, X)}$ が $\tilde{G}$ の最大値部分群であることを示します。

(i) $X = S$ と $\Phi$ は、$\Omega$ の最大部分群です。

(ii) $\Phi = \Omega$ と $\Phi$ は、$S - X$ (空ではない) に対して推移的に動作します。

$G_{(\Phi, X)}$ が含む $G$ ではなく、$\tilde{G}$ の部分群の集合における最大部分群であることを示します。

(iii) $X \neq S$、$\Phi$ は、$\Omega$ の $X$ の正規化子であり、$S - X$ に対して推移的に作用します。

g) $\Phi$ を $\Omega$ の通常の部分群とし、$G' = \Phi G$、$B' = \Phi B$、$N' = \Phi N$、$T' = B' \cap N'$ を置きます。 $\Phi$ のすべての元が $W$ のすべての元と交換する場合に限り、$N'$ では $T' = \Phi \tilde{T}$ と $T'$ が正常であることを示してください。 $G'$ が $\tilde{G}$ で正常であること、$N$ の単射が $N'$ 定義する同型 $j$ で $W$ から $W' = N'/T'$ になり、$(G', B', N', S')$ であることを示します ( $S' = j(S)$) はおっぱい系です。
