Exerc の仮説と記法を保持します。 15.

a) C と C' を 2 つのチャンバーとします。 C と C' の両方に反対する議院 $C''$ が存在することを示します (C に反対する $C''$ を取ると、$t(C, C')$ は最大の可能性があります長さ; $t(C', C'') \neq w_0$ の場合、隣接する議院 $C_1$ が存在します$C''$ は、$l(t(C', C_1)) > l(t(C', C''))$ であることを示します。Exerc 10 の条件 (G) を使用すると、$C_1 \notin A_{(C, C'')}$ と $C_1$ が C に対立すると仮定できます。

b) $a \in \mathscr{U}$ とします。 A のすべてのチャンバーを反対側のチャンバー ($§ 1$ の練習問題 22 c を使用) に導く一意の包含自己同型 $j_A$ (必ずしも許可されるわけではない) が存在することを示します。 F と F' を I の 2 つの面とする。いくつかの $A \in \mathscr{U}$ 含む F と F' に対して $F' = j_A(F)$ がある場合、同じことがすべての $A \in \mathscr{U}$ 含む F と F' にも当てはまることを示します ($F, F' \in A \cap A'$ と $A, A' \in \mathscr{U}$ の場合、チャンバー C (それぞれ C') を考慮します)。 A (それぞれ A') 含む F (それぞれ F') と $A'' \in \mathscr{U}$ 含む C および C' を使用します (SB 3))。このとき、F と F' は対立していると言われます。 2 つのファセットが同じ型 T である場合に限り、2 つのファセットが共通の反対のファセットを持つこと、および型 T のファセットの反対側のファセットが型 $w_0 T w_0^{-1}$ であることを示します。

c) $A_0$ を Coxeter 系 $(W, S)$ ($§ 1$、例題 16) に関連付けられたアパートメントとし、$\mathscr{J}$ を $A_0$ からさまざまな元まで許可された同型の集合とします。 $\mathscr{U}$。 $\alpha$ が $A_0$ の半分で、壁 L がある場合 ($§ 1$、練習問題 16)、$\varphi \in \mathscr{J}$ の場合、$\varphi(\alpha)$ は壁 $\varphi(L)$ を持つ I の半アパートであると言います。 $\varphi(L)$ は対 $(\varphi, \alpha)$ には依存せず、$\varphi(\alpha)$ のみに依存することを示します。 $D_1$ と $D_2$ を、同じ壁 L を持つ 2 つの別個の半アパートメントとします。$\varphi \in \mathscr{J}$ と $A_0$ の壁 $L_0$ が存在し、その下に $L = \varphi(L_0)$ と $D_i$ が像であることを示します。 $L_0$ によって決定される $A_0$ の 2 つの半分の $\varphi$ (選ぶ $L$ に含まれるパネル $F$ と 2 つのチャンバー $C_1$ と $C_2$、1 つは $D_1$ に含まれ、もう 1 つは $D_2$ に含まれ、 $C_1$ 含む $F$ と $C_2$ 含むのパネルは、$D_1$ で $F$ に反対し（$D_2$ では $F$ にも反対）、$I$ のアパートを検討します。 含む $C_1$ および $C_2$)。
