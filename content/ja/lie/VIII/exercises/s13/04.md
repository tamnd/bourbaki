$S$ を位数 $n$ の平方行列とします

0 0 $\cdots$ 0 1

0 0 $\cdots$ 1 0

$(\delta_{i,n+1-i}) =$ ... ... 。 .. ... ....

0 1 $\cdots$ 0 0

1 0 $\cdots$ 0 0

$\mathfrak{o}_S(n, k)$ の元は、2 番目の対角線に関して反対称である行列 $(a_{ij})$ です。

対 $(i, j)$ ごとに $a_{i,j}=-a_{n+1-j,n+1-i}$。

代数 $\mathfrak{o}_S(n, k)$ は、$n$ が偶数で $\geq 6$ の場合、型 $D_{n/2}$ と、$n$ が奇数で $\geq 5$ の場合、型 $B_{(n-1)/2}$ の単純な分割可能です。 $\mathfrak{o}_S(n, k)$ 形分裂カルタン (ボレル) 部分代数の対角線 (上三角) 元。
