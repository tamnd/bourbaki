(a) K = $\mathbf{R}$ または $\mathbf{C}$ または特性 > 0 の剰余体を持つウルトラメトリック体とします。G を K 上のリー群とし、U を L(G) および $\phi : U \to G$ 写像の 0 の開いた近傍とします。 0 で微分可能で、$U$ の $\lambda b,\ \lambda'b,\ (\lambda + \lambda')b$ に対して $\phi(0) = e,\ T_0(\phi) = \mathrm{Id}_{L(G)}$ と $\phi((\lambda + \lambda')b) = \phi(\lambda b)\phi(\lambda'b)$ が成り立ちます。次に、指数関数写像を使用した 0 の近傍上の $\phi$ 一致するです。

(b) $k$ を特性 0 の体とします。$K$ を特性 0 の値体 $k((X))$ とします。$G$ を加法リー群 $k[[X]]$ とします。 $\phi$ を、整数 $n \geqslant 0$ ごとに $\phi(X^n) = X^n + X^{2n}$ となるような、$G$ の $G$ への連続 $k$ 線形写像とします。この場合、$\phi$ は (a) の条件を満たしますが、指数関数写像を持つ 0 の近傍には一致するが満たされます。
