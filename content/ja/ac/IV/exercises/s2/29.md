A を強いラスケリアン環 (練習問題 28) とする。

(a) a、b を A の 2 つのイデアル、ab = \bigcap_{i=1}^{n} q_i とし、A の ab の縮小主分解と、根基が含む b にならない q_i の c 共通部分とします。 a \部分集合 c (q_i がその根号 p である場合、 含む b および x \in b および x \not p_i ではない場合、積 ax を考慮してください)。

(b) (a) から、a^s \部分集合 a'、b^s \部分集合 b'、(a + b)^s \部分集合 c となるような 3 つの理想 a'、b'、c および整数 s > 0 が存在することを推定します。

ab = a' \cap b = a \cap b' = a \cap b \cap c。

(c) A のイデアルのすべての有限族 (a_k) について、 \bigcap_k a_k^m \部分集合 \prod_k a_k となるような整数 m > 0 が存在することを示します (イデアル a_k の数に帰納法による議論 (b) を適用します)。

(d) A のすべてのイデアル a について、 共通部分 b = \bigcap_{n=1}^{\infty} a^n が x \in xa となるような x \in A のイデアルであることを示します ((b) を積 (Ax)a に適用します)。 b は、根基が 1 + a を満たす、{0} の主要な成分の共通部分 ({0} の縮小された主要な分解の場合) であると推定します。

(e) (d) から、A のすべての素イデアル p について、n \in \mathbf{N} に対するシンボリック冪 p^{(n)} (練習問題 18 (b)) の共通部分は、x \in xp (環 A_p を考慮) となる x \in A のイデアルであると推定します。
