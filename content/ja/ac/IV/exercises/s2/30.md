M を A-加群とし、N を M の部分加群とし、縮小プライマリー 分解 N = \bigcap_{i=1}^{n} Q_i; を認めます。 p_i を Q_i に関連付けられた主イデアルとする。

(a) b が p_i のいずれにも含まれない A のイデアルである場合、N : b = N (cf. 練習問題 17) であることを示します。

(b) 各 Q_i が M において強く一次である場合、逆に、N : b = N の場合、b はどの p_i にも含まれないことを示します。 (b \部分集合 p_i かつ P = \bigcap_{j \neq i} Q_j の場合、適切な整数 r に対して b^rP \部分集合 N となり、N : b = N の場合、P = N であると推測できることに注意してください。) N : (\beta) = N となる \beta \in b が存在すると推測します。
