$A$ をラスケリアン環とします。 $a$ を $A$ の理想とし、$a = \bigcap_{1 \leq i \leq n} q_i$ を $A$ の $a$ の削減された主要な分解とします。 $p_i$ は $q_i$ の根基を表します。 $\mathrm{Ass}_f(A/a)$ の最小の元が $1 \leq i \leq s$ と $s < n$ のような $p_i$ であるとします。 $b = \bigcap_{1 \leq i \leq s} q_i, c = \bigcap_{s+1 \leq i \leq n} q_i$と書きます。

(a) $1 \leq i \leq s$ に対して $x \notin p_i$ があり、$a = b \cap (a + Ax)$ となるような $x \in c$ が存在することを示します。

(b) たとえば、$p_{s+1}$ が $\mathrm{Ass}_f(A/c)$ で最小であると仮定します。 $xp_{s+1} + a \neq Ax + a$ と $a = b \cap (xp_{s+1} + a)$ を表示します。さらに、$p_{s+1}$ は $\mathrm{Ass}_f(A/b)$ で最小であり、ここで $b = xp_{s+1} + a$ です。 $p_{s+1}$に対する$b$の彩度が$q''_1$とは異なることを示してください。 (この彩度はできない含む $x$ であることに注意してください。)
