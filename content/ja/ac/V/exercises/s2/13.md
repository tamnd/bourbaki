(a) $K$ を特性 0 の体とし、$Y^2 - X^2 - X^3$ によって生成された多項式環 $K[X, Y, Z]$ の理想値を $n$ とします。 $n$ が素数であり、整域 $A = K[X, Y, Z]/n$ が積分閉ではないことを示します: $x, y, z$ が $A$ の $X, Y, Z$ の像である場合、元 $t = y/x$ of 体 of 分数 $A$の$L$は$A$に関しては積分ですが、属するから$A$までは積分しません。 $A' \supseteq A$ を $L$ の部分環 $K[x, t, z]$ とし、$A$ の積分とします。 $A$ で、$xz - y$ と $z^2 - 1 - x$ によって生成された素イデアル $p$ と、$x, y, z - 1$ によって生成された最大イデアル $q \supset p$ を考えてみましょう。一方、$A'$ では、$x, t + 1$ と $z - 1$ によって生成される最大理想$q'$ を考えてみましょう。 $q'$ は $q$ の上にあるが、$p$ の上にある$A$ の主理想$p' \subset q'$ は存在しないことを示します。 ($K$ の $A'/pA'$ から拡大体までの準同型を考え、そのような準同型の下で $q'$ の像は必ず 0 になることを示します。)

(b) $2X$ と $X^2 - X$ によって生成される理想 $n$ により、$A'$ を多項式環 $\mathbf{Z}[X]$ の商環とします。 $x$ を $A'$ の $X$ の像とします。 $A'$ は $\mathbf{Z}$ に対して整数ですが、数 2 は $A'$ の 0 の因子です。 $q'$ を 2 と $x - 1$ によって生成される $A'$ の主イデアルとします。それから$q' \cap \mathbf{Z} = 2\mathbf{Z}$; $p$が$\mathbf{Z}$の素イデアル(0)である場合、$p$の上にある$A'$に含まれる素イデアル$p' \subset q'$が存在しないことを示します。

(c) $K$ を体, $n$ の $X^2, XY, XZ, YZ - Y$ と $Z^2 - Z$, $A'$ 商環 $K[X, Y, Z]/n$, $x, y, z$ 像によって生成される多項式環 $K[X, Y, Z]$ の理想とする$A'$ と $A$ の部分環 $K[x, y]$ の $A'$ の $X, Y, Z$。 $A$ は分数の合計環で積分的に閉じており、$A'$ は $A$ にわたって積分です。 $A$ で、$x$ によって生成された素理想値 $p$ と、$x$ と $y$ によって生成された最大理想値 $q$ を考えてみましょう。一方、$A$ では、$x, y, z$ によって生成された最大理想$q'$ について考えてみましょう。 $q'$ は $q$ の上にあるが、$p$ の上にある主理想$p' \subset q'$ は存在しないことを示します ((a) と同じ方法)。

(a) と (c) の例を幾何学的に解釈します。 \*
