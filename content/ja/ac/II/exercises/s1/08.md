(a) a、b を環 A の 2 つの互いに素なイデアルとします。a: b = a、b: a = b であることを示します。 c が ac ⊂ b となるような A のイデアルである場合、c ⊂ b となります。

(b) p、q を、どちらも他方に含まれない 2 つの素イデアルとする。 p: q = p および q: p = q 多項式環 A = K[X, Y ] (K は体) における 2 つの主素数イデアル p, q の例を与えます。どちらも他方に含まれず、互いに素ではありません。

(c) a を A の 0 の因子ではない元とします。主イデアル p = Aa が素数である場合、2 つのイデアル b、A の c に対して関係 p = bc が b = A または c = A を意味することを示します。
