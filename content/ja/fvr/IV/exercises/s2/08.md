$G$ を、体 $\mathbf{R}$ に対して単位元 $\mathbf{e}$ を加えた完全なノルム代数とします。

a) $t \mapsto \mathbf{a}(t)$ を、$G$ の値で区間 $J \subset \mathbf{R}$ の規制された写像とします。 点 $t_0 \in J$ で値 $\mathbf{e}$ をとる線形方程式 $d\mathbf{x}/dt = \mathbf{a}(t)\mathbf{x}$ の積分 $\mathbf{u}$ は $J$ で可逆であり、その逆数は方程式 $d\mathbf{x}/dt = -\mathbf{x}\mathbf{a}(t)$ の解 ($\mathbf{v}$ が積分の場合) であることを示してください。 点 $t_0$ で値 $\mathbf{e}$ を取るこの最後の方程式の、$\mathbf{uv}$ と $\mathbf{vu}$ によって満たされる線形方程式を考慮してください。すべての $\mathbf{x}_0 \in G$ について、点 $t_0$ で値 $\mathbf{x}_0$ を取る$d\mathbf{x}/dt = \mathbf{a}(t)\mathbf{x}$ の積分は、$\mathbf{u}(t)\mathbf{x}_0$ に等しいと推定します。

b) $\mathbf{a}(t), \mathbf{b}(t)$ を、$J$ で 2 つの調整された写像とし、$\mathbf{u}$ と $\mathbf{v}$ を、点 $t_0$ で値 $\mathbf{e}$ をとった方程式$d\mathbf{x}/dt = \mathbf{a}(t)\mathbf{x}, d\mathbf{x}/dt = \mathbf{x}\mathbf{b}(t)$ の積分とします。 点 $t_0$ で値 $\mathbf{x}_0$ を取る方程式 $d\mathbf{x}/dt = \mathbf{a}(t)\mathbf{x} + \mathbf{x}\mathbf{b}(t)$ の積分が $\mathbf{u}(t)\mathbf{x}_0 \mathbf{v}(t)$ に等しいことを示してください。

c) $\mathbf{a}(t), \mathbf{b}(t), \mathbf{c}(t), \mathbf{d}(t)$ を 2 つの線形方程式の $J$ の 4 つの規制写像と系の $(\mathbf{u}, \mathbf{v})$ 解とします。

$$
\frac{d\mathbf{x}}{dt} = \mathbf{a}(t)\mathbf{x} + \mathbf{b}(t)\mathbf{y}, \qquad \frac{d\mathbf{y}}{dt} = \mathbf{c}(t)\mathbf{x} + \mathbf{d}(t)\mathbf{y}.
$$

$v$ が $J$ で可逆である場合、$w = uv^{-1}$ は方程式 $d\mathbf{z}/dt = \mathbf{b}(t) + \mathbf{a}(t)\mathbf{z} - \mathbf{z}\mathbf{d}(t) - \mathbf{z}\mathbf{c}(t)\mathbf{z}$ (「リカッティ方程式」) の積分であることを示します。そして逆に。 点 $t_0$ で値 $x_0$ を取る、$J$ 上のこの最後の方程式のすべての積分は、形 $(A(t)x_0 + B(t)e)(C(t)x_0 + D(t)e)^{-1}$ であると推測します。ここで、$A(t)$、$B(t)$、$C(t)$、 $D(t)$ は、$J$ から $\mathscr{L}(E)$ 満たすまで連続する写像であり、アイデンティティ $U.(xy) = (U.x)y$ です。

d) $w_1$ を $J$ 上の $d\mathbf{z}/dt = \mathbf{b}(t) + \mathbf{a}(t)\mathbf{z} - \mathbf{z}\mathbf{d}(t) - \mathbf{z}\mathbf{c}(t)\mathbf{z}$ の積分とします。 $w$ がこの方程式の他の積分で、$w - w_1$ が $J$ で可逆である場合、$w - w_1$ は方程式 $d\mathbf{x}/dt = -(d + cw_1)\mathbf{x}$ と $d\mathbf{x}/dt = \mathbf{x}(\mathbf{a} - w_1\mathbf{c})$ の積分の項で表現できることを示します ($(w - w_1)^{-1}$ によって満たされる方程式を考慮し、次を使用します) $b$) )。
