a) ボックス P について: $|t - t_0| < a,\ |x - x_0| < b$ g と h を 2 つの連続する実数写像とし、P 上で $g(t, x) < h(t, x)$ となるようにします。u (それぞれ v) を、区間で定義される $u(t_0) = x_0$ (それぞれ $v(t_0) = x_0$) となるように $x' = g(t, x)$ (それぞれ $x' = h(t, x)$) の積分とします。 $[t_0, t_0 + c[$; $t_0 < t < t_0 + c$ に対して $u(t) < v(t)$ が成り立つことを示してください (この不等式が成り立つ t の最高値 $\tau$ を考えてください)。

b) u を、$|x - x_0| < b$ の値を使用して、区間 $[t_0, t_0 + c[$ で定義された $x' = g(t, x)$ 対応するから点 $(t_0, x_0)$ までの最大積分とします (例題 10)。 $[t_0, t_0 + c[$ に含まれるすべてのコンパクト区間 $[t_0, t_0 + d]$ において、方程式 $x' = g(t, x) + \varepsilon$ 対応するから点 $(t_0, x_0)$ の最小および最大積分は、$\varepsilon > 0$ が十分に小さいと定義され、$\varepsilon$ のときに u に一様に収束することを示します。 0 ～ 値 > 0 の傾向があります。

c) g と h を、P 上で定義され、P 上で $g(t, x) \leq h(t, x)$ となる 2 つの実数連続写像とします。$[t_0, t_0 + c[$ を区間とし、その上で $u(t_0) = x_0$ のような $x' = g(t, x)$ の積分 u と、$x' = h(t, x)$ 対応するの最大積分 v が定義されます。 点 $(t_0, x_0)$。この区間に $u(t) \leq v(t)$ があることを示してください (ケース a) に対して b) を使用して簡約する)。
