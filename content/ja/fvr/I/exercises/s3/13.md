a) Let $f$ be a twice differentiable real function on $\mathbf{R}$, such that $(f(x))^2 \leq a$ and $(f'(x))^2 + (f''(x))^2 \leq b$ on $\mathbf{R}$; show that
$$
(f(x))^2 + (f'(x))^2 \leq \max(a, b)
$$
on $\mathbf{R}$ (argue by contradiction, noting that if the function $f^2 + {f'}^2$ takes a value $c > \max(a, b)$ at a point $x_0$ then there exist two points $x_1, x_2$ such that $x_1 < x_0 < x_2$ and that at $x_1$ and $x_2$ the function $f'$ takes values small enough that $f^2 + {f'}^2$ takes values $< c$; then consider a point of $[x_1, x_2]$ where $f^2 + {f'}^2$ attains its supremum on this interval).

b) $f$ を、$\mathbf{R}$ で微分可能な実数の写像 $n$ 回とし、$\mathbf{R}$ で$(f(x))^2 \leq a$ と $(f^{(n-1)}(x))^2 + (f^{(n)}(x))^2 \leq b$ が成り立つようにします。それを示してください
$$
(f^{(k-1)}(x))^2 + (f^{(k)}(x))^2 \leq \max(a, b)
$$
$\mathbf{R}$ で $1 \leq k \leq n$ に。 ($n$ での帰納法の議論。12 の練習により、$\mathbf{R}$ での $(f'(x))^2$ の最高値 $c$ は有限であることに注意。矛盾に還元することによって、必然的に $c \leq \max(a, b)$ が成り立つことを示す: $c > \max(a, b)$ 選ぶを仮定すると、定数 $\lambda$ と $\mu$ なので、写像 $g = \lambda f + \mu$ の 1 つは $|g(x)| \leq 1,\ |g'(x)| \leq 1$ を持ちますが、1 つのできないはすべての $x$ に対して $(g(x))^2 + (g'(x))^2 \leq 1$ を持ちます。）
