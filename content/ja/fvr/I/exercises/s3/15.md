$I$ を $\mathbf{R}$ の開いた区間とし、$\mathbf{f}$ ベクトル写像を $I$ で定義され連続するとします。 $I$ に $n$ ベクトル写像 $g_i$ ($1 \leq i \leq n$) があり、$x$ の写像が成立すると仮定します。

$$
\frac{1}{h^n} \left( \mathbf{f}(x+h) - \mathbf{f}(x) - \sum_{p=1}^n \frac{h^p}{p!} \mathbf{g}_p(x) \right)
$$

$h$ が 0 になる傾向があるため、$I$ に含まれるすべてのコンパクト区間で一律に 0 になる傾向があります。

a) $\mathbf{f}_p(x,h) = \Delta^p \mathbf{f}(x;h,h,\ldots,h)$ (I、p. 40、練習問題 6) を置きます。 $1 \leq p \leq n$ については、$h$ が 0 になる傾向があるため、$(1/h^p) \mathbf{f}_p(x,h)$ は$I$ のすべてのコンパクトな部分区間で一様に $\mathbf{g}_p(x)$ になる傾向があり、$\mathbf{g}_p$ は $I$ で連続していることを示します (これを $p = n, p = n-1$ などについて連続的に証明します)。

b) これから、$\mathbf{f}$ には連続導関数 $n^{th}$ があり、$1 \leq p \leq n$ に対する $\mathbf{f}^{(p)} = \mathbf{g}_p$ が導出されます (関係 $\mathbf{f}_{p+1}(x,h) = \mathbf{f}(x+h,h) - \mathbf{f}_p(x,h)$ を考慮して)。
