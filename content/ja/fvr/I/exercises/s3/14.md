$\mathbf{f}$ を区間 $I$ 含む 0 で $n - 1$ 回微分可能な写像とし、$\mathbf{f}_n$ を $I$ で $x \neq 0$ に対して定義されたベクトル写像とします。 関係

$$
\mathbf{f}(x) = \mathbf{f}(0) + \mathbf{f}'(0) \frac{x}{1!} + \mathbf{f}''(0) \frac{x^2}{2!} + \cdots + \mathbf{f}^{(n-1)}(0) \frac{x^{n-1}}{(n-1)!} + \mathbf{f}_n(x)x^n.
$$

a) $\mathbf{f}$ が点 0 で $(n+p)^{th}$ 導関数を持つ場合、$\mathbf{f}_n$ は点 0 で $p^{th}$ 導関数を持ち、0 の近傍の点では 0 とは異なる $(n+p-1)^{th}$ 導関数を持つことを示します。さらに、$0 \leq k \leq p$ には $\mathbf{f}_n^{(k)}(0) = \frac{k!}{(n+k)!} \mathbf{f}^{(n+k)}(0)$ があり、$\mathbf{f}_n^{(p+k)}(x)x^k$ は $1 \leq k \leq n-1$ に対して $x$ とともに 0 になる傾向があります ($\mathbf{f}$ の連続導関数のテイラー展開を使用して $\mathbf{f}_n$ の導関数を表現し、次の prop. 6 を使用します) I、p. 18）。

b) 逆に、$\mathbf{f}_n$ をベクトル写像とし、$I$ の 0 の近傍での導関数 $(n+p-1)^{th}$ を認め、$\mathbf{f}_n^{(p+k)}(x)x^k$ が $0 \leq k \leq n-1$ に対して極限を持つようにします。 写像 $\mathbf{f}_n(x)x^n$ には $I$ の $(n+p-1)^{th}$ 導関数があることを示します。さらに、$\mathbf{f}_n$ が点 0 で $p^{th}$ 導関数を認める場合、$\mathbf{f}_n(x)x^n$ は点 0 で $(n+p)^{th}$ 導関数を認めます。

c) $I$ が 0 に関して対称で、$\mathbf{f}$ が偶数であると仮定します ($I$ 上の $\mathbf{f}(-x) = \mathbf{f}(x)$)。 a) の助けを借りて、$\mathbf{f}$ が $I$ で $2n$ 回微分可能である場合、定義された写像 $g$ が存在し、$I$ で $n$ 回微分可能であること、つまり $I$ で $\mathbf{f}(x) = g(x^2)$ が存在することを示します。
