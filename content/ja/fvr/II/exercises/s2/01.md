$\alpha$ と $\beta$ を、$\alpha < \beta$ となるような 2 つの有限実数とします。 Show that if $\gamma$ and $\delta$ are two numbers such that $\alpha < \gamma \leq \delta < \beta$ then there exists a real function $f$ defined on an interval $[0, a]$, taking only the values $\alpha$ and $\beta$, such that, on all the interval $[\varepsilon, a]$ (for $\varepsilon > 0$), $f$ is a step function and that, if one puts $g(x) = \int_0^x f(t)\, dt$, one has
$$
\liminf_{x \to 0, x > 0} \frac{g(x)}{x} = \gamma, \qquad \limsup_{x \to 0, x > 0} \frac{g(x)}{x} = \delta;
$$
(*)
(take for $g$ a function whose graph is a broken line whose consecutive sides have gradients $\alpha$ and $\beta$ and whose peaks occur alternately on the lines $y = \gamma x, \ y = \delta x$ for $\gamma \neq \delta$, or on the line $y = \gamma x$ and the parabola $y = \gamma x + x^2$ for $\gamma = \delta$).

同じ方法により、$\gamma$ と $\delta$ が有限であるかどうか ($\gamma < \delta$) にかかわらず、$[0, a]$ で定義された実際の写像 $f$ が存在し、区間 $[\varepsilon, a]$ ($\varepsilon > 0$ の場合) ごとに、 $f$はステップ写像であり、整$g(x) = \int_0^x f(t)\, dt$が存在し、その積分は再び関係になります(*)。
