(a) $\alpha$ と $\beta$ を 2 つの序数とします。 不等式 $\alpha < \beta$ は $\alpha + 1 \leqslant \beta$ と同等であり、すべての序数 $\xi$ に対して不等式 $\xi + \alpha < \xi + \beta$、$\alpha + \xi \leqslant \beta + \xi$、$\alpha\xi \leqslant \beta\xi$ が、$\xi > 0$ の場合は $\xi\alpha < \xi\beta$ を意味することを示してください。

(b) (a) から、すべての序数属するに当てはまる集合は存在しないと推定します (練習問題 14 (d) を使用します)。

(c) $\alpha$、$\beta$、$\mu$ を 3 つの序数とします。 関係 $\mu + \alpha < \mu + \beta$、$\alpha + \mu < \beta + \mu$ がそれぞれ $\alpha < \beta$ を意味することを示してください。そして、$\mu > 0$ の場合、関係 $\mu\alpha < \mu\beta$、$\alpha\mu < \beta\mu$ はそれぞれ $\alpha < \beta$ を意味します。

(d) $\mu > 0$ の場合、関係 $\mu + \alpha = \mu + \beta$ は $\alpha = \beta$ を意味し、$\mu\alpha = \mu\beta$ は $\alpha = \beta$ を意味することを示します。

(e) 2 つの序数 $\alpha$ と $\beta$ は、$\beta = \alpha + \xi$ のような序数 $\xi$ が存在する場合に限り、$\alpha \leqslant \beta$ になります。この序数 $\xi$ は一意であり、 $\xi \leqslant \beta$ となります。 $(-\alpha) + \beta$と書かれています。

(f) $\alpha$、$\beta$、$\zeta$ を、$\zeta < \alpha\beta$ となる 3 つの序数とします。 $\zeta = \alpha\eta + \xi$ と $\xi < \alpha$, $\eta < \beta$ (cf. no. 5, 定理 3, 系 3) のような 2 つの序数 $\xi$, $\eta$ が存在することを示します。また、$\xi$と$\eta$はこれら条件により一意に決まります。
