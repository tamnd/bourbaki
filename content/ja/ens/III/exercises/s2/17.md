序数 $\alpha_0$ が与えられた場合、項 $f(\xi)$ は *序数関数記号* (*$\xi$ に関して) *定義されている* $\xi \geqslant \alpha_0$ の場合、関係 「$\xi$ は序数であり、$\xi \geqslant \alpha_0$」は関係を意味します"$f(\xi)$ は序数です"; 関係 $\alpha_0 \leqslant \xi < \eta$ が $f(\xi) < f(\eta)$ を意味し、序数 $\geqslant \alpha_0$ の各族 $(\xi_\iota)_{\iota \in I}$ について、$\sup_{\iota \in I} f(\xi_\iota) = f(\sup_{\iota \in I} \xi_\iota)$ (cf. 練習問題 14 (d)) がある場合、$f(\xi)$ は *正規* であると言われます。

(a) それぞれの序数 $\alpha > 0$、$\alpha + \xi$、$\alpha\xi$ が $\xi \geqslant 0$ に対して定義された通常の関数記号であることを示します (練習問題 15 (f) を使用)。

(b) $w(\xi)$ を、$w(\xi) \geqslant \xi$ となり、$\alpha_0 \leqslant \xi < \eta$ が $w(\xi) < w(\eta)$ を意味するような、$\xi \geqslant \alpha_0$ に対して定義された順序関数記号とします。また、$g(\xi, \eta)$ を項とし、関係 「$\xi$ と $\eta$ は序数$\geqslant \alpha_0$」は、関係 「$g(\xi, \eta)$ は$g(\xi, \eta) > \xi$ のような序数である」ことを意味します。

定義する項 $f(\xi, \eta)$ は次のプロパティを持ちます: (1) 各序数 $\xi \geqslant \alpha_0$、$f(\xi, 1) = w(\xi)$; (2) 各序数 $\xi \geqslant \alpha_0$ および各序数 $\eta > 1$、$f(\xi, \eta) = \sup_{0 < \zeta < \eta} g(f(\xi, \zeta), \xi)$ について (no. 2 の基準 C60 を使用)。これら 2 つのプロパティで $f_1(\xi, \eta)$ が他の項である場合、すべての $\xi \geqslant \alpha_0$ とすべての $\eta \geqslant 1$ について $f(\xi, \eta) = f_1(\xi, \eta)$ であることを示します。各序数 $\xi \geqslant \alpha_0$ について、$f(\xi, \eta)$ は $\eta$ (すべての $\eta \geqslant 1$ に対して定義) に関して通常の関数記号であることを証明します。すべての $\eta \geqslant 1$ と $\xi \geqslant \alpha_0$ については $f(\xi, \eta) \geqslant \xi$ であり、すべての $\xi \geqslant \sup(\alpha_0, 1)$ と $\eta \geqslant 1$ については $f(\xi, \eta) \geqslant \eta$ であることを示してください。さらに、$\alpha > 0$、$\alpha \geqslant \alpha_0$、$\beta \geqslant w(\alpha)$ などの各対 $(\alpha, \beta)$ に対して、次のような固有の序数 $\xi$ が存在します。

$$f(\alpha, \xi) \leqslant \beta < f(\alpha, \xi + 1),$$

そして$\xi \leqslant \beta$です。

(c) $\alpha_0 = 0$、$w(\xi) = \xi + 1$、$g(\xi, \eta) = \xi + 1$ を取ると、$f(\xi, \eta) = \xi + \eta$ になります。 $\alpha_0 = 1$、$w(\xi) = \xi$、$g(\xi, \eta) = \xi + \eta$ を取ると、$f(\xi, \eta) = \xi\eta$ になります。

(d) 関係 $\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta \leqslant \eta'$ が $g(\xi, \eta) \leqslant g(\xi', \eta')$ を暗示する場合、関係 $\alpha_0 \leqslant \xi \leqslant \xi'$、$1 \leqslant \eta \leqslant \eta'$ は $f(\xi, \eta) \leqslant f(\xi', \eta')$ を暗示することを示します。 関係 $\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta < \eta'$ が $g(\xi, \eta) < g(\xi, \eta')$ および $g(\xi, \eta) \leqslant g(\xi', \eta)$ を暗示する場合、関係 $\alpha_0 \leqslant \xi < \xi'$ および $\eta \geqslant 0$ は $f(\xi, \eta + 1) < f(\xi', \eta + 1)$ を暗示します。

(e) $w(\xi) = \xi$ と関係 $\alpha_0 \leqslant \xi \leqslant \xi'$、$\alpha_0 \leqslant \eta < \eta'$ が $g(\xi, \eta) < g(\xi, \eta')$ と $g(\xi, \eta) \leqslant g(\xi', \eta)$ を暗示しているとします。さらに、それぞれの $\xi \geqslant \alpha_0$、$g(\xi, \eta)$ が $\eta$ ($\eta \geqslant \alpha_0$ で定義) に関して通常の関数記号であり、$\xi \geqslant \alpha_0$、$\eta \geqslant \alpha_0$、および $\zeta \geqslant \alpha_0$ には結合性関係があると仮定します。

$$g(g(\xi, \eta), \zeta) = g(\xi, g(\eta, \zeta)).$$

$\xi \geqslant \alpha_0$、$\eta \geqslant 1$、$\zeta \geqslant 1$ の場合、

$$g(f(\xi, \eta), f(\xi, \zeta)) = f(\xi, \eta + \zeta)$$

($f$に対する$g$の「分配性」)および

$$f(f(\xi, \eta), \zeta) = f(\xi, \eta\zeta)$$

（$f$の「連想性」）。
