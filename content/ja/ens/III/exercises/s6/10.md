$\omega$ または $\omega_0$ が序数 Ord (**N**) (§ 2、練習問題 14) を表すものとします。すべての整数のうち集合は、すべての序数 $< \omega$ の集合と同型の整った順序の集合です。それぞれの整数 $n$ について、序数の Ord $([0, n[)$ を (言葉の乱用により) $n$ で再度表します。

(a) それぞれの基数 $\mathfrak{a}$ 関係について、「$\xi$ は序数であり、カード $(\xi) < \mathfrak{a}$」が集合化していることを示します (Zermelo の定理を使用)。 $W(\mathfrak{a})$ が、カード $(\xi) < \mathfrak{a}$ のようなすべての序数 $\xi$ の集合を表すものとします。

(b) For each ordinal $\alpha > 0$ define a function $f_\alpha$ on the well-ordered set $O'(\alpha)$ of ordinals $\leqslant \alpha$ by transfinite induction as follows : $f_\alpha(0) = \omega_0 = \omega$, and for each ordinal $\xi$ such that $0 < \xi \leqslant \alpha$, $f_\alpha(\xi)$ is the least upper bound (§ 2, Exercise 14 (d)) of the set of ordinals $\zeta$ such that $\mathrm{Card}(\zeta) \leqslant \mathrm{Card}(f_\alpha(\eta))$ for at least one ordinal $\eta < \xi$. $0 \leqslant \eta < \xi \leqslant \alpha$の場合は$\mathrm{Card}(f_\alpha(\eta)) < \mathrm{Card}(f_\alpha(\xi))$、$\xi \leqslant \alpha \leqslant \beta$の場合は$f_\alpha(\xi) = f_\beta(\xi)$であることを示します。 $\omega_\alpha = f_\alpha(\alpha)$を入れてください。 $\omega_\alpha$ は、添字 $\alpha$ との *最初の序数 * であると言われています。 $\omega_\alpha \geqslant \alpha$ があります。 $\aleph_\alpha = \mathrm{Card}(\omega_\alpha)$を入れてください。 $\aleph_\alpha$ は添字* $\alpha$ の *アレフであると言われています。 特に$\aleph_0 = \mathrm{Card}\ (\mathbf{N})$。

(c) 無限の各基数 $\mathfrak{a}$ について、序数 $W(\mathfrak{a})$ の集合の最小上界 $\lambda$ が初期序数 $\omega_\alpha$ であり、$\mathfrak{a} = \aleph_\alpha$ (次のような最小序数 $\mu$ を考えてください) であることを示します。 $\omega_\mu \geqslant \lambda$);他の語では、$\omega_\alpha$ は $\mathrm{Card}(\xi) = \aleph_\alpha$ のような最小序数 $\xi$ です。 $O'(\alpha)$ で定義された各序数 $\alpha$ 写像 $\xi \rightarrow \aleph_\xi$ は、基数 $\leqslant \aleph_\alpha$ の整った順序の集合上の整った順序の集合 $O'(\alpha)$ の同型です。特に、$\aleph_{\alpha+1}$ は基数 $> \aleph_\alpha$ よりも最小です。 $\alpha$ に先行関数がない場合、$\alpha = \sup_{\xi < \beta} \sigma_\xi$ となる$\alpha$ への序数 $\beta$ のすべての真に増加する写像 $\xi \rightarrow \sigma_\xi$ について、

$$\sum_{\xi < \beta} \aleph_{\sigma_\xi} = \aleph_\alpha.$$

(d) (c) から、$\omega_\xi$ は通常の順序関数記号 (§ 2, 練習問題 17) であると推定します。
