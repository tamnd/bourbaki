$\alpha$ を序数 $> 0$ とします。 序数 $\alpha$ のそれ自体への写像 $f$ は、各序数 $\lambda_0 < \alpha$ に対して、関係 $\mu_0 \leqslant \xi < \alpha$ が $\lambda_0 \leqslant f(\xi) < \alpha$ [^1] を暗示するような序数 $\mu_0 < \alpha$ が存在する場合、*発散* であると言われます。

(a) $\varphi$ を、序数 $\beta$ の真に増加する写像を $\alpha$ にするとします。

$$\varphi \left( \sup_{\zeta < \gamma} \zeta \right) = \sup_{\zeta < \gamma} \varphi(\zeta) \quad \text{for all} \quad \gamma < \beta,$$

そしてそのようなこと

$$\sup_{\zeta < \beta} \varphi(\zeta) = \alpha.$$ [^2]

そのとき、同じ型のそれ自体への $\beta$ の発散写像が存在する場合に限り、$\alpha$ のそれ自体への発散写像 $f$ が存在し、すべての $\xi$ 満たす $0 < \xi < \alpha$ に対して $f(\xi) < \xi$ が存在します。

(b) (a) から、$\omega_\alpha$ の最後の指標が $\omega_0$ である場合に限り、すべての $\xi$ 満たす $0 < \xi < \alpha$ に対して $f(\xi) < \xi$ となるように、それ自体への$\omega_\alpha$ の発散写像が存在することを推定します。 ($\omega_\alpha$ が通常の序数 $> \omega_0$ である場合、定義するは次のように帰納的に真に増加する数列 $(\eta_n)$ になります: $\eta_1 = 1$、そして $\eta_{n+1}$ はすべての$f(\xi) > \eta_n$ となる最小の序数 $\zeta$ です$\xi \geqslant \zeta$)

(c) $\omega_{\bar{\alpha}}$ を $\omega_\alpha$ (練習問題 16) の最後の指標とします。 $\bar{\alpha} > 0$ が、$f$ が $0 < \xi < \omega_\alpha$ のようなすべての $\xi$ に対して $f(\xi) < \zeta$ となるように、$\omega_\alpha$ の写像である場合、方程式の解の集合となる序数 $\lambda_0$ が存在することを示してください。 $f(\xi) = \lambda_0$ には基数 $\geqslant \aleph_{\bar{\alpha}}$ があります。


[^1]: If the well-ordered set $O'_\alpha$ of ordinals $\leqslant \alpha$ is endowed with the topology $\mathscr{T}_-(O'_\alpha)$ (*General Topology*, Chapter I, § 2, Exercise 5), this condition may be written $\lim_{\xi \to \alpha, \, \xi < \alpha} f(\xi) = \alpha$.
[^2]: If we extend $\varphi$ to $O'_\beta$ by defining $\varphi(\beta) = \alpha$, the conditions above signify that $\varphi$ is continuous with respect to the topologies $\mathscr{T}_-(O'_\alpha)$ and $\mathscr{T}_-(O'_\beta)$ on $O'_\alpha$ and $O'_\beta$ respectively (*loc. cit.*).
