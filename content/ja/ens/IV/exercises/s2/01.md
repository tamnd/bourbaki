S を記号 $\mathsf{P}$、$\mathsf{P}^-$、$\mathsf{X}$、$\mathsf{X}^-$、$x_1$、...、$x_n$ の集合とし、$x_i$ は重み 0、$\mathsf{P}$、$\mathsf{P}^-$ の文字とします。 重み 1、および重み 2 の $\mathsf{X}$、$\mathsf{X}^-$。 L(S) の各語 A について、次のように A の *分散* を定義する計算します。各文字 $x_i$ と符号 $\mathsf{P}$、 $\mathsf{X}$、分散は 0 です。記号 $\mathsf{P}^-$、$\mathsf{X}^-$ には分散 1 があります。 A の分散は、A に現れる符号の分散の和 \* (体 $\mathbf{F}_2$ では) \* です (他の語では、含むが分散符号 1 の *偶数* 数であれば 0、それ以外の場合は 1)。

*符号付き階層型* は、次の 2 つの条件のうちの 1 つを満たす、L(S) (章 I, 付録, no. 3) の平衡型語 A です。 (1) A は文字の 1 つです。 $x_i$; (2) A が形 $f\mathrm{A}_1\mathrm{A}_2 \ldots \mathrm{A}_p$ (章 I, 付録, no. 3, 系 2 of 命題 2) の場合、$f$ は記号 $\mathsf{P}$ の 1 つです。 $\mathsf{P}^-$、$\mathsf{X}$、$\mathsf{X}^-$、$p$ が 1 または 2 に等しく、$\mathrm{A}_i$ $(1 \leqslant i \leqslant p)$ がバランス語である場合、$\mathrm{A}_i$ のそれぞれは符号付き階層型になります。さらに、$f = \mathsf{X}$ の場合、$\mathrm{A}_1$ と $\mathrm{A}_2$ は分散 0 を持ち、$f = \mathsf{X}^-$ の場合、$\mathrm{A}_1$ と $\mathrm{A}_2$ は分散 1 を持ちます。

符号付き段階型は、分散が 0 の場合は *共変*、分散 1 の場合は *反変* であると言われます。 符号付き段階型 A で、置き換える $\mathsf{P}^-$ と $\mathsf{X}^-$ が $\mathsf{P}$ と $\mathsf{X}$ により、それぞれ、階層型 A\* (§ 1, 練習問題 1) を取得します。 $n$ 項 $\mathrm{E}_1$, ..., $\mathrm{E}_n$ 上のエシュロン型 A\* のすべての実現は、$\mathrm{E}_1$, ..., $\mathrm{E}_n$ 上の署名されたエシュロン型* A の * 実現と呼ばれ、次のように書かれます。 $\mathrm{A}(\mathrm{E}_1, \ldots, \mathrm{E}_n)$。

$\mathrm{E}_1$, ..., $\mathrm{E}_n$, $\mathrm{E}'_1$, ..., $\mathrm{E}'_n$ を集合とし、$f_i$ を $\mathrm{E}_i$ の写像から $\mathrm{E}'_i$ $(1 \leqslant i \leqslant n)$ とします。 $x_1$, ..., $x_n$ の各署名階層型に対して、次の特性を持つ写像 $\{f_1, \ldots, f_n\}^{\mathrm{S}}$ を関連付けることができることを示します。

(i) S が共変 (または反変) の場合、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は $\mathrm{S}(\mathrm{E}_1, \ldots, \mathrm{E}_n)$ の $\mathrm{S}(\mathrm{E}'_1, \ldots, \mathrm{E}'_n)$ への写像 (それぞれ $\mathrm{S}(\mathrm{E}'_1, \ldots, \mathrm{E}'_n)$ の $\mathrm{S}(\mathrm{E}_1, \ldots, \mathrm{E}_n)$ ) です。

(ii) S が文字 $x_i$ の場合、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は $f_i$ です。

(iii) S が $\mathsf{P}\mathrm{T}$ (それぞれ $\mathsf{P}^-\mathrm{T}$) で、$g = \{f_1, \ldots, f_n\}^{\mathrm{T}}$ が F の写像から F' である場合、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は $g$ の拡大から部分集合の集合 (それぞれ拡大 ) です。 $\overset{-1}{g}$ から集合の部分集合)。

(iv) S が $\mathsf{X}\mathrm{TU}$ または $\mathsf{X}^-\mathrm{TU}$ の場合、$\{f_1, \ldots, f_n\}^{\mathrm{T}}$ が写像 $g : \mathrm{F} \to \mathrm{F}'$ の場合、$\{f_1, \ldots, f_n\}^{\mathrm{U}}$ が写像 $h : \mathrm{G} \to \mathrm{G}'$ の場合、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は拡大 $g \times h : \mathrm{F} \times \mathrm{G} \to \mathrm{F}' \times \mathrm{G}'$ です。

写像 $\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は、$f_1, \ldots, f_n$ 対応するの符号付きエシュロン型 S に対する *署名付き正規拡大* と呼ばれます。 S がエシュロン型である場合 (つまり、 $\mathsf{P}^-$ と $\mathsf{X}^-$ がそうでない場合) S) に出現する場合、符号付き正規拡大 $\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は $\langle f_1, \ldots, f_n \rangle^{\mathrm{S}}$ と等しくなります。

$f_i$ が $\mathrm{E}_i$ の $\mathrm{E}'_i$ の写像であり、$f'_i$ が $\mathrm{E}'_i$ の $\mathrm{E}''_i$ $(1 \leqslant i \leqslant n)$ の写像である場合、共変符号付き階層型 S について、

$$\{f'_1 \circ f_1, \ldots, f'_n \circ f_n\}^{\mathrm{S}} = \{f'_1, \ldots, f'_n\}^{\mathrm{S}} \circ \{f_1, \ldots, f_n\}^{\mathrm{S}},$$

そして、反変符号付き階層型については、次のようになります。

$$\{f'_1 \circ f_1, \ \ldots, f'_n \circ f_n\}^{\mathrm{S}} = \{f_1, \ \ldots, f_n\}^{\mathrm{S}} \circ \{f'_1, \ \ldots, f'_n\}^{\mathrm{S}}.$$

$f_i$ が $\mathrm{E}'_i$ 上の $\mathrm{E}_i$ の全単射であり、$f'_i$ がその逆全単射 $(1 \leqslant i \leqslant n)$ である場合、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は全単射であり、$\{f'_1, \ldots, f'_n\}^{\mathrm{S}}$ はその逆であると推測します。さらに、$\mathrm{S}^*$ が符号付きエシュロン型 S に対する (符号なし) エシュロン型対応するである場合、S が共変か反変かに従って、$\{f_1, \ldots, f_n\}^{\mathrm{S}}$ は $\langle f_1, \ldots, f_n \rangle^{\mathrm{S}^*}$ または $\langle f'_1, \ldots, f'_n \rangle^{\mathrm{S}^*}$ に等しくなります。
