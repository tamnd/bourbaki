$R$、$S$、$T$ を $\mathscr{T}$ の関係とし、$x$ を文字とします。 $R$ が $\mathscr{T}$ の $x$ で機能する場合、次の関係が $\mathscr{T}$ の定理であることを示します。

$$(\text{not } (\exists x)(R \text{ and } S)) \Leftrightarrow (\exists x)(R \text{ and } (\text{not } S)),$$

$$(\exists x)(R \text{ and } (S \text{ and } T)) \Leftrightarrow (\exists x)(R \text{ and } S) \text{ and } (\exists x)(R \text{ and } T)),$$
$$(\exists x)(R \text{ and } (S \text{ or } T)) \Leftrightarrow ((\exists x)(R \text{ and } S) \text{ or } (\exists x)(R \text{ and } T)).$$
