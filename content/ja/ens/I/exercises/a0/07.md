$R_1, R_2, \ldots, R_n$ を、理論 $\mathscr{T}_0$ における論理的に既約な別個の関係 (練習問題 6) とします。 $A_1, A_2, \ldots, A_m$ を基底 $R_1, R_2, \ldots, R_n$ を含む論理構成とします。それぞれの $R_j$ に符号 0、1 のいずれかが与えられているとします。次に、次の規則に従って、それぞれの $A_i$ に符号 0、1 のいずれかを与えます。 (1) $A_i$ が $R_j$ と同一の場合、$A_i$ には $R_j$ と同じ符号を与えます。 (2) $A_i$ が $\neg A_j$ と同一で、$A_j$ が $A_i$ に先行する場合、$A_j$ の符号が 0 (それぞれ 1) であれば、$A_i$ に符号 1 (それぞれ 0) を与えます。 (3) $A_i$ が $\vee A_jA_k$ と同一の場合、$A_j$ と $A_k$ が両方とも符号 1 であれば、$A_i$ に符号 1 を与えます。それ以外の場合は、$A_i$ に符号 0 を与えます (私たちは適用以下の「象徴的規則」です:

$$
\neg 0 = 1,\qquad \neg 1 = 0,\qquad \vee 11 = 1,\qquad \vee 10 = \vee 01 = \vee 00 = 0.
$$

(a) これらの規則に従って、それぞれの $A_i$ に記号を割り当てる方法は 1 つだけであることを示してください。

(b) $R$ が $R_1, R_2, \ldots, R_n$ から論理的に構築される場合、$R$ によってもたらされる符号は、基底を使用して、論理的な構成から独立しています。

$$
R_1,\ R_2,\ \ldots,\ R_n,
$$

$R$が登場します。

(c) $R$ と $S$ が $R_1, R_2, \ldots, R_n$ から論理的に構築され、$R$ と $\Rightarrow RS$ によって運ばれる符号が 0 である場合、$S$ によって運ばれる符号は 0 になります。

(d) これから、$\mathscr{T}_0$ の唯一の公理がスキーム S1 から S4 から提供されるものであると仮定します。 $R$ を $\mathscr{T}_0$ の定理とし、$R_1, R_2, \ldots, R_n$ をその論理成分とします。ただし、符号 0 と 1 が $R_1, R_2, \ldots, R_n$ に与えられ、$R$ が持つ符号は 0 であることを示してください。 ($R$ が $\mathscr{T}_0$ の公理である場合について最初にこれを証明します。一般の場合、$R$ の証明を考慮し、(c) を適用します) $\mathscr{T}_0$。

(e) $R$ を、$\mathscr{T}_0$ における論理的に既約の関係とする。 $\mathscr{T}_0$ では $R$ も「$R$ ではない」も定理ではないことを示してください。特に、$\mathscr{T}_0$ は矛盾しません ((d) を使用)。

(f) $R_1, R_2, \ldots, R_n$ を、$\mathscr{T}_0$ において論理的に既約な個別の関係とする。 形のすべての関係 「$R'_1$ または $R'_2$ または $\ldots$ または $R'_n$」を検討してください。ここで、$i$ ごとに、$R'_i$ は 2 つの関係 $R_i$ のうちの 1 つであり、「$R_i$ ではありません」。 $S_1, S_2, \ldots, S_p$ をこれらの関係とします。 $T_1, T_2, \ldots, T_q$ を形の関係とします

「$S_{i_1}$ と $S_{i_2}$ と ... と $S_{i_r}$」。$i_1$、$i_2$、...、$i_r$ は、添字のいずれかの真に増加する数列です。最後に、$T_0$ を関係 「$R_1$ または ($R_1$ ではない)」、つまり $\mathscr{T}$ の定理とします。 $R_1$、$R_2$、...、$R_n$ から論理的に構築されたすべての関係が、$\mathscr{T}$ では関係 $T_0$、$T_1$、...、$T_q$ の 1 つと等価であることを示します。 (最初に、$\mathscr{T}$ ではすべての関係 $R_i$ が関係 $T_0$, $T_1$, ..., $T_q$ の 1 つと同等であることを示します。$R$ が $R_1$, $R_2$, ..., $R_n$、論理構成を基底 $R_1$, $R_2$, ..., $R_n$ と含む $R$ をステップごとに議論し、最後に (d) を使用して一意性を証明します。)

(g) $R$ を $\mathscr{T}$ の関係とし、$R_1$、$R_2$、...、$R_n$ をその論理成分とします。この場合、$R$ は $\mathscr{T}$ の定理ですが、符号 0 と 1 が $R_1$、$R_2$、...、$R_n$、対応するに割り当てられている$R$ の符号が 0 である場合に限ります。
