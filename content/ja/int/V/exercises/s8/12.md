$T_i$ ($1 \leq i \leq n$) を $n$ 局所的にコンパクトな空間、$\mu_i$ を $1 \leq i \leq n$ に対する $T_i$ の正の尺度とします。それぞれの添字 $i$ を $E_i$ 積 $\prod_{j \neq i} T_j$ で表します。 $f_i$ を $T = \prod_{i=1}^n T_i$ の写像 $\geq 0$ として、$\mu = \bigotimes_{i=1}^n \mu_i$ について測定可能で、*$t_i$ には依存しません*。 $1 \leq k \leq n$ について、写像 $f_k^{n-1}$ が測度 $\mu_1 \otimes \cdots \otimes \mu_{k-1} \otimes \mu_{k+1} \otimes \cdots \otimes \mu_n$ に対して積分可能である場合、$f_1 f_2 \cdots f_n$ は $\mu$ 積分可能であることを示します。

$$
\int f_1 f_2 \cdots f_n\, d\mu_1\, d\mu_2 \cdots d\mu_n \leq \left( \prod_{k=1}^n J_k \right)^{1/(n-1)}
$$

ここで、各添字 $k$ に対して、1 つの集合 $J_k = \int f_k^{n-1} d\mu_1 \cdots d\mu_{k-1} d\mu_{k+1} \cdots d\mu_n$ ($n$ の帰納法、適用ルベーグ・フビニ定理およびヘルダーの不等式によって続行)。

このことから、$A$ が $T$ の $\mu$ 可測部分集合である場合、$A_i$ は $E_i$ の射影であり、$A_i$ が可積分で測度 $m_i$ である場合 (測度について) を推測します。 $E_i$ 上の $\bigotimes_{j \neq i} \mu_j$)、その場合、$A$ は $\mu$ 積分可能であり、
$$
\mu(A) \leq (m_1 m_2 \cdots m_n)^{1/(n-1)}.
$$

これら 2 つの不等式における等式の場合を調べてください。

$T_i$ の $n-1$ の $n$ 積を考慮する代わりに、$T_i$ の $p$ の $\binom{n}{p}$ 積を考慮し、$T$ を積分する場合に一般化します。 $\binom{n}{p}$ 写像 $\geq 0$ の積は、それぞれ変数 $t_i$ の $p$ のみに依存します。たとえば、$F_{ij} = T_i \times T_j$ ($i < j$) および $f_{ij}$ が変数 $t_i$ と $t_j$ にのみ依存する場合、次を示します。
$$
\int \left( \prod_{i < j} f_{ij} \right) d\mu_1 d\mu_2 \cdots d\mu_n \leq \left( \prod_{i < j} \int f_{ij}^{n-1} d\mu_i d\mu_j \right)^{1/(n-1)}.
$$
