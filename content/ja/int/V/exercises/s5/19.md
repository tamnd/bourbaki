$\mu$ を $T$ に対するプラスの尺度とします。
a) $(f_n)$ を $\mathscr{L}^p$ ($1 < p < +\infty$) の写像の数列とし、$\mathscr{L}^p$ で境界を定め、メジャーで 0 に収束します。 弱化されたトポロジでは、シーケンス $(\widetilde{f}_n)$ が $L^p$ で 0 に収束することを示します。
b) $\mathscr{L}^1$ の関数のシーケンス $(f_n)$ は、$\mathscr{L}^1$ で制限され、測定値が 0 に収束しますが、シーケンス $(\widetilde{f}_n)$ は$L^1$ の弱められたトポロジーでは 0 に収束しません ($\mu$ を $T = [0,1]$ のルベーグ測度として取り、次を使用します) Exer の基準 $\alpha$)。 15）。
