$\rho, \sigma$ を T 上の 2 つの原子単位とし、M、N をそれぞれ $|\rho|$ と $|\sigma|$ を運ぶ最小の集合とします。 $\rho$ と $\sigma$ が異質であるためには、$M \cap N = \varnothing$ が必要かつ十分です。これから、$\mathbf{R}$ の区間 $I = [0,1]$ 上の原子メジャー $\nu$ の例を推定し、I が $\nu^+$ と $\nu^-$ のサポートとなるようにします。
