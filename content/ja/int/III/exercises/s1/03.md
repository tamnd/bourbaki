エクサーの例にて。 2、Y として離散空間 $\mathbf{N}$ をとります。すべての $n \in \mathbf{N}$ について、$e_n$ を $\mathscr{K}(X; \mathbf{R})$ の写像とし、X の $x \neq n$ に対して $e_n(n) = 1$ と $e_n(x) = 0$ を定義します。 写像 0 と $e_n/(n+1)$ で形成される集合 A は $\mathscr{K}(X; \mathbf{R})$ でコンパクトですが、厳密にはコンパクトではないことを示します。 $\mathfrak{U}$ が $\beta Y = \beta \mathbf{N}$ の $\omega$ の近傍のフィルターによって引き起こされる $\mathbf{N}$ の限外フィルターである場合、$\mathfrak{U}$ に関して、ポジティブ測度の族 $(n \varepsilon_n)$ は、$\mathscr{K}(X; \mathbf{R})$ のすべての厳密にコンパクトな部分集合で均一に 0 になる傾向があるが、そうではないことを示します。 A では一様に 0 になる傾向があります。
