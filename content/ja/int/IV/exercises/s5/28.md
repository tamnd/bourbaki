X を局所コンパクト空間、μ を X の正の測度、P 集合を数値写像 (有限かどうか) f ≥ 0 で X で定義され、μ可測であるとします。 λ を、P 上で定義された写像とし、値 ≥ 0 (有限であるかどうか)、つまり正に均一、増加するで凸 (cf. 第 1 章) とします。 I, No. 1)、さらに次のようになる: μ が無視できるすべての写像 f ≥ 0 に対して 1° λ(f) = 0; P の写像の増加する数列 (f_n) ごとに 2°、λ(\sup_n f_n) = \sup_n λ(f_n)。 すべての Banach 空間 F について、μ 可測写像 f の X を $\mathscr{L}_F$^λ 集合で表し、λ(|f|) が有限となるように F に変換します。 λ(|f|) が $\mathscr{L}_F$^λ 上の準ノルムであり、$\mathscr{L}_F$^λ がこの準ノルムによって定義される位相に対して完全であることを示します。
