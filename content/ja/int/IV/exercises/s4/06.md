a) $f$ を、$\mu^*(f)$ (例 5) が有限となるような数値写像とする。 $\mu(f_1) = \mu^*(f)$ となる可積分関数 $f_1 \geq f$ が存在することを示します。 $f_2$ が 2 番目の可積分関数で、$f_2 \geq f$ と $\mu(f_2) = \mu^*(f)$ が一致する場合、$f_1$ と $f_2$ は同等です。

b) 数値写像 $f$ が積分可能であるためには、$\mu^*(f)$ と $\mu_*(f)$ が有限で等しいことが必要かつ十分です。

c) $f$ を、$\mu^*(f)$ と $\mu_*(f)$ が両方とも有限であるような数値写像とする。 $g$ と $h$ を 2 つの可積分関数とし、$g \leq f \leq h$ と $\mu(g) = \mu_*(f)$、$\mu(h) = \mu^*(f)$ とします。それを見せてください

$$
\mu_*(f - g) = \mu_*(h - f) = 0 \quad \text{and} \quad \mu^*(f - g) = \mu^*(h - f) = \mu^*(f) - \mu_*(f).
$$

d) $f_1, f_2$ を、数 $\mu^*(f_1), \mu^*(f_2), \mu_*(f_1)$ と $\mu_*(f_2)$ がすべて有限であるような 2 つの数値写像とする。それを示す

$$
\mu_*(f_1 + f_2) \leq \mu_*(f_1) + \mu_*(f_2) \leq \mu^*(f_1 + f_2)
$$

($g_2$ が $f_2 \leq g_2$ と $\mu^*(f_2) = \mu(g_2)$ のような可積分関数である場合、$h \leq f_1 + f_2$ のような可積分関数 $h$ ごとに 1 つが $h - g_2 \leq f_1$ になることに注意してください。)このことから、$f_1$ が可積分である場合、

$$
\mu^*(f_1 + f_2) = \mu(f_1) + \mu^*(f_2), \quad \mu_*(f_1 + f_2) = \mu(f_1) + \mu_*(f_2),
$$

および $\mu^*(f_1 + f_2) = \mu^*(\sup(f_1, f_2)) + \mu^*(\inf(f_1, f_2))$ (後者の関係については、§1 の Exer. 1 を使用します)。

e) $f$ を可積分関数とします。 $\mu^*(g)$ が有限であるような写像 $g$ が可積分である位数では、$\mu(f) = \mu^*(g) + \mu^*(f - g)$ が必要かつ十分です ($g_1$ が $g \leq g_1$ と $\mu^*(g) = \mu(g_1)$ であるような可積分関数である場合、$f - g_1 \leq f - g$ に注意してください)。
