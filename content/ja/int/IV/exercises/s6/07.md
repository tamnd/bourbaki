$f$ を、正で測定可能で無視できない数値写像とします。
a) 有限数 $r > 0$ に対して、$f^r$ が可積分である場合、$\log f$ は準可積分であることを示します (§ 5、Exer. 15)。
b) $f^r$ が $0 < r < r_0$ に対して可積分であると仮定します。 $A$ を $x \in X$ の集合として、$f(x) > 0$ とします。 $\mu^*(A) > 1$ の場合、$r$ は 0 になる傾向があるため、$N_r(f)$ は $+\infty$ になる傾向があることを示します。 $\mu(A) < 1$ の場合、$N_r(f)$ は $r$ で 0 になる傾向があります (I の提案 4 を利用します)。
c) $\mu(A) = 1$ の場合、$r$ が 0 になる傾向があるのと同様に、$\int f^r d\mu$ も 1 になる傾向があり、この点で右導関数があり、$\int \log f \, d\mu$ に等しいことを示します (§ 5 の Exer. 12 を使用します)。これから、$r$ は 0 になる傾向があり、$N_r(f)$ は $G(f) = \exp(\int \log f \, d\mu)$ になる傾向があると推測します。
d) $\mu(X) = 1$ と $f^r$ と $\log f$ が可積分である場合、$f$ がほぼどこでも定数である場合にのみ $G(f) \leq N_r(f)$、等式が成り立つことを示します (Exer. 4 を使用します)。
e) $\mu(X) = 1$ と、$f$ と $g$ が 2 つの測定可能な写像であり、$G(f)$ と $G(g)$ が定義される場合、$G(f + g)$ が定義され、$G(f) + G(g) \leq G(f + g)$、等式が 2 つ存在する場合にのみ成立することを示します。 数 $\alpha, \beta$、零の両方ではなく、ほぼどこでも $\alpha f(x) = \beta g(x)$ になるか、写像 $f/(f + g)$ と $g/(f + g)$ を考慮して $G(f + g) = 0$ ($d$ を利用する) の場合)。
