$\mu$ を区間 $X = [0, +\infty[$ のルベーグ測度とする。
a) $k > 1$、$h < k$ を 2 実数とします。 $1 \leq p \leq +\infty$、写像 $f_n(x) = n^h / (x + n)^k$ 属するから $\mathscr{L}^p$ のように、$n \geq 1$ ごと、および数 $p$ ごとにそれを示します。 $N_p(f_n)$ は $p > 1/(k - h)$ の $1/n$ で 0 になる傾向があるが、$N_p(f_n)$ の数列は $p < 1/(k - h)$ に限定されないことを示します。
b) $k$ を数 $< 1$ とします。 $n > 1$ および数 $p$ ごとに、$1 \leq p \leq +\infty$、写像 $g_n(x) = n^k e^{-nx}$ 属するから $\mathscr{L}^p$ となることを示します。 $N_p(g_n)$ は $p < 1/k$ の $1/n$ で 0 になる傾向があるが、$N_p(g_n)$ の数列は $p > 1/k$ に限定されないことを示します。
a) と b) から、$1 \leq p < q \leq +\infty$ の場合、$\mathscr{L}^p$ と $\mathscr{L}^q$ のトポロジーによって $\mathscr{L}^p \cap \mathscr{L}^q$ に誘発されるトポロジーは比較できないと推測します。
c) $\mu$ が区間 $[0, 1]$ のルベーグ測度である場合、同様に、$p < q$ の場合、位数 $q$ の平均収束の位相は、厳密に位相の平均収束よりもより細かいであることを示します。 位数 $p$ ($\mathscr{L}^q$)。
