$F$ をバナッハ空間とし、$F'$ をその双対とします。 $1 \leq p \leq +\infty$ のようなすべての $p$ を、$\Lambda_{F'}^p(T, \mu)$ (または単純に $\Lambda_{F'}^p$) で表し、写像の集合 $T$ の $f$ を $F'$ に変換し、$z \in F$ ごとに数値写像 $\langle z, f \rangle$ 属するから $L^p(T, \mu)$ まで。 1 つは $\Lambda_{F'}^p \supset L_{F'}^p$ で、$\Lambda_{F'}^1$ は $F'$ の値を備えたスカラー的に本質的に $\mu$ 積分可能な関数の空間です ($F'$ には $\sigma(F', F)$ が装備されています)。 $L^p(\mu)$ の $\langle z, f \rangle$ の $\theta(z)$ 類で示されるように、写像 $z \mapsto \theta(z)$ は連続 (No. 4, 補題 2) であることがわかります。 $M_p(f)$ をそのノルムとします。これは空間 $\Lambda_{F'}^p$ の準標準です。 $M_p(f) = 0$ の位数では、$f$ が局所的にスカラー的に無視できることが必要かつ十分です。

a) $f \in \Lambda_{F'}^p$ の位数では、すべての数値写像 $g \in L^q$、写像 $gf$ が本質的にスカラー的に $\mu$ 積分可能であることが必要かつ十分です。その場合、1 つは $M_1(gf) \leq M_p(f) N_q(g)$ になります。

b) 空間 $\Lambda_{F'}^1$ では、半ノルム $M_1$ が半ノルム $M'_1(f) = \sup |\int_A f d\mu|$ と等価であり、$A$ が $T$ の測定可能な部分集合の集合を超えていることを示します。より正確には、$M'_1 \leq M_1 \leq 2M'_1$。このことから、$M_p$ は $M'_p(f) = \sup_{N_q(g) \leq 1} M'_1(gf)$ と同等の準ノルムであると推測できます。

c) $F$ については可算正規直交数基底を持つヒルベルト空間を、$\mu$ については $T = [0, 1]$ のルベーグ測度をとります。 $T$ の写像が $F$ に存在し、積分可能ではないがスカラー積分可能であること、つまり可測ステップ写像の数列の準ノルム $M_1$ に対して極限が存在することを示します (cf. Exer. 11)。このことから、$\mu$ 可積分関数の空間 $L_{F'}^1$ では、半ノルム $M_1$ で定義される位相は、$N_1$ で定義されるものより厳密に粗いことが推測されます。 $1 \leq p < +\infty$ に対する準ノルム $M_p$ と $N_p$ の同様の結果。

d) 空間 $L_{F'}^\infty$、$M_\infty = N_\infty$ でそれを示します。

e) 二重数列 $(e_{mn})$ に配置された可算直交基底を持つヒルベルト空間を $F$ とします。 $\mu$を$T = [0, 1]$のルベーグ測度とする。 $u_m$ を $T$ の $F$ の写像とし、$(n-1)2^{-m} \leq t < n2^{-m}$ と $1 \leq n \leq 2^m$ および $u_m(1) = 0$ を$u_m(t) = e_{mn}$ とします。 集合 $f_n = \sum_{i=0}^n u_i$。 $1 \leq p < +\infty$ について、$(f_n)$ は $\Lambda_{F'}^p$ のコーシー 数列ですが、$\Lambda_{F'}^p$ のどの写像にも収束しないことを示します。

f) $(f_n)$ を空間 $\Lambda_{F'}^p$ ($1 \leq p \leq +\infty$) のコーシー 数列とする。 $F'$ に $T$ の写像 $f$ が存在し、$z \in F$ ごとに、写像 $\langle z, f_n \rangle$ の数列が$\langle z, f \rangle$ に収束すると仮定します (Ch. IV, §5, No. 11)。 $f \in \Lambda_{F'}^p$ と数列 $(f_n)$ には $\Lambda_{F'}^p$ に極限 $f$ があることを示してください。

g) 絶対収束系列のバナッハ空間 $L^1(\mathbf{N})$ を $F$ とします。その双対は $F' = L^\infty(\mathbf{N})$ (TVS、IV, §1、Exer. 1) です。 $\mu$を$T = [0, 1]$のルベーグ測度とする。 $f$ を $T$ の写像から $F'$ にすると、$f(0) = 0$ となり、$2^{-n-1} < t \leq 2^{-n}$ の場合、$f(t)$ は数列となり、その項はすべて零になりますが、項は除きます。 添字 $n$、$1 \leq p < +\infty$ の $2^n/p$ に等しい。 $f$は$F'$の強い位相と属するから$\Lambda_{F'}^p$までは測定可能ですが、空間で$f$になる傾向のあるステップ写像の数列$(f_n)$は存在しないことを示してください。 $\Lambda_{F'}^p$。
