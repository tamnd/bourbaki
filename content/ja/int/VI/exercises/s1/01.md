局所的にコンパクトな空間 T, T' が区間 [0, 1] と同一であり、T と T' の測度 $\mu, \mu'$ がそれぞれルベーグ測度と同一であると考えてください。 F を可算直交基底を許容するヒルベルト空間とし、二重数列 $(e_{mn})$ に配置します。 $F' = F$ をその双対とします。 $(n-1)2^{-m} \leq t < n2^{-m}$ と $1 \leq n \leq 2^m$ の場合は集合 $u_m(t) = e_{mn}$。 集合 $f(t, t') = 2^m u_m(t)$ から $2^{-m} < t' \leq 2^{-m+1}$ 、そして最後に $f(t, 0) = 0$ と $f(1, t') = 0$ です。 $f$ は積メジャー $\mu \otimes \mu'$ に対してスカラー的に積分可能ですが、写像 $t' \mapsto f(t, t')$ はどの $t \in T$ に対してもスカラー的に $\mu'$ 積分可能ではないことを示します。
