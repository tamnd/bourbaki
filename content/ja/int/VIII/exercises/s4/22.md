記法はエクサーのものです。 §4の21とExer。 §3の11。

a) (μ_n) を G 上の有界測度の数列とします。すべての写像 f ∈ L^1(G, β) について、数列 (μ_n \* f) が $\mathscr{P}_I$ で 0 に収束すると仮定します。 ノルム (||μ_n||) の数列が有界であることを示します (L^1(G, β) の写像 f ↦ μ_n \* f の族に対して Banach–Steinhaus 定理を使用し、Exer と同様にします)。このことから、$\mathscr{P}_I$ では数列 (μ_n) が 0 になる傾向があることが推測されます (Exer. 20 を使用)。

b) (μ_n) を、写像 f ∈ L^1(G, β) ごとに数列 (μ_n \* f) が漠然と 0 になる傾向があるような、G 上の有界測度の数列とします。 数列 (μ_n) が漠然と 0 になる傾向があることを示します (G のすべての圧縮部分集合 K について、a と同様に議論します)、数列 (|μ_n|(K)) は有界であることを示します。 例 (G = $\mathbf{Z}$) を与えます。ここで、数列 (||μ_n||) は有界ではありません。

c) (μ_n) を、写像 f ∈ L^1(G, β) ごとに、数列 (μ_n \* f) が $\mathscr{P}_{II}$ で 0 に収束するような G 上の有界測度の数列とします。 数列 (μ_n) が $\mathscr{P}_{II}$ で 0 に収束することを示します (a) を使用します)。
