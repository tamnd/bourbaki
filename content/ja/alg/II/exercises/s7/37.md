(a) $E$ を左ベクトル空間 (有限次元またはその他) および $E$ の $A_i$ ($1 \leq i \leq n$) ベクトル部分空間とします。 $E$ の点のすべての数列 $(a_i)_{1 \leq i \leq n}$ について、すべての $i$ の $a_i \in A_i$ が、$a_i$ によって生成された $E$ のベクトル部分空間が次元であると仮定します。 $\leq m$ ($m$ 整数 $\leq n$)。 次に、次元 $h \leq m$の$E$、部分空間 $A_i$の含む $h + (n - m)$の部分空間 $W$が存在することを証明してください。 ($n$の帰納法までに議論してください。 まず、(固定 $n$ の場合) 注意は、すべての $i$ に対して $m < n$ と $\dim(A_i) \leq m$ の場合に限定される可能性があることを証明します。また、すべての $i$ に対して $A_i \neq \{0\}$ があり、$A_i$ がすべての次元 1 ではないと仮定することもできます。 次に、$d = \sum_{i=1}^m \dim(A_i)$ について帰納法で (固定 $n$ について) 議論します。 たとえば$\dim(A_n) \geq 2$の場合、次元 1の$A_n$の1次元部分空間 $B_n$を考え、帰納法の仮定を$A_1, \ldots, A_{n-1}, B_n$に適用します。 結論するには、$1 \leq k \leq m$ と $A_i$ の $E$ 含む $k$ の $k$ 次元の部分空間 $U$ が存在するという数 $k$ が存在するとします。 $A_1, \ldots, A_k$; 置き換えること、必要に応じて、$1 \leq k' \leq k$ となる整数 $k'$ による $k$ は、$b_1, \ldots, b_k$ 形のように、$1 \leq i \leq k$ に対してベクトル $b_i \in A_i$ が存在すると仮定できることも示します。 $U$中基底;次に、$E$ の$U$ の補助部分空間に投影し、帰納法の仮定を使用します。)

(b) $K$ を有限体とし、$E$ を $K$ 上の $N$ 次元ベクトル空間とします。 $U_i$ ($1 \leq i \leq n$) を、$\{1, n\}$ の $H$ 部分集合ごとに、$i \in H$ が次元になるように、$U_i$ の共通部分を$E$ のベクトル部分空間とします。 $\leq N - \mathrm{Card}(H)$。 $U_i$ できないの和集合が $E$ に等しいことを示します ((a) を使用した双対性による議論)。
