(a) M、N、M'、N' を、M ∩ N = M' ∩ N' = P となるように、加群 E の 4 つの部分加群とします。

$$
M = (M + (N \cap M')) \cap (M + (N \cap N'))
$$

M が E において既約であれば、必然的に P = M' ∩ N または P = N' ∩ N になると推測します。

(b) (N_i)_{1 ≤ i ≤ n} を、E で既約な E の部分加群と M の共通部分の有限族とする。 (P_j)_{1 ≤ j ≤ m} が M = $\bigcap_j P_j$ であるような E の部分加群の有限族である場合、1 ≤ i ≤ n であるようなすべての添字 i に対して、1 ≤ φ(i) ≤ m であるような添字 φ(i) が存在することを示します。 $N'_i = \bigcap_{k \neq i} N_k$ と書くと、M = P_{φ(i)} ∩ N'_i ((a) を使用)。 添字 ≠ j の P_k の P_j 含む共通部分がいずれも存在しない場合、m ≤ n (上記の結果を使用して、適切な P_j による連続置き換える N_i) であると推定します。 E の M の 2 つの既約分解のうち 1 つは有限であり、必然的に項 (cf. 練習問題 23) の同じ数を持つ結論する。
