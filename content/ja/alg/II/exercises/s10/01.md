(a) $E$ を右側の $A$ 加群とする。 加法群 $E^r$ ($r \geq 1$ 付き) では、合成の外部法則は、$E^r$ のすべての元 $x = (x_i)_{1 \leq i \leq r}$ およびすべての$x.P$ で示される演算子の集合として $\mathbf{M}_r(A)$ で定義されます。 平方行列 $P = (\alpha_{ij}) \in \mathbf{M}_r(A)$、元 $y = (y_i)$ $E^r$ のような
$$
y_i = \sum_{j=1}^r x_j \alpha_{ji} \qquad (1 \leq i \leq r).
$$
この外部法則定義するは、$E^r$ に加法法則を加え、$E^r$ に右側の $\mathbf{M}_r(A)$ モジュール構造を持ちます。スカラー行列$I.\alpha$の環の演算子の環を制限することで、$E^r$上の積$A$モジュール構造が復元されます。 $A$加群 $E$ が $r$ 元の生成する系を持つためには、 $\mathbf{M}_r(A)$ 加群 $E^r$ が単種であることが必要かつ十分であることを示してください。

(b) $(x_i)_{1 \leq i \leq n}$ を $E$ の生成する系および $(y_j)_{1 \leq j \leq m}$ を $E$ の元 (それぞれ $E$ の生成する系) とします。 $z, z', z''$を$E^{m+n}$の3つの元とし、$1 \leq i \leq n$は$z_i = x_i$、$1 \leq j \leq m$は$z_{n+j} = 0$、1は$z'_i = x_i$、$1 \leq j \leq n,\ z''_i = 0$は$1 \leq i \leq n,\ z''_{n+j} = y_j$を$\leq i \leq n,\ z'_{n+j} = y_j$とします。 $1 \leq j \leq n$。 $z' = z.P$ (それぞれ $z'' = z.Q$) となる 2 つの $\mathbf{M}_{n+m}(\mathbf{A})$ の反転可能な行列 $P, Q$ が存在することを示してください。

(c) $\mathbf{A}$ が可換である場合、$u_P : x \mapsto x.P$ は $\mathbf{A}$ モジュール $E'$ の自己準同型であり、写像 $P \mapsto u_P$ は環 $\mathbf{M}_r(\mathbf{A})$ の準同型から環になります。 $\operatorname{End}_\mathbf{A}(E')$。 $E$ が忠実な $\mathbf{A}$ モジュールである場合、この準同型は単射的です。
