Aを主イデアル整域、τをAの既約元、MをA上のπ主加群とする。Iを序数aの集合とする（集合理論、III、p. 225、例14）順序数 < a の集合の基数は、最大でも M の基数と等しくなります。次のような超限帰納法により、すべての a ∈ I に対する M の定義する部分加群 M^{(α)} は次のようになります。 M^{(0)} = M とします。 M^{(α + 1)} = πM^{(α)} とします。そして a が極限序数の場合、M^{(α)} は β < a のすべての M^{(β)} の共通部分となります。

a) M^{(τ + 1)} = M^{(τ)} (M の末端序数) となる最小序数 τ ∈ I が存在することを示します。 M^{(τ)} が M に補数を認め、部分加群の直和が U_π と同型であることを示します (例 3)。 M^{(τ)} = 0 の場合に M が減少するとします。
b) M を縮小τモジュールとする。すべての x ∈ M について、x ∈ M^{(γ(x))} となるような最大の個の順序 γ(x) ≤ τ が存在することを示します (特に、γ(0) = τ)。例の定義を一般化する8 では、γ(x) は M における x の高さであると言います。γ(x) < γ(y) の場合は γ(x + y) = γ(x) であり、γ(x) = γ(y) の場合は γ(x + y) ≥ γ(x) であることを示します。すべての y ∈ N に対して高さ γ(x + y) が最大でも γ(x) に等しい場合、x は M の部分加群 N に関して適切であると言います。すべての y ∈ N に対して、 γ(x + y) = inf(γ(x), γ(y)) であることを示します。
c) a < τ を序数とし、M^{(α)} を、ある y ∈ M^{(α + 1)} に対して πx = πy となるような x の M^{(α)} からなるの部分加群とする。この性質, 元を持つ y ∈ M^{(α + 1)} に対して、形 u = x − y 形類 mod M(π) ∩ M^{(α − 1)} in M(τ) ∩ M^{(α)}; φ が M(π) ∩ M^{(α)} からこの加群の商に M(π) ∩ M^{(α + 1)} によって標準準同型である場合、x を φ(u) に送る写像 ψ が核で準同型であることを示します。 M^{(α − 1)}、従って、その M^{(α)}/M^{(α + 1)} は (M(π) ∩ M^{(α)})/(M(π) ∩ M^{(α + 1)}) と同型です。
d) N を M の部分加群とし、x ∈ M^{(α)} を高さ α の元とする。 対応する元 u = x − y of M(π) ∩ M^{(α)} (cf. c)) が N に関して適切である場合に限り、x が N に関して適切であることを示します。 このような元 x が存在するのは、N ∩ M^{(α)} の像である場合に限ります。 準同型 ψ は (M(π) ∩ M^{(α)})/(M(π) ∩ M^{(α − 1)}) とは異なります。
