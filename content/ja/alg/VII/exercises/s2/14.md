M を縮小τ一次加群とします。例の記法で。 13、各序数 a < τ について、(M(π) ∩ M^{(α)}/(M(π) ∩ M^{(α + 1)}) を体 F_π = A/Aπ 上のベクトル空間として考えることができます。c(α) がこのベクトル空間の次元を表し、c(α) を呼び出します。 加群 M の序数 a の重複度 (cf. VII, p. 24)。
a) M と N が 2 つの τ 主要加群で、それぞれが巡回部分加群の直和である場合 (τ ≤ ω、最初の無限序数であることを意味します)、M と N は、すべての終端序数 τ と重複度が同じである場合に限り、同型であることを示します。 整数 n < τ は M と N で同じです。
b) 無限の高さの元を持たない 2 つのτ 1 次加群の例を与えます。これらは同型ではありませんが、各整数 n は同じ重複度を持ちます (cf. 例 10、f))。
c) M と N を、それぞれ生成元の可算無限大系を持つ 2 つの縮小τ原数加群とします。 M と N が同じ末端序数 τ を持ち、各序数 a < τ が M と N で同じ重複度をもつ場合、M と N は同型であることを示します。

(« ウルム・ジップン定理 ») (2 つの部分加群 S ⊂ M と T ⊂ N が与えられた場合、すべての x ∈ S について、M の x の高さが N の $h(x)$ の高さに等しい場合、S から T への同型 h は指示的であると言われます。 定義する帰納法による M から N への指標同型と、M と N が果たす役割交代的によって、次のように簡約する問題: 有限に生成された 2 つの部分加群 S ⊂ M と T ⊂ N が与えられた場合、指標S から T への同型 h、および S + Ax から N 含む T の部分加群への指標同型への元 $x \in M \cap C S$、拡大する h。 これが $\tau x \notin S$; の場合に帰着できることを示してください。例を使用して。 5、選ぶ元 w、$(S + Ax) \cap C S$でMで最大のの可能な高さ$a$、次に$S \cap M^{(\alpha)}$で選ぶ元$w_2$となり、Mで$\pi(w_1 + w_2)$の高さは最大の可能です。 $w = w_1 + w_2$ が S に関して適切であることを示します (例 13、b))。 $z = h(\tau w) \in T$ にしましょう。 T に関して適切な、N の高さ $a$ の N の元 t が存在する場合、$\pi t = z$ である場合、$\overline{h}(w) = t$ を置くことで、目的の形の h の拡大 $\overline{h}$ が得られることを示します。 元 t の存在を証明することはまだ残っています。 もし

$$
\gamma(z) = \gamma(\pi w) = \alpha + 1 < \tau,
$$

$N^{(\alpha)} \cap C T$ には $z = \pi u$ となる元 $u$ が存在し、t はそのような元であるとみなせることを示します。一方、$\gamma(z) = \gamma(\pi w) > \alpha + 1$ の場合、または $\gamma(z) = \gamma(\pi w) = \alpha + 1 = \tau$ の場合は、例を使用します。 (例 13 の記法において) $(M(\tau) \cap M^{(\alpha)})/(M(\tau) \cap M^{(\alpha + 1)})$ の $S \cap \tilde{M}^{(\alpha)}$ の $\psi$ の下の像が体 $F_{\sigma}$ にわたって有限次元であることに注目して、元 t の存在を証明する。
