C を主理想領域とし、$A = (\alpha_{ij})$ を C にわたる n 次の正方行列とします。
a) 行列式 1 で、C にわたって n 次の正方行列 U が存在し、行列 UA の最後の列の最初の $(n-1)$ エントリが 0 で、最後のエントリが $A$ の n 列目のエントリの gcd に等しいことを示します (例 20、b) を使用)。
b) a) から、行列式 1 をもつ C 上の n 次の正方行列 V が存在し、行列 VA = $(\beta_{ij})$ が下三角行列 (「A のエルミート縮小形」) であると推定します。
c) W が行列式 1 で C 上の n 次の正方行列で、WA = $(\gamma_{ij})$ が下三角である場合、$\beta_{ii}$ と $\gamma_{ii}$ が $1 \leq i \leq n$ に関連することを示します。
