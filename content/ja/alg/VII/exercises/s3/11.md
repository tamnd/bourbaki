A と B を有理素数数の 2 つの無限集合とし、共通の元を持たず、含む数を持たないものとします。 5. $(e_i)_{1 \leq i \leq 4}$ を $\mathbf{Q}$ ベクトル空間 $\mathbf{Q}^4$ の標準基底とします。
a) M を、$m \in A$ に対して元 $e_1/m$ によって生成された $\mathbf{Q}^4$ の Z サブモジュールとする。 N を、元 $e_2/m$ と $m \in A$、 $e_3/n$ と $n \in B$、および $(e_1 + e_3)/5$ によって生成される $\mathbf{Q}^4$ の Z サブモジュールとします。それから$M \cap N = 0$。 $e'_1 = 8e_1 + 3e_2$と$e'_2 = 5e_1 + 2e_2$を入れます。 $M'$ を、元 $e'_1/m$ と $m \in A$ によって生成された $\mathbf{Q}^4$ の Z サブモジュールとします。 $N'$ を、元 $e'_2/m$ と $m \in A$、$e_4/n$ と $n \in B$、および $(3e'_2 + e_3)/5$ によって生成される $\mathbf{Q}^4$ の Z サブモジュールとします。 $M' \cap N' = 0$、その $M \oplus N = M' \oplus N'$ を表示します。 M と $M'$ は同形であり、分解不可能であること。そして、N と N' は分解不可能だが同型ではない (VII、p. 69、例 23 を比較)。
b) M を、A の m \ を持つ元 e_1/m、B の n を持つ e_2/n、および (e_1 + e_2)/5 によって生成される Q^4 の Z サブモジュールとします。 N を、A に m \ を含む元 e_3/m、B に n \ を含む e_4/n、および (e_1 + e_4)/5 によって生成される Q^4 の Z サブモジュールとします。 e'_1 = 2e_1 + e_3、e'_2 = e_2 + 3e_4、e'_3 = 17e_1 + 9e_3、および e'_4 = e_2 + 2e_4 とします。 M' を、A の m \ に対して元 e'_1/m、B の n に対して e'_2/n、および (e'_1 + 2e'_2)/5 によって生成される Q^4 の Z サブモジュールとします。 N' を、A の m \in に対して元 e'_3/m、B の n に対して e'_4/n、および (e'_3 + 2e'_4)/5 によって生成される Q^4 の Z サブモジュールとします。 M \oplus N = M' \oplus N' であること、M は N と同型であり、M' は N' と同型であるが、M' は M と同型ではないことを示します。
c) M を e_1/5^n (n \geq 0) によって生成された Q^4 の Z サブモジュールとします。 N を、e_2/5^n、e_3/2^n、e_4/3^n (n \geq 0)、(e_2 + e_3)/3、および (e_2 + e_4)/2 によって生成された Q^4 の部分加群とします。 e'_1 = 3e_1 - e_2 および e'_2 = 2e_1 - e_ とします。 M' を、元 e'_1/5^n、e_3/2^n (n \geq 0) および (e'_1 - e_3)/8 によって生成された Q^4 の Z サブモジュールとします。 N' を、元 e'_2/5^n、e_4/3^n (n \geq 0) および (e'_2 - e_4)/2 によって生成される Q^4 の Z サブモジュールとします。 M \oplus N = M' \oplus N' であること、M と N' が階数 2 に分解不可能であること、そして M が階数 1 を持つことを示してください。
