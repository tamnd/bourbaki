$A,B$、C を環、$f: A\rightarrow C$、$g: B\rightarrow C$ 環準同型とします。 $f$ が全射であると仮定します。 $f(a) =g(b)$ となるような対 $(a, b)$ の $A\times B$ からなるの部分環 D を考えてみましょう。 M を A-加群、N B-加群、および $u$ を $C\otimes_AM$ から $C\otimes_BN$ までの C 同型写像とする。 $u(1\otimes m) = 1\otimes n$ となるように、対 $(m, n)$ の $M\times N$ からなるの D サブモジュールを P で表します。

a) 加群 M と N が有限基底 $(e_i)_{i\in I}$ と $(f_j)_{j\in J}$ を許容し、基底 $(1\otimes e_i)$ と $(1\otimes f_j)$ の $u$ の行列が可逆行列行列の像であると仮定します。 $(a_{ji})$ に A のエントリが含まれています。D-加群 P が自由であることを証明します。より正確には、P の元 $(e_i,\sum_ja_{ji}f_j)_{i\in I}$ 形基底

b) $p$ と $q$ を整数と $X\in \mathbf{M}_{p,q}(C)$ と $Y\in \mathbf{M}_{q,p}(C)$ 行列とし、XY = $I_p$ および YX = $I_q$ とします。恒等式を使用して、平方行列 $\begin{pmatrix} X & 0 \\ 0 & Y \end{pmatrix}$ が A に要素を持つ可逆な行列の像であることを証明してください。

$$

c) 加群 M と N が自由で有限に生成されると仮定します。 a) と b) から、D-加群 P は射影であり、有限に生成されると推定します。

d) M と N が射影的であり、有限に生成されると仮定します。 構成する A-加群 $M'$ と B-加群 $N'$ では、$M\oplus M'$ と $N\oplus N'$ は自由で有限に生成され、C 加群 $C\otimes_AM'$ と $C\otimes_BN'$ は同型です。 D-加群 P は射影的であり、有限に生成されると推定します。

e) 2 つの射影から導出される標準準同型 $A\otimes_DP\rightarrow M$ と $B\otimes_DP\rightarrow N$ が全単射であることを証明せよ (簡約するは a) の条件が満たされる場合と同様)。

f) 逆に、$P'$ を有限生成射影 D-加群とします。 集合 $M'= A\otimes_DP'$ および $N'= B\otimes_DP'$ であり、$u': C\otimes_AM'\rightarrow C\otimes_BN'$ 標準同型で示されます。 $P'$ から $M'\times N'$ 誘導するまでの標準準同型が $(M',N', u')$ に関連付けられた $P'$ から D-加群までの D 線形同型であることを証明してください。

g) $\varphi_0: K_0(D)\rightarrow K_0(A)\times K_0(B)$ と $\psi_0: K_0(A)\times K_0(B)\rightarrow K_0(C)$ 準同型で次のように表します。

$\varphi_0([P]) = ([A\otimes_DP],[B\otimes_DP])$ と $\psi_0([M],[N]) = [C\otimes_AM]-[C\otimes_BN]$。

数列を証明してください

$$
K_0(D)\longrightarrow^{\varphi_0}K_0(A)\times K_0(B)\longrightarrow^{\psi_0}K_0(C)
$$

正確です。さらに、$f\circ s=$ Id$_C$ となる環準同型 $s: C\rightarrow A$ が存在する場合、$\varphi_0$ は単射であり、$\psi_0$ は全射であることを証明してください。
