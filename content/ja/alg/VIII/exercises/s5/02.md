Kを可換体、Aを$\mathbf{M}_3(K)$の部分環、行列の形のからなるとする

$a$ 0 0

$bc$ 0

0 0 $a$

K の $a, b, c$ について。M を A-加群 $K^3$ とします。 部分加群 $N = Ke_1+ Ke_2$ と $P = Ke_3$ の直和です。

a) M が平衡であること、標準写像 $A''_M\rightarrow A''_N$ (練習問題 1) は単射的であるが全射的ではないこと、および標準写像 $A''_M\rightarrow A''_P$ は全射的であるが単射的ではないことを証明します。

b) 標準写像 $B''_Q\rightarrow B''_R$ が単射でも全射でもないように、環 B と直和因子部分加群 R から加群 Q の例を推定します ($B = A\times A$ と $Q = M\times M$ をとります)。
