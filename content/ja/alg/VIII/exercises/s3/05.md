A を環とします。

a) M, N を一次 A-加群とする。次のプロパティが同等であることを証明します。

(i) A-加群 M と N は同形です。

(ii) M のすべての生成元 $m$ に対して、$m$ と同じ消滅子を持つ N の生成元 $n$ が存在します。

(iii) 同じ消滅子を持つMの生成元とNの生成元が存在します。

b) $\mathfrak{a},\mathfrak{b}$ を A の (左) イデアルとします。A-加群 $A/\mathfrak{a}$ と $A/\mathfrak{b}$ は、$Aa+\mathfrak{b}= A$ と $\mathfrak{a}$ が元の集合であるような A の元 $a$ が存在する場合に限り、同型です。 $xa\in \mathfrak{b}$ となるような A の $x$ (a) を使用します)。

c) $\mathfrak{m}$ と $\mathfrak{n}$ を A の最大左イデアルとする。 The simple A-modules $A/\mathfrak{m}$ and $A/\mathfrak{n}$ are isomorphic if and only if there exists an element $a$ of A$-\mathfrak{n}$ such that $\mathfrak{m}a\subset \mathfrak{n}$. d) Deduce from b) that the set of quotient A-modules of the A-module $A_s$ isomorphic to a given module has cardinal less than Card(A).
