Let $\varphi : H\rightarrow G$ be 群準同型, M a $\mathbf{Z}$[G]-module, N a $\mathbf{Z}$[H]-module, and $u: M\rightarrow N$ 準同型 of アーベル群. We say that $\varphi$ and $u$ are compatible if we have $u(\varphi (h)x) =hu(x)$ for every $h\in H$ and $x\in M$.

a) $n\geqslant 0$ について、$\varphi^n: H^n\rightarrow G^n$ を $\varphi$ から推定した写像とします。 $\varphi$ と $u$ に互換性がある場合、$C^n(G,M)$ から $C^n(H,N)$ への準同型 $c\mapsto u\circ c\circ \varphi^n$ は、$Z^n(G,M)$ を $Z^n(H,N)$ に、$B^n(G,M)$ を $B^n(H,N)$ に送信するため、誘導する準同型 $H^n(\varphi , u)$ $H^n(G,M)$ から $H^n(H,N)$ まで。 b) Let $\psi : K\rightarrow H$ be 他の群準同型, P a$\mathbf{Z}$[K]-module, and $v: N\rightarrow P$ 準同型 of アーベル群. $\varphi$ と $u$ が互換性があり、$\psi$ と $v$ も互換性がある場合、$H^n(\varphi \circ \psi , v\circ u) = H^n(\psi , v)\circ H^n(\varphi , u)$ になります。

c) 可換図式を考えてみましょう

0 // $M'$ // M // $M''$ // 0

$u'uu''$

0 // $N'$ // N // $N''$ // 0 、

ここで、最初 (または 2 番目) 行は $\mathbf{Z}$[G] モジュール (それぞれ $\mathbf{Z}$[H] モジュール) の完全系列であり、$u', u, u''$ は $\varphi$ と互換性があります。 図式を証明してください

$\cdots$ // $H_n(G,M')$ // $H_n(G,M)$ // $H_n(G,M'')$ // $H_{n+1}(G,M')$ /$/\cdots$

$H^n(\varphi ,u')H^n(\varphi ,u)H^n(\varphi ,u'')H^{n+1}(\varphi ,u)$

$\cdots$ // $H_n(H,N')$ // $H_n(H,N)$ // $H_n(H,N'')$ // $H_{n+1}(H,N')$ /$/\cdots$

(水平線は練習問題 1, c) で定義された長い完全系列です) は可換です。

d) 例: H = G の場合、写像 $u$ は、$\mathbf{Z}$[G]-線形である場合に限り、Id$_G$ と互換性があり、$H^n$(Id$_G, u$) $= H^n(G, u)$ が得られます。 N が $\varphi$ から推定される $\mathbf{Z}$[G] 加群構造を備えた M に等しい場合、準同型 $\varphi$ と $1_M$ は互換性があります。 Res$^q: H^q(G,M)\rightarrow H^q(H,M)$ 準同型 $H^q(\varphi ,1_M)$ (「制限準同型」) と表します。

e) Let H be a normal subgroup of G, and let $M^H$ be the subgroup of M consisting of the elements invariant under H, endowed with the action of $G/H$ deduced from that of G by passing to the quotient. 標準全射 $p: G\rightarrow$ $G/H$ および標準単射 $j: M^H\rightarrow M$ は互換性があります。 Inf$^q: H^q(G/H,M^H)\rightarrow H^q(G,M)$ 準同型 $H^q(p, j)$ (“インフレーション準同型”) で表します。 数列を証明してください

$$
0\rightarrow H^1(G/H,M^H)\longrightarrow^{Inf^1}H^1(G,M)\longrightarrow^{Res^1}H^1(H,M)
$$

正確です。さらに、$H^1(H,M)$ が零であれば、数列

$$
0\rightarrow H^2(G/H,M^H)\longrightarrow^{Inf^2}H^2(G,M)\longrightarrow^{Res^2}H^2(H,M)
$$

正確です。
