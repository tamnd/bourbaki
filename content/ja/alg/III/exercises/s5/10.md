A を可換環とします。
$$
M' \xrightarrow{u} M \xrightarrow{v} M'' \longrightarrow 0
$$
A-加群と $n$ 整数 $> 0$ の完全系列。 完全系列になるように$L = \mathrm{Coker}(T^n(u))$とします
$$
T^n(M') \xrightarrow{T^n(u)} T^n(M) \to L \to 0.
$$
集合 $\{1, 2, \ldots, n\}$ の部分集合 J ごとに、次のように書きます。
$$
P_J = N_1 \otimes N_2 \otimes \cdots \otimes N_n,\quad \text{where } N_i = M' \text{ if } i \in J, N_i = M \text{ if } i \notin J
$$
(したがって、$P_\varnothing$ は $T^n(M)$ に等しい) および
$$
Q_J = N_1 \otimes N_2 \otimes \cdots \otimes N_n,\quad \text{where } N_i = M' \text{ if } i \in J, N_i = M'' \text{ if } i \notin J
$$
(したがって、$Q_\varnothing$ は $T^n(M'')$ に等しい)。 $0 \leq i \leq n$ のようなすべての整数 $i$ について、$P^{(i)}$ は、すべての部分集合 $J$ に対して、$P_J$ の像の和集合によって生成された $T^n(M)$ の部分加群を表します。 $\mathrm{Card}(J) = i$ そして、$L^{(i)}$ を $L$ の $P^{(i)}$ の標準像とします。

(a) 正規の全射準同型が存在することを示す

$$
\bigoplus_{\mathrm{Card}(J)=i} Q_J \to L^{(i)}/L^{(i+1)}
$$

(cf. II, § 5, no. 6、命題 6)。

(b) 数列 $0 \to M' \xrightarrow{u} M \xrightarrow{v} M'' \to 0$ が正確で、分裂の場合、(a) で定義された準同型が全単射であることを示せ。
