K を可換体、E、F に 2 つの K-代数があり、それぞれ単位元があり、これは K の単位元 1 と識別されます。K-代数 $T(E \oplus F)$ を考えてください。ここで、$E \oplus F$ は K 上のベクトル空間と見なされます。 E (それぞれ F) は、標準単射の下の $T(E \oplus F)$ の *ベクトル部分空間* で識別されます。 $J$ を、元 $x_1 \otimes x_2 - (x_1x_2)$ と $y_1 \otimes y_2 - (y_1y_2)$ によって生成される $T(E \oplus F)$ の両側理想とします。ここで、$x_i \in E$、$y_i \in F$、$i = 1, 2$ です。 $E * F$ は商代数 $T(E \oplus F)/J$ を表します。それは、K-代数 E と F の *自由な積* と呼ばれます。 $\phi$ は、$E * F$ と $\alpha$ 上の $T(E \oplus F)$ の標準準同型と、$\phi$ の $\beta$ 制限を E と F に表します。 $\alpha$ と $\beta$ は K-*代数* 準同型です。

(a) K 準同型 $u : E \to G,$ v : F → G から K-代数 G への順序付き対ごとに、u = w ∘ α および v = w ∘ β となる K 準同型 w : E \* F → G が 1 つだけ存在することを示します (これは用語を正当化します)。

(b) R_n を 0 ≤ k ≤ n の T(E ⊕ F) のベクトル部分空間和 T^k(E ⊕ F) とし、J_n = J ∩ R_n と書きます。 E からなる of 1 と族 (e_\lambda)_{\lambda \in L} の基底と F からなる of 1 と族 (f_\mu)_{\mu \in M} の基底を考慮すると、J_n + の補足部分空間が成り立つことを示してください。 R_{n-1} は、R_n の部分空間と形の基底元を考慮することによって R_n で取得されます。 z_1 \otimes z_2 \otimes \cdots \otimes z_n ここで、いずれかの z_{2j+1} は 2j + 1 の e_\lambda の 1 つに等しい≤ n および z_{2j} は 2j ≤ n の f_\mu の 1 つに等しいか、または z_{2j+1} は 2j + 1 ≤ n の f_\mu の 1 つと等しく、z_{2j} は 2j ≤ n の e_\lambda の 1 つに等しい (n について帰納法による引数)。

(c) P_n = \phi(R_n) \部分集合 E \* F とします。次に、P_n \部分集合 P_{n+1}、P_0 = K、P_h P_k \部分集合 P_{h+k}、および E \* F は P_n の和集合です。 n ≥ 1 の場合、正規のベクトル空間同型が存在することを示します。

$$
P_n / P_{n-1} \to (G_1 \otimes G_2 \otimes \cdots \otimes G_n) \oplus (G_2 \otimes G_3 \otimes \cdots \otimes G_{n+1})
$$

ここで、k が奇数の場合は G_k = E/K、k が偶数の場合は G_k = F/K と書きます。特に、準同型 α と β は単射法であるため、E \* F の部分 K 代数を使用して同一視する E と F を使用できます。P'_n (または P''_n) は、G_1 \otimes G_2 \otimes \cdots \otimes G_n (それぞれ G_2 \otimes) の P で逆像を表すために使用されます。 G_3 \otimes \cdots \otimes G_{n+1}); h(z) で示される元 z \in E \* F の高さは最小の整数であり、z \in P_n となります。 h(z) = n かつ z \in P'_n (または z \in P''_n) の場合、z は純粋な奇数 (または純粋な偶数) と呼ばれます。このとき、n ≥ 1 の場合、P_n = P'_n + P''_n および P'_n \cap P''_n = P_{n-1} となります。

(d) u、v が h(u) = r、h(v) = s であるような E \* F の 2 つの元である場合、h(uv) ≤ h(u) + h(v) であり、h(uv) = h(u) + h(v) 〜でない限り u と v は純粋であり、r が偶数で u、v が同じパリティではないか、または r が奇数で u、v がパリティであることを示します。同じパリティです。 (たとえば r が偶数の場合、u \in P'_r、v \in P'_s は、u \in P_{r-1} または v \in P_{s-1} の場合にのみ uv \in P_{r+s-1} が可能であることを示します。)

(e) E には零の因子がないと仮定し、(d) の記法では、r が偶数、u が純粋な偶数、v が純粋な奇数であると仮定します。 h(uv) = r + s - 1, 〜でない限り uy \in P_{r-1} と xb \in P_{s-1} となるような E の 2 つの可逆元 x, y が存在することを示してください。 ((a_i) (それぞれ (b_j)) を、(b) で考慮した R_r の J_r + R_{r-1} (R_s の J_s + R_{s-1}) の補足部分空間の基底とします。u = \和_i \phi(a_i)x_i および v = \和_j と書きます。 y_j\phi(b_j)、ここで、x_i と y_j は E にあり、uv \in P_{r+s-2} の場合、必然的に x_iy_j \in K になることを示します。) E と F に零の因子がないと仮定される場合、h(uv) < h(u) + h(v) である他のケースも同様に扱います。

(f) (d) と (e) から、E と F に零の因子が存在せず、E \* F も存在しないと推定します。

(g) 上記の定義と結果を単位 K-代数の任意の有限数に一般化します。
