C を環 A 上の余代数とします。C のサブ A モジュール S は、$c(S) \subset \operatorname{Im}(S \otimes S)$ の場合、C の *部余代数* と呼ばれます。

(a) C が共結合的 (または共可換的) であれば、すべての部余代数も同様です。 $\gamma$がCの余単位である場合、$\gamma$の制限とCの部余代数は余単位です。

(b) 余代数 $A^{(X)}$ (no. 1、*例 4*) のうち部余代数はどれですか?

(c) $(S_\alpha)$ が C の部余代数の家族である場合、$\sum_\alpha S_\alpha$ は C の部余代数 (最小の含むすべての $S_\alpha$) です。
