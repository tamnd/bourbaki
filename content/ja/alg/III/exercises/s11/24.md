C を環 A よりも余代数とします。C のサブ A モジュール S は、$c(S) \subset \operatorname{Im}(S \otimes C)$ (それぞれ $c(S) \subset \operatorname{Im}(C \otimes S)$) の場合、*右* (または *左*) *coideal* と呼ばれます。

(a) 部余代数 (練習問題 23) は左右の共理想です。 A が体の場合、逆は真です。

(b) 右 (それぞれ左) コイデアルのすべての和は、右 (それぞれ左) コイデールです。

(c) S が C の右 (または左) 共イデアルである場合、直交 $S^0$ は双対代数 $C^*$ の右 (または左) イデアルです。

(d) A が体と $\mathfrak{J}'$ が双対代数 $C^*$ の右 (それぞれ左) イデアルである場合、C の直交 $\mathfrak{{J}'}^0$ は C の右 (それぞれ左) 共イデアルです。 ($c(x) \notin \mathfrak{{J}'}^0 \otimes C$ となるような $x \in \mathfrak{{J}'}^0$ が存在すると仮定して *不条理な縮約* によって議論します。$z_i$ が線形独立である場合に $c(x) = \sum_i y_i \otimes z_i$ を書き、$\langle y'z', x \rangle \neq 0.$ となるような $y' \in \mathfrak{J}'$ と $z' \in C^*$ が存在することを示します。)

C のベクトル部分空間 S が右 (それぞれ左) 理想であるためには、$S^0$ が $C^*$ の右 (それぞれ左) イデアルであることが必要かつ十分であると推測します。

(e) (d) から、A が体の場合、C の右コイデアル (それぞれ左コイデアル、それぞれ部余代数) のすべての共通部分が右コイデアル (それぞれ左コイデアル、それぞれ部余代数) であると推定します。 S が C の部余代数であるためには、その直交 S^0 が代数 C* の両側イデアルであることが必要かつ十分です。
