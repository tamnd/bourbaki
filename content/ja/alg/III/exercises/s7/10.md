n 元の生成する系を用いて E を A-加群とします。 $E^n$ の A 加群 F への交互の n 線形写像はすべて、$E^n$ の F への n 線形写像の歪対称化であることを示します。 ($a_j$ ($1 \leq j \leq n$) を E の生成子とし、$\phi : A^n \to E$ をすべての j に対して $\phi(e_j) = a_j$ となるような準同型写像とします。 $(e_j)$ は $A^n$ の正規の基礎です。 $f : E^n \to F$ が交代的 n 線形マッピングの場合、$f_0 : (x_1, \ldots, x_n) \mapsto f(\phi(x_1), \ldots, \phi(x_n))$ も同様です。 $g_0$ が $(A^n)^n$ の F への n 線形写像である場合、$f_0 = ag_0$、$g_0$ は $(x_1, \ldots, x_n) \mapsto g(\phi(x_1), \ldots, \phi(x_n))$ としても書けることを示します。ここで、g は $E^n$ の F への n 線形写像です。)
