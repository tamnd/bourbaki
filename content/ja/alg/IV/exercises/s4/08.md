$(1 + X)^T$ 元 $\exp(T \log (1 + X))$ の $\mathbf{Q}[[X, T]]$ で表します。
a) $(1 + X)^T = \sum_{n \geq 0} \frac{T(T-1) \ldots (T-n+1)}{n!} X^n$ を示します。 ($X^n$ の係数は $T$ の多項式であり、その値は $T = n \in N.$ で知られています)
b) $(1 + X)^l (1 + X)^T = (1 + X)^{T+l}$ を示します。こうして得られた二項係数間の同一性を明示的に書き留めてください。 $(1 + X + Y + XY)^T = (1 + X)^T (1 + Y)^T$ を表示します。
