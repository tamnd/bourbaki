a) K を体および $X_1, \ldots, X_n$ として不定とします。 $K(X_1, \ldots, X_n)$ の任意の指数 $v_1 < v_2 < \ldots < v_n$ 行列式 $\det(X_i^{v_j})$ がゼロ以外であることを示します。

b) $s_k$ ($1 \leq k \leq n$) を、体 $K(X_1, \ldots, X_n)$ の $X_i$ と $r_1, \ldots, r_n$ n 元の初等対称多項式とします。 (新しい不定の T を付けて)

$$
R(T) = \frac{1 + r_1 T + \cdots + r_n T^n}{1 + s_1 T + \cdots + s_n T^n} = 1 + u_1 T + \cdots + u_k T^k + \cdots.
$$

係数 $u_k$ の $n$ が零である場合、すべての $u_k$ は零であることを示してください。 ($R(T)$ を単純な分数に分解します。)

*c) K が標数0 であると仮定します。 $\{v_1, v_2, \ldots, v_n\}$ を n 元 $\geq 1$ の $\mathbf{N}$ の集合とし、M を $\mathbf{N}$ におけるこの集合の補数とします。また、M が加法で安定していると仮定します。 $y_1, \ldots, y_n$ が $K(X_1, \ldots, X_n)$ の n 元である場合、次のようになることを示します。

$$
P_{v_j}(y_1, \ldots, y_n) = P_{v_j}(X_1, \ldots, X_n)
$$

$1 \leq j \leq n$の場合は$y_j = X_j$、$1 \leq j \leq n$の場合は置換を除く。 ($\log R(T) = v_1 T + v_2 T^2 + \cdots + v_k T^k + \cdots$ の展開を考え、$1 \leq j \leq n$ に対して $v_{v_j} = 0$ を観察し、$v_k$ と $u_k$ の間の関係を調べてください。)
