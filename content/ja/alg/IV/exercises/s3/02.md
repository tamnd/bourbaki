a) K を可換体とし、u = a_m X^m + a_{m+1} X^{m+1} + \ldots + a_n X^n を a_m \neq 0, a_n \neq 0 (0 \leq m \leq n) となるような K[X] の多項式とします。 g が K(X) の次数 d \neq 0 の有理分数である場合、u(g) は非ゼロであり、d > 0 の場合は次数 nd であり、d < 0 の場合は次数 md であることを示します。
b) K(X) の非定数有理分数 g は K(X) のすべての有理分数に代入可能であると推定します (g が次数 0 の場合、g - a が次数 < 0 となるような \ が K に存在することに注意してください)。
