*ringoid* は合成の 2 つの法則を含む集合 $E$ です: (a) 連想乗法 $xy$; (b) 法則加法的に記述されていますが、*どこでも定義されているわけではありません* (§ 1, no. 1) および満たす以下の条件:

(1) それは *可換* です (他の語では、$x + y$ が定義されている場合、$y + x$ と $x + y = y + x$ も同様です。その場合、$x$ と $y$ は *加算可能* と言われます)。

(2) $x$ と $y$ が加算可能である場合、$x + y$ と $z$ が加算可能であるためには、一方では $x$ と $y$ が、他方では $y$ と $z$ が加算可能であれば十分です。その場合、$x$ と $y + z$ は加算可能であり、$(x + y) + z = x + (y + z)$;

(3) 単位元 0 が存在します。

(4) 一方では $x$ と $z$、他方では $y$ と $z$ が加算可能であり、$x + z = y + z$ の場合は $x = y$ です。

(5) $x, y$ が加算可能な場合、$xz$ と $yz$ (それぞれ $zx$ と $zy$) も加算可能です
$$
(x + y)z = xz + yz
$$
(それぞれ $z(x + y) = zx + zy$) $z \in E$ 全員に。

すべての環は輪ゴムです。

(a) 定義と § 8 および上記の練習問題拡大するの結果が輪ゴムにどのように変換されるかを調べてください (輪ゴム $E$ の左イデアルは加法および $E.a \subset a$ の下で安定する $E$ の部分集合 $a$ です)。

(b) $G$ を演算子と $f$ と $g$ 2 つの$G$ の自己準同型で群とします。 写像 $x \mapsto f(x)g(x)$ が $G$ の準同型であるためには、サブグループ $f(G)$ のすべての要素が $g(G)$ のすべての要素と置換可能であることが必要かつ十分です。この準同型性が $f + g$ で表され、$fg$ が合成準同型性 $x \mapsto f(g(x))$ である場合、これらの合成法則を持つ $G$ の準同型性の集合 $E$ が単位要素を持つ *リンゴイド* であることを示します。 $E$ が環であるためには、$G$ が可換であることが必要かつ十分です。

元 $f \in E$ が $E$ のすべての元に加算可能であるためには、 $f(G)$ が $G$ の中心に含まれることが必要かつ十分です。これら自己準同型のうち集合 $N$ は、輪状体 $E$ の *核* と呼ばれる *疑似リング* です。

$G$ の自己準同型 $f$ は、$G$ のすべての内部自己同型と置換可能であれば *normal* と呼ばれます。 $G$ の通常の安定した部分群 $H$ ごとに、$f(G)$ は $G$ の通常の安定した部分群になります。 $G$ 形の正常な自己準同型の集合 $D$ が $E$ の部分リンゴイドであり、核 $N$ が $D$ の両側理想であることを示してください。
