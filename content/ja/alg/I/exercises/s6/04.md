(a) G を位数 $mn$ の有限群とし、位数 m の周期である G の通常の部分群 H、位数 n の周期である剰余群 G/H が存在するようにします。 G が 2 つの元 a, b によって $a^m = e, b^n = a^r, bab^{-1} = a^s$ となるように生成されることを示します。ここで、r と s は 2 つの整数で、$r(s - 1)$ と $s^n - 1$ は m の倍数 (a を剰余類の元生成する H、b 元とします) 生成する G/H; 元 $b^h a^k b^{-h}$ を a の冪として表現し、これを特に $h = n, k = 1$ と $h = 1, k = r$ の場合に適用します。

(b) *逆に、$G(m, n, r, s)$ をプレゼンテーションによって定義された群とする*

$$
\langle a, b ; a^m = e, b^n = a^r, bab^{-1} = a^s \rangle,
$$

ここで、m と n は 2 の整数 $\geqslant 0$ であり、r と s は任意の整数 (cf. § 7, no. 6) です。 m、$r(s - 1)$、$s^n - 1$ がすべて零ではない場合、$G(m, n, r, s)$ は位数 $qn$ の有限群であり、q は m の最大の共通の因子であることを示します。 $|r(s - 1)|$ と $|s^n - 1|$;この群では、a によって生成された部分群 H は位数 q の通常の部分群であり、G/H は位数 n の循環群です ($G(m, n, r, s)$ のすべての元が形に書き込めることを証明します) $a^x b^y$、ここで、x と y は 2 つの整数で、$0 \leqslant x \leqslant q - 1, 0 \leqslant y \leqslant n - 1$ と $G(m, n, r, s)$ は、上記の条件を適用した整数の対 $(x, y)$ の群からなると同型です。 法則/合成

$$
(x, y) \cdot (x', y') = \begin{cases}
(x + x's^y, y + y') & \text{if } y + y' \leq n - 1 \\
(x + x's^y + r, y + y' - n) & \text{if } y + y' \geq n
\end{cases}
$$

右辺の最初の座標は $q$ を法とする和です。 $m = r(s - 1) = s^n - 1 = 0$ の場合を調べてください。

群 $G(n, 2, 0, -1)$ は、位数 $2n$ の*二面角群* と呼ばれ、$\mathbf{D}_n$ で表されます。 群 $G(4, 2, 2, -1)$ は、位数 8 の群であり、*四元数群* と呼ばれ、$\mathfrak{Q}$ で表されます。 $\mathfrak{Q}$ ではすべての部分群が正常であり、$\{e\}$ と異なる部分群の共通部分は $\{e\}$ とは異なる部分群であることを示してください。 $\mathbf{D}_4$ が $\mathfrak{Q}$* と同型ではないことを証明します
