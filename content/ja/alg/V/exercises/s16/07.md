Ex.の仮説が成立すると仮定します。 6 が成り立ち、さらに、$K$ 上の $E$ の不完全性の次数 (*V*、p. 170、例 1) は *有限* です (これは、$E$ が $K$ の有限生成された拡大である場合に常に当てはまります)。

*a*) $B$ を、$K(F^p)$ に対する $F$ の p 基底とし、これは、$K$ に対する $F$ の分離超越基底 (および $K$ に対する $E$ の超越基底) とします。すべての整数 $k > 0$ について、$B^{p^k}$ は $K(E^{p^{k+1}})$ 上の $K(E^{p^k})$ の p 独立の部分集合であることを示します。 $q = \operatorname{tr.deg}_K E$ にしましょう。 $m_k + q$ が $K(E^{p^{k-1}})$ に対する $K(E^{p^k})$ の不完全性の次数である場合、$f = \sum_{k=0}^{h-1} m_k$ である $p^f$ が次数 $[E : F]$ に等しいため、識別された部分拡張の選択から独立していることを示します。 $E$中$F$。 整数 $p^f$ は、$K$ に対する $E$ の不可分性 * 位数と呼ばれ、$[E : K]_i$ と書かれます。この数一致するは、$E$ が有限次数の場合、*V*、p. 46 の $[E : K]$ で示される分離不可能な次数となります。

*b*) $0 \leq k \leq h - 1$ の場合、$[K^{p^{-k}}(E) : K^{p^{-k}}]$ は $p^{f_k}$ に等しくなります ($f_k = \sum_{j=k}^{h-1} m_j$)。

*c*) $L$ を、$K$ 上で分離可能な $E$ の部分拡張とし、$E$ が p-ラジカルであり、$L$ 上で有限次数の部分拡張とする。 $[E : L] \geq [E : K]$ を示します ($[L(E^{p^k}) : K(E^{p^k})] = p^{r_k}$ の場合、$K(E^{p^k})$ に対する $L(E^{p^k})$ の基底と $K(L^p)$ に対する $L$ の基底を考慮して、$r_{k+1} \leq r_k + q$ を示します)。

*d*) $K'$ を $K$ の拡大とし、$K'$ と $E$ が同じ $K$ の代数閉拡大 $\Omega$ に含まれるようにします。 $K'(F)$ が $K'$ 上で分離可能である場合、それは $K'$ の拡大 $K'(E)$ の区別された部分拡張であることを示します。これは、$K'$ と $E$ が代数的に $K$ を超えて互いに素となり、$[K'(E) : K'] \leq [E : K]$ が得られる場合に当てはまります。 等式は、$K'$ と $E$ が $K$ 上で線形互いに素である場合、または $K'$ が $K$ の可分代数拡大である場合に成立します。

*e*) $[E : K]_i$ が、$K$ 上の $E$ のすべての超越基底 $B$ に対する $[E : K(B)]_i$ の最小値であることを示します。 $K$ が $\Omega$ における $K$ の相対代数閉包 (これは $K$ の代数閉包です) である場合、$[E : K(B)]_i = [E : K]_i [\bar{K}(E) : \bar{K}(B)]_i$ です。 $L$ が $E$ の部分拡張であり、$E$ が $L$ の代数拡大であり、$\bar{K}(E)$ が $\bar{K}(L)$ の可分 (代数) 拡大である場合、最大の分離拡大 $E$に含まれる$L$の$F$が区別されます。

*f*) $E$ が $K$ の有限生成された拡大であると仮定します。 $E$ のサブ拡張子 $L$ ごとに $[L : K]_i \leq [E : K]_i \leq [L : K]_i [E : L]_i$ があることを示します。 例を与えてください

$$
[L : K]_i = [E : K]_i \quad \text{and} \quad [E : L]_i > 1
$$
