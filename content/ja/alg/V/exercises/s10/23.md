k を特性 2 の体とします。
a) $A_1, \ldots, A_n$ を不定とし、多項式 $P = X^n + A_1 X^{n-1} + ... + A_n \in K[X]$ の K 体 $k(A_1, ..., A_n)$、E 分解体と E の P の $X_1, ..., X_n$ 根として、$E = k(X_1, ..., X_n)$ (V, p. 21) とします。変数 $X_1, ..., X_n$ (V, p. 59) の置換によって作用する対称群 $S_n$ を持つ E/K の同一視するガロア群です。置く
$$
\beta(X_1, ..., X_n) = \sum_{i < j} X_i/(X_i + X_j) \in E \quad \text{and} \quad C(A_1, ..., A_n) = \sum_{i < j} (X_i X_j)/(X_i^2 + X_j^2) \in K.
$$
次に$\beta \notin K$と
$$
\beta^2 + \beta + C = 0.
$$
$\sigma \in U_n$には$\sigma(\beta) = \beta$、$\sigma \in S_n - U_n$には$\sigma(\beta) = \beta + 1$がございます。 $K(\beta)$ は $E/K$ の一意の 2 次部分拡張であると推定します。
b) $D \in \mathbf{Z}[T_1, ..., T_n]$ を多項式 $X^n + T_1 X^{n-1} + ... + T_n$ の判別式とします。 Q、R、S $\in \mathbf{Z}[T_1, ..., T_n]$ が存在することを示します
$$
D = Q^2 - 4R + 8S
$$
そして
$$
C = C(A_1, ..., A_n) = \frac{R(A_1, ..., A_n)}{Q^2(A_1, ..., A_n)} = \frac{R(A_1, ..., A_n)}{D(A_1, ..., A_n)}.
$$
$D = U^2 - 4V + 8W$ となる元 U、V、W の $\mathbf{Z}[T_1, ..., T_n]$ のトリプルごとに、次のような $M \in \mathbf{Z}[A_1, ..., A_n]$ が存在します。
$$
C = \frac{V(A_1, ..., A_n)}{D(A_1, ..., A_n)} + \left( \frac{M}{D(A_1, ..., A_n)} \right)^2 + \frac{M}{D(A_1, ..., A_n)}
$$
c) $f = X^n + a_1 X^{n-1} + ... + a_n$ を $k[X]$ と分裂拡大の G ガロア群の分離可能な多項式とします。 $(a_1, ..., a_n)$ は C で置換可能であり、次の条件は同等であることを示します
(i) G 誘導するのすべての元と f の根の偶数置換 ;
(ii) $C(a_1, ..., a_n) = a^2 + a$ となるような $a \in k$ が存在します。
\* d) 以降、k は有限で、b) で述べた選ぶ元 U、V、$\mathbf{Z}[T_1, ..., T_n]$ の W を任意に満たす条件と仮定します。
c) の (i) と (ii) が次の条件と同等であることを示します。
(iii)
$$
\operatorname{Tr}_{k/\mathbf{F}_2}(C) = 0;
$$
(iv)
$$
\operatorname{Tr}_{k/\mathbf{F}_2}\left( \frac{V(a_1, ..., a_n)}{D(a_1, ..., a_n)} \right) = 0.
$$
(v) f の既約因子の数は、2 を法とする n に合同です (V、p. 165 の例 22 を使用)。 \*
