$f(X) = X^n + a_1 X^{n-1} + \ldots + a_n$ を Z[X] の多項式とし、p を素数数とします。 $a_i \equiv 0 \pmod{p}$、$1 \leq i \leq n$、そして$a_n \not\equiv 0 \pmod{p^2}$ だとします。 $f(X)$ が Q[X] で既約であることを示してください。 (Q[X] で $f(X) = P(X) Q(X)$ を分解とします。P と Q がモニックの場合、整数係数. 簡約する modp を持つことを示します。)
