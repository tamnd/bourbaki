K を次数 n の $K[X]$ における既約可分多項式体, $f_0$ とします。 $\alpha_i$ ($1 \leq i \leq n$) を $f_0$ の分解体北の根とします。 F を有理分数 $N(X_1, X_2, ..., X_n)$ の体、E を F の部分体 $K(X_1, X_2, ..., X_n)$ とします。 F は E のガロア拡大であり、$\mathrm{Gal}(E/F)$ は $\mathrm{Gal}(N/K)$ と正準的に同型です (V, p. 71, Th. 5 ; V, p. 154, 例 8)。 $8 = \alpha_1 X_1 + \alpha_2 X_2 + ... + \alpha_n X_n$ の場合、$F = E(8)$ となり、$E[T]$ の 8 の最小多項式 $g_1$ が多項式の既約因子であることを示します。

$$
f(T) = \prod_{\sigma \in S_n} (T - \alpha_1 X_{\sigma(1)} - \alpha_2 X_{\sigma(2)} - \cdots - \alpha_n X_{\sigma(n)})
$$

それぞれの置換 $\sigma \in S_n$、定義するは、$1 \leq i \leq n$ に対して条件 $\sigma(X_i) = X_{\sigma(i)}$ によって、再び a で表される E の K 自己同型です。 $\mathrm{Gal}(N/K)$ は、$\sigma(g_1) = g_1$ のような $S_n$ の部分群、置換のからなると同型であることを示します。さらに、$f = g_1 g_2 ... g_r$ が f の分解で、$E[T]$ の既約因子になる場合、$1 \leq j \leq r$ となるすべての添字 j に対して、$\sigma_j(g_1) = g_j$ となる置換 $\sigma_j \in S_n$ が存在することを示せ。
