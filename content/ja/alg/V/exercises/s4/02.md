K を特性 0 の代数閉体とします。 $X^{1/n!}$ の形式的な冪系列と $E = K((X))$ の $F = K((X^{1/n!}))$ 体、F の $X = (X^{1/n!})^{n!}$、部分体形式冪のからなる Xの系列。 すべての正式な冪系列 $f \in K((X))$ を $\omega(f)$ で表し、その位数を表します。
a) $P(Y) = a_n Y^n + a_{n-1} Y^{n-1} + \ldots + a_1$ を、$a_n \neq 0$ となるような次数 n の $E[Y]$ の多項式とします。 区間 $[0, n]$ 内に次のような整数の厳密に増加するシーケンス $(i_k)_0, \ldots, r$ が存在することを示します: 1" $i_0 = 0, i_r = n$; 2" $\omega(a_{i_k})$ は $0 \leq k \leq r$ に対して有限です。 $0 \leq j \leq n$ が$i_k$ とは異なり、$\omega(a_j)$ が有限であるような各インデックス j に対して 3" で、点 $(j, \omega(a_j)) \in \mathbf{R}^2$ は点 $(i_k, \omega(a_{i_k}))$、$(i_{k-1}, \omega(a_{i_{k-1}}))$ を通る直線の上にあり、$j < i_{k-1}$ または $j > i_k$ ($1 \leq k \leq r$) の場合は厳密にその上にあります。 $1 \leq k \leq r$ の点 $(i_{k-1}, \omega(a_{i_{k-1}}))$ と $(i_k, \omega(a_{i_k}))$ を結合するセグメントの和集合は P のニュートン多角形と呼ばれ、その前のセグメントはその辺、点 $(i_k, \omega(a_{i_k}))$ は頂点と呼ばれます。
b) $\rho_k = i_k - i_{k-1}$、$\sigma_k = (\omega(a_{i_k}) - \omega(a_{i_{k-1}}))/\rho_k$ を置きます。 P が正確に $\rho_k$ 零 (右から数えて重複度) 所属から体 $K((X^{1/(\rho_k!)})$ を持ち、その位数が $\sigma_k$ (形式的な式の再帰係数により決定する ) に等しいことを示します。この型満たすの方程式 $P(z) = 0$ の冪系列）。
c) 結論する、すべての整数 $n > 0$ の体 $K((X^{1/n}))$ の和集合は、体 $E = K((X))$ の代数閉包 (「ピューズの定理」)。
d) $K'$ が標数 2 の体と $E' = K'((X))$ である場合、$E'[Y]$ の多項式 $Y^2 + XY + X$ は、体 $K'((X^{1/n!}))$ の和集合に根を持ちません。
