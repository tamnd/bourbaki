K を特性 $p > 0$ の体とします。
a) E を K の次数 $p^e$ の巡回拡大とし、$\sigma$ を K 自己同型生成する群 Gal(E/K) とする。 F を K 上の次数 $p^{e-1}$ の体とし、$K \subset F \subset E$ とします。 $m = p^{e-1}$ の場合、$E = F(\theta)$ と $\sigma^m(\theta) = 0 + 1$ となる F[X] の既約多項式 $X^p - X - \alpha$ の $0 \in E$、根が存在することを示します。 $E = K(\theta)$ と $\sigma(\theta) = 0 + \beta$ も存在することを示してください。ここで、$\beta \in F$ は $\sigma(\alpha) - \alpha = \beta^p - \beta$ と $\operatorname{Tr}_{F/K}(\beta) = 1$ になります。
b) 逆に、F を K の次数 $p^{e-1}$ の巡回拡大 ($e > 1$ 付き)、$\sigma$ を F 生成する Gal(F/K) の K 自己同型とする。 $\operatorname{Tr}_{F/K}(\beta) = 1$ と $\sigma(\alpha) - a = \beta^p - \beta$ のような F の 2 つの元 $a, \beta$ が存在することを示します (V、p. 85 の Th. 3 と V、p. 49 の Prop. 1 の Cor. を使用します)。すべての $c \in K$ について、多項式 $X^p - X - a - c$ は F[X] で既約であると推測します。 0 が F の代数閉包 $\Omega$ におけるこの多項式の根である場合、$\sigma$ を拡張する $\Omega$ に $E = F(\theta)$ の K 準同型性 $a$ が存在し、$\bar{\sigma}(\theta) = 0 + \beta$ となることを示します。 結論する E は K の次数 $p^e$ の環状拡大、生成する Gal(E/K) および$E = K(0)$。最後に、K 含む F の次数 $p^e$ のすべての循環拡大が、適切な $c \in K$ に対する F[X] の多項式 $X^p - X - \alpha - c$ の分解体であることを示します。
