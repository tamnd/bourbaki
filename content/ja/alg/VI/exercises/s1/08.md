x を、y = inf(x, 0) が定義されるような順序付けられた群の元とします。 n > 0 が整数の場合、nx ≥ 0 は x ≥ 0 を意味します (次のようになります)

$$
ny = \inf(nx, (n-1)x, ..., 0) \geq \inf((n-1)x, ..., 0) = (n-1)y;
$$

したがって、nx = 0 は x = 0 を意味します。
