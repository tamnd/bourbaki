G を正の元 P を持つ群順序の格子とする。 P の 2 つの元 x と y は、一方と互いに素である元が他方とも互いに素である場合、等価であると言われます。 この関係の下の同値類は P のスレッドと呼ばれます。 $\overline{x}$ はスレッド含む x を表します。
a) $\overline{a}$ と $\overline{b}$ をスレッドとします。 x, $x_1$ を n の元とし、y, y を $\overline{b}$ の元とする。 x とのすべての元が y とも互いに素である場合、$x_1$ とのすべての元は $y_1$ とも互いに素であることを示します。 定義する関係このように a と b の間に、$a \geq b$ と書かれます。これがスレッドの集合 F の順序であることを示します。
b) F がこの順序に基づく格子であること、および次のことを示します。

$$
\inf(\overline{a}, \overline{b}) = \overline{\inf(a, b)}, \quad \sup(\overline{a}, \overline{b}) = \overline{\sup(a, b)} = \overline{a + b}
$$

(VI、p. 15のCor. 3を使用してください)。 F に最小の元、つまりスレッド $\overline{0} = \{0\}$ があることを示します。
c) $\inf(\overline{a}, \overline{b}) = \overline{0}$ の場合、2 つのスレッド a、b を互いに素に呼び出します。 a と b が 2 つのスレッド $\neq \overline{0}$ であり、$\overline{a} < \overline{b}$ の場合、a と互いに素であるスレッド $\overline{c}$ が存在し、$\overline{c} < \overline{b}$ となることを示します。
d) スレッド $\neq \overline{0}$ の集合の最小元である場合、スレッド m $\neq \overline{0}$ を既約と呼びます。既約スレッドが完全に順序付けされていることを示します (a と b が $\overline{m}$ の 2 つの元である場合、スレッド含む a $\inf(a, b)$ と $b - \inf(a, b)$ を考慮して b) を使用します)。 $\overline{m}$、$-\overline{m}$、$\{0\}$ の和集合が G の完全順序部分群 II($\overline{m}$) であることも示してください。
e) G の別個の既約スレッドの族 $(m_i)$ を与えて、$\overline{m_i}$ の和集合によって生成された部分群 H が群 H($\overline{m_i}$) の直和 (有限族の場合では簡約する ) と同型であることを示し、次のように議論します。 帰納法）。

f) 既約スレッドの非零の全順序群、元の積 (それぞれ直和) では、1 つ (正) を除いてすべての座標が零であることを示します。順序付けられた群は、せいぜい一方向で完全に順序付けられた群の非零の積 (それぞれ直和) になる可能性があると推測します (他の方法では、語因子は一意に決定されます)。
