A を A のすべての理想の可換環と I 集合とします。すると、I、p. 107 により、I のすべての $a, b, c$ に対して $a(b + c) = ab + ac$ が計算されます。他の語 I は、合成 $(a, b) \mapsto ab$ の位数関係 $a \supseteq b$ と法則が半格子順序モノイド (VI、p. 31、例 13) です。 2 つの元 a の上位、I の b は $a \cap b$ であり、それらの拡張子 $a + b$ です。

a) K を、K 上の 2 つの不定数の多項式の体および $A = K[X, Y]$ 環とします。A の主イデアル $a = (X), b = (Y), c = (X + Y)$ を考えます。

$$
(a \cap b) + c \neq (a + c) \cap (b + c),
$$
$$
(a + b) \cap b \neq (a \cap c) + (b \cap c),
$$
$$
(a \cap b)(a + b) \neq (a(a + b)) \cap (b(a + b))
$$

b) 環 A では、1 は X と Y の gcd ですが、$(X) + (Y) \neq A$ です。
