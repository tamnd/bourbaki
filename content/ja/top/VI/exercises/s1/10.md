a) $\mathfrak{M}$ を有限の集合とし、$R \{ x, y \}$ を $\mathfrak{M}$ の元 $x, y$ 間の対称な関係とします。 $\mathfrak{M}$ に次のプロパティを持つ 2 つの異なる要素 $a, b$ が存在するとします。$x \neq a$ と $y \neq b$ が存在し、$x$ (それぞれ $y$) が唯一の要素 $z \in \mathfrak{M}$ であり、$R \{ a, z \}$ (それぞれ $R \{ b, z \}$) が true になります。そして、$a$と$b$以外の各$t \in \mathfrak{M}$について、$R \{ t, z \}$が真となるようなすべての$z \in \mathfrak{M}$の集合は、$t$とは異なり、2つの要素からなる集合です。 これらの条件の下に、$\mathfrak{M}$ 上に区間の $[0, n]$ の $\mathbf{N}$ の全単射 $i \to x_i$ が存在し、$x_0 = a, x_n = b$ となり、$1 \leq i \leq n$ (定義する $x_i$ によって $R \{ x_{i-1}, x_i \}$ が真となる) が存在することを示します。 $i$の帰納法）。

b) $\mathbf{R}^{n-1} \times \mathbf{R}$ で識別される $\mathbf{R}^n$ ($n \geq 2$) では、$L$ と $L'$ を 2 つの破線とし、それぞれ 2 つの数列 $(x_i)_{0 \leq i \leq p}$ と $(x'_j)_{0 \leq j \leq q}$ で定義され、次のプロパティを持ちます: (i) $x_i = (y_i, z_i)$、$x'_j = (y'_j, z'_j)$ を置くと、次のようになります。 $1 \leq i \leq p - 1$の場合は$z_0 = z'_0 = 0, z_p = z'_q = 1, 0 < z_i < 1$、$1 \leq j \leq q - 1$の場合は$0 < z'_j < 1$。 (ii) $p + q - 2$ 数 $z_i, z'_j$ ($1 \leq i \leq p - 1, 1 \leq j \leq q - 1$) はすべて別個です。 (iii) $L$ (それぞれ $L'$) の 2 つの異なる辺には、共通のに最大 1 つの点が含まれます [これは、$x_i$ (それぞれ $x'_j$) の 1 つである場合もあれば、そうでない場合もあります]。区分的に 2 つの全射法線形写像 (練習問題 6) $u : I \to L, u' : I \to L'$ が存在することを示します。ここで、$I$ は $\mathbf{R}$ の区間 $[0, 1]$ であり、$u(t) = (v(t), \zeta(t))$ と置くと、$u'(t) = (v'(t), \zeta'(t))$ になります。 ($t \in I$)、すべての $t \in I$ に対して $\zeta(t) = \zeta'(t)$ があります。

$$
\zeta(0) = \zeta'(0) = 0 \quad \text{and} \quad \zeta(1) = \zeta'(1) = 1.
$$

c) $\mathbf{R}^{n-1} \times \mathbf{R}$ と同一視される $\mathbf{R}^n$ では、$K \cap (\mathbf{R}^{n-1} \times \{0\})$ 含むが少なくとも 2 つの異なる点となるように、$K$ を接続されたコンパクト集合とします。 $K' = K - K$ (すべての $x - y$ のうち集合、$x \in K$ と $y \in K$) の場合、$K' \cap (\mathbf{R}^{n-1} \times \{0\})$ 含むは 1 つの点から構成されていない接続された集合であることを示します。 [b)、適用章 II、 、命題 6 および練習問題 15 を使用します。]
