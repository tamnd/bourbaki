a) すべての 0 次元ポーランド語空間が、積 $J = \mathbf{N}^\mathbf{N}$ の閉じた部分空間と同相であることを示します (開いたものと閉じたものの両方である集合による X の厳密なふるい分けを考えてください)。

b) X を 0 次元のポリッシュ空間とし、Y を内部点を持たず、X のオープン集合の可算共通部分であるX の密部分空間とする。 Y が J と同相であることを示します。 (メトライズ可能 0 次元空間では、開いているが閉じていない集合は、開いていて閉じているペアの互いに素集合の無限可算数数列の和集合であることに注意してください。 の定理 1 を使用してください。 no. 1.) 内部点を持たず、開集合の可算共通部分である R のすべての密部分空間は J と同相であると推定します (そのような集合は R の可算密部分集合 D の補数に含まれており、 $\mathbf{C}D$ は 0 次元です)。

c) X が任意の不可算 0 次元ポーランド語空間である場合、J と同型の可算集合と部分空間に X の分割が存在します [b) と § 5 の練習問題 11 を使用]。
