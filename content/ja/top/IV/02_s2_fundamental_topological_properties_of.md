## 2. 実直線の基本的なトポロジカル特性

### 1. アルキメデスの公理

この切断の主題である実直線の位相的性質は、次の定理のすべて帰結です。

#### 定理 1 {#top-iv-s2-thm-1 .statement tag=0BPF}

*$x$ と $y$ が 2 つの実数 > 0 である場合、$y < nx$ となる整数 $n > 0$ が存在します。

開いた区間 ]$0, x$ と ]$y, \to$ は空ではないので、$0 < p/q < x$ と $y < r/s$ となる 2 つの有理数数 $p/q$ と $r/s$ が存在します ($\S$ I, no. 4, 命題 4); $n$ を$nps > qr$ とすると、$y < nx$ になります。

#### 注意 {#top-iv-s2-n1-rem-1 .statement tag=0BPG}

実数の理論の公理構成は章 V, $\S$ 2 で見つかり、定理 1 が公理として現れます。この公理の詳細については、歴史注意から章 IV を参照してください。

### 2. コンパクト部分集合/$\mathbf{R}$

#### 定理 2 (ボレル ルベーグ) {#top-iv-s2-thm-2 .statement tag=0BPH}

実直線 $\mathbf{R}$ の部分集合がコンパクトであるためには、それが閉じて有界であることが必要かつ十分です。

1) 条件が必要です。 $A$ を $\mathbf{R}$ の圧縮部分集合とし、$a$ を実数 $> 0$ とします。 集合 $A$ は閉じており (章 I、$\S$ 9、no. 3、命題 4)、点 $x_i$ の有限の数が存在します。 $A$ が近傍 $[x_i - a, x_i + a]$ (章 I, $\S$ 9, no. 3) の和集合に含まれるような、$\mathbf{R}$ の ($1 \leq i \leq n$)。 $b$ を数 $|x_i|$ の最大値とします。そうすると$A \subset [-b - a, b + a]$になります。

2) 条件で十分です。すべての区間 $[ -a, +a ]$ ($a > 0$) がコンパクトであることを示すだけで十分です。また、この区間は完全な一様空間の閉じた部分集合であるため、各 $b > 0$ について、有限によって $[ -a, +a ]$ をカバーできることを示すだけで十分です。 数/区間/形 $[x - b, x + b]$ (章 II、$\S$ 4、no. 2、系 ～ 定理 3)。さて、$n$ を整数 $> 0$ として、$a < nb$ とします。 $x \in [ -a, +a ]$ で、$m$ が最大の整数 (正または負) で、$mb \leq x$ の場合、$-n \leq m \leq n$ と $mb \leq x \leq (m + 1)b$ が得られます。したがって、$2n + 1$ 区間 $[ (k - 1)b, (k + 1)b ]$ ($-n \leq k \leq n$) 形は、必要な型をカバーします。

#### 系 1 {#top-iv-s2-thm-2-cor-1 .statement tag=0BPI}

実直線 $\mathbf{R}$ の部分集合は、有界である場合に限り、比較的コンパクトです。

#### 系 2 {#top-iv-s2-thm-2-cor-2 .statement tag=0BPJ}

実直線は局所的にコンパクトな空間であり、コンパクトではありません。

#### 注意 {#top-iv-s2-n2-rem-1 .statement tag=0BPK}

定理 2 は、「ハイネ・ボレル定理」と呼ばれることがよくあります。歴史的な注意から章 II および IV を参照してください。

### 3. 部分集合中$\mathbf{R}$中最小の上界

#### 定理 3 {#top-iv-s2-thm-3 .statement tag=0BPL}

上に境界がある (それぞれ下に境界がある) 実直線の空でないすべての部分集合には、最小の上界 (それぞれ最大の下界) があります。

$A$ を上で境界のある $\mathbf{R}$ の空ではない部分集合とし、$b$ を $A$ の上界として、$A \subset ]\leftarrow, b]$ とします。それぞれの $x \in A$ について、属するから $A$ までの数 $\geqslant x$ の集合 $A_x$ を検討します。 集合 $A_x$ 形 $y \geqslant x$ の場合、$A_y \subset A_x$ 以降、$\mathbf{R}$ では基底 $\mathfrak{B}$ のフィルター。 $a$を$A$の点とします。それぞれの $x \geqslant a$ 所属から $A$ について、$A_x$ はコンパクトな区間 $[a, b]$ に含まれるため、フィルター 基底 $\mathfrak{B}$ にはクラスター 点 $c$ が含まれます。 区間 $[x, \rightarrow[$ が閉まっているため、$c$ 属するから共通部分となり、$c$ は $A$ の上界になります。しかし、一方で、$A$ のすべての上界 $z$ は $\geqslant c$ であり、そうでない場合、$c$ の近傍 $]z, \rightarrow[$ は $A$ の点含むにはなりません。したがって、$c$ は $A$ の最小の上界です。

下に有界がある空ではない集合 $B$ についても同様に議論することができます。あるいは、単に $-B$ は空ではなく上に有界であり、$c$ が $-B$ の最小の上界である場合、$-c$ は以下の最大の下界であると述べることができます。 $B$。

$A$ のうち最小の上界 $c$ は、次の 2 つの特性によって特徴付けることができます。
(i) $x \in A, x \leqslant c_*$ ごとに。
(ii) それぞれの $a < c$ に対して、$a < x \leqslant c$ となるような $x \in A$ が存在します。

閉じた集合 (空ではなく上に境界がある) 属するから集合の最小の上界であり、その最大の元です。そして、上で制限されている$\mathbf{R}$の空でない部分集合$A$の最小の上界は、$A$の閉包内の最大の実数として定義できます。

### 4. 区間中特徴付け

#### 命題 1 {#top-iv-s2-prop-1 .statement tag=0BPM}

*空ではない $\mathbf{R}$ の部分集合 $A$ は、$a$ と $b$ が $A$ のいずれか 2 つの点である場合に限り、$a < b$、閉じた区間 $[a, b]$ が含まれる場合に限り、区間になります。 $A$*。

条件は明らかに必要です。逆に満たされたとする。 $A$ が上にも下にも境界がない場合は、$\mathbf{R}$ の全体である必要があります。$x$ が $\mathbf{R}$ のいずれかの点である場合、$a < x < b$ のように $A$ の 2 つの点 $a, b$ が存在します。 $A$ が上に限定され、下に限定されない場合、$k$ をその最小の上界とします。次に、任意の $x < k$ に対して、$A$ には $a$ と $b$ が存在し、$a < x < b \leqslant k$ となるため、$x \in A$ となり、したがって、$A$ は 2 つの区間 $]\leftarrow, k], ]\leftarrow, k[$ のうちの 1 つだけになります。他の場合でも議論は同様です。

### 5. $\mathbf{R}$中部分集合に接続されました

#### 定理 4 {#top-iv-s2-thm-4 .statement tag=0BPN}

* $A$ が区間である場合にのみ、$\mathbf{R}$ の部分集合 $A$ が接続されます。*

i) 条件が必要です。 $A$ が接続されているとします。$A$ が単一の点で構成されている場合、それは区間です。 $A$ に複数の点がある場合、$a$ と $b$ を $a < b$ となるように $A$ の 2 つの点とします。 no. 4 の 1 である命題によって、$a < x < b$ 属するから $A$ までのすべての $x$ を示すだけで十分です。さて、$x \notin A$ の場合、$A \subset C\{x\}$ になるはずです。しかし、$C\{x\}$ は 2 つの互いに素が開いた集合 ]$\leftarrow, x[$ と $]x, \rightarrow[$ のうちの和集合であり、それぞれが $A$ を満たすため、仮定とは反対に、$A$ は接続されません。

2) 条件は *十分* です。まず、すべての *コンパクト* 区間 $[a, b]$ が接続されていることを示しましょう。それぞれの整数 $n > 0$ について、$V_{1/n}$ をすべての対 $(x, y)$ の側近からなるとし、$|x - y| \leq 1/n$ とします。 章 II, § 4, no. 4 の命題 6 により、点 $x, y$ $[a, b]$ のすべての対が $V_{1/n}$ チェーンで結合できることを示すだけで十分です。 $p$ を $p/n \leq x$ となる最大の整数とし、$q$ を最大の整数とし、$q/n \leq y$ ($p$ と $q$ は定理 1 の理由により存在します) no. 1);それから$p \leq q$。 $p = q$ の場合、$y - x < 1/n$ と点 $x$ と $y$ 形は $V_{1/n}$ チェーンです。 $q > p$ の場合は、$x_i = (p + i)/n$ ($i = 1, 2, \ldots, q - p$) を入れます。 $x_1 - x \leq 1/n$、$y - x_{q-p} \leq 1/n$、$x_{i+1} - x_i = 1/n$があるので、点 $x, x_1, x_2, \ldots, x_{q-p}, y$ 形 $x$と$y$を結合する$V_{1/n}$チェーンです。

ここで、$I$ が 1 つの点のからなるではなく、任意の区間であり、$a$ と $b$ が $a < b$ のような $I$ の任意の 2 つの点である場合、区間 $[a, b]$は$I$に含まれて接続されているため、$I$は接続されています。

#### 系 1 {#top-iv-s2-thm-4-cor-1 .statement tag=0BPO}

*実直線は接続されており、ローカルに接続されている空間です。*

#### 系 2 {#top-iv-s2-thm-4-cor-2 .statement tag=0BPP}

*$\mathbf{R}$ のコンパクト接続部分集合のみが有界で閉じた区間です。*

定理 4 までに、複数の点のどの区間からなるも含むに属さない $\mathbf{R}$ の部分集合が *完全に切断* されます。これは、例えば、有理数数の集合 $\mathbf{Q}$ に当てはまります。なぜなら、無理数数の集合 $C\mathbf{Q}$ が $\mathbf{R}$ に密集しているからです。

#### 命題 2 {#top-iv-s2-prop-2 .statement tag=0BPQ}

*$\mathbf{R}$ の空でないすべてのオープン集合は、相互に互いに素オープン区間の可算家族の和集合です。

$A$ を $\mathbf{R}$ の空ではないオープン集合とします。 $\mathbf{R}$ はローカルに接続されているため、$A$ のすべての *成分* は接続されたオープン集合 (章 I, § 11, no. 6、命題 11) であるため、定理による *オープン区間* 4. 次のいずれか 2 つです。これらの開いている区間は互いに素です。一方、それらのそれぞれ含むは有理数です。したがって、これら区間のうち集合は $\mathbf{Q}$ 以下の冪を持ち、つまり *可算* です。

その結果、$\mathbf{R}$ のすべての閉じた集合は、相互に開いた互いに素区間の (有限または無限) 数列 $(I_n)$ の和集合の補数になります。これらの区間は、検討中の閉鎖された集合に*隣接している*と言われています。逆に、区間のような数列が与えられると、それらの和集合の補数は、これらの区間が隣接する閉じた集合になります。

### 6. 区間の区間への同型写像

#### 定理 5 {#top-iv-s2-thm-5 .statement tag=0BPS}

*I を R の区間とします。すると、R への I の写像 f は、f が厳密に単調で、I 上で連続である場合に限り、f(I) に対する I の同型写像になります。そして f(I) は R で区間になります。*

1) 条件が必要です。 $a$ と $b$ を $a < b$ となるような I の 2 つの点とし、たとえば $f(a) < f(b)$ と仮定します。 $f$ が I の真に増加するであることを示しましょう。まず、$a < c < b$ の場合、$f(a) < f(c) < f(b)$ が必要です。たとえば、$f(a) < f(b) < f(c)$ がある場合、$f$ の下の区間 $[a, c]$ の像は接続された集合 (章 I, , no. 2, 命題 4) となるため、次のようになります。 含む区間 $[f(a), f(c)]$;したがって、$f$が単射である仮定とは反対に、$f(x) = f(b)$となるような$x \in [a, c]$が存在することになります。

したがって、$x$ と $y$ が $x < y$ となるような I のいずれか 2 つの点である場合、$f(x) < f(y)$ になります。なぜなら、$a < x < b$の場合は$f(a) < f(x) < f(b)$、$b < x$の場合は$f(a) < f(b) < f(x)$、$x < a$の場合は$f(x) < f(a) < f(b)$があるからです。 $a, b, x$ の代わりに $a, x, y$ をそれぞれ使用して議論を繰り返すと、$f(x) < f(y)$ であることがわかります。

2) 条件は *十分* です。 $f$ が I (たとえば、真に増加する) 上で連続で厳密に単調であると仮定します。 $f(I)$ は接続されているため区間であり、$f$ は真に増加するであるため、$f$ は全単調写像です。 Iから$f(I)$へ。さらに、開いた区間 *in* I の $f$ の下の像は、開いた区間 *in* $f(I)$ であるため、 (§ 1, no, 4, 命題 5) $f$ は、 Iから$f(I)$へ。

#### 注意 {#top-iv-s2-n6-rem-1 .statement tag=0BPT}

前述の証明の最初の部分は、実際、 I から $\mathbf{R}$ への*連続単調詞* 写像が厳密に単調であることを示しています。したがって、証明の 2 番目の部分から、*すべての連続単射詞写像* $f$ *区間* I *into* $\mathbf{R}$ *は* I *onto* の同型写像であるということになります。 $f(I)$。
