$(u_n)$ を、一般的な項が $u_n$ である系列が収束するが、絶対的に収束しないような有限実数の数列とします。 III, § 5章、練習問題6 a)の条件を満たす$\mathbf{N}$の順列$\sigma$が存在するが、一般項が$u_{\sigma^{-1}(n)}$である級数は収束しないことを示してください。 [$h, k, m$ を次の特性を持つ 3 つの整数とします: $p_1, \ldots, p_r$ が整数 $n$ で、$h \leq n < h + m$ と $u_n \geq 0$ である場合、$u_{p_1} + \cdots + u_{p_r} > 2$ と $h + m < k - r$ になります。さらに、$\mu, \nu$ が $h + m \leq \mu \leq \nu$ となるような整数である場合、$\left| \sum_{n=\mu}^{\nu} u_n \right| \leq 1$ になります。 $s = m - r$ を置き、$q_1, \ldots, q_s$ が整数 $n$ を表し、$h \leq n < h + m$ と $u_n < 0$ のようになります。 $1 \leq i \leq r$ に対して $\pi(p_i) = k - i + 1$、$1 \leq j \leq s$ に対して $\pi(q_j) = k + j$、$1 \leq j \leq s$ に対して$\pi(k + j) = h + s - j$、$1 \leq i \leq r$ に対して$\pi(k - i + 1) = h + s + i - 1$、そして最後に、$\mathbf{N}$ の区間 $[h, k + s]$ の順列 $\pi$ を考えます。 $h + m \leq n \leq k - r$の場合は$\pi(n) = n$。私たちが持っていることを示す
$$
\left| \sum_{i=h}^k u_i - \sum_{i=h}^k u_{\pi^{-1}(i)} \right| \geq 1.
$$
