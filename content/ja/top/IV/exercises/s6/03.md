a) それぞれの区間 $I \subset \mathbf{R}$ について、$G(I)$ がそれ自体に対する $I$ のすべての同型写像の群を表すものとします。 $I$ と $J$ が $\mathbf{R}$ のいずれか 2 つの区間であり、それぞれの含むが 1 つ以上の点である場合、$G(I)$ と $G(J)$ は同型であることを示します。 $G(I)$、増加するの同型写像の集合 $F(I)$ は、添字 2 の正規の部分群です。

b) $G = G(\mathbf{R})$ と $F = F(\mathbf{R})$ とします。それぞれの $f \in G$ とそれぞれの $x \in \mathbf{R}$ について、$\sigma(x; f)$ が $\operatorname{sgn}(f(x) - x)$ を表すものとします。 $T^+$ (それぞれ $T^-$) をすべての $f \in F$ の集合とし、$\sigma(x; f)$ が定数となり、$\mathbf{R}$ では 1 (それぞれ $-1$) に等しくなります。 $T^+$ (それぞれ $T^-$) のすべての元が、$F$ の翻訳 $x \to x + 1$ (それぞれ $x \to x - 1$) では共役であることを示します。 [$f \in T^+$ の場合、点 $f^n(o), n \in \mathbf{Z}$ の数列を考慮してください]。

c) $T = T^+ \cup T^-$ とします。 属するから $T$ にならないすべての $f \in F$ は、$T_*$ の 2 つの元のうち $F$ では積であることを示してください。 [$f_1(x) = \sup (x, f(x))$と$f_2(x) = \inf (x, f(x))$を$F$に$f = f_1 f_2$と書きます。 $g$ が $x \to x + 1$ の翻訳である場合、$f_1 g$ と $g^{-1} f_2$ 属するから $T$]。

d) 2 つの元 $f, g$ は、すべての $x \in \mathbf{R}$ に対して $\sigma(x; f) = \sigma(s(x); g)$ となるような $s \in F$ が存在する場合に限り、$F$ で共役になります。 [すべての $x$ のオープン集合のうち $\sigma(x; f) \neq 0$ となる成分 $I_n$ を考えてみましょう。 $F(I_n)$ と $F$ が ($a$ による) 同型であることに注意し、$b$] を使用します。 特に、$[a, b]$ が $\mathbf{R}$ の区間で、F の一部の f \in について $\sigma(a; f) = \sigma(b; f) = 0$ となる場合、$F$ の元 $f'$ は、$x \leq a$ または $x \geq b$ の $f$ と一致するであり、次のようになります。 $a < x < b$の$f'(x) = x + \varepsilon(f(x) - x)$、$0 < \varepsilon < 1$は、$F$の共役から$f$です。

e) $f \in F$ と $a, b, c, d$ を 4 つの実数とし、$x = a, x = b, x = c, x = d$ は $a < c < b < d$ と $f(x) - x = 0$、$a < x < c$ と $b < x < d$ は $\sigma(x; f) = 1$ とします。 $a', b'$ を 2 つの数として、$a \leq a' < c$ と $b < b' \leq d$ とします。 $J = [a, b], J' = [a', b']$ とし、$f_1$ は $f$ から $J$ の制限を表すものとします。したがって$f_1 \in F(J)$。 $F(J')$ の要素 $f_2 = s f_1 s^{-1}$ が $a' < x < b'$ のときはいつでも $f_2(x) > f^{-1}(x)$ となるような、$J$ の$J'$ への漸増同型同型$s$ があることを示してください [$d$ を使用]。

f) $f \in F$ と $[a, b]$ を $\mathbf{R}$ の区間とし、$x = a$ と $x = b$ は $f(x) - x = 0$、$x < a$ は $\sigma(x; f) = -1$、$x > b$ は $\sigma(x; f) = +1$ とします。 $F$には$g \in F$、共役から$f$が存在し、すべての$x \in \mathbf{R}$に対して$g(x) > f(x)$となることを示してください（同じ方法）。

g) $H^+$ (それぞれ $H^-$) は、$+\infty$ (それぞれ $-\infty$) の近傍における $f(x) = x$ のように、すべての $f \in F$ の $F$ からなるの通常の部分群を表すものとします。 $H^+, H^-$ と $H = H^+ \cap H^-$ が、$F$ のうち、$F$ と $\{e\}$ を除く唯一の正常な部分群であることを示してください。 [$N$ が $F$ 以外の $F$ の通常の部分群であり、$f \in N$ が属するから $H^+$ にならない場合、すべての集合が成り立つような元 $g \in N$ があることを示してください。 $x \in \mathbf{R}$ のうち、$\sigma(x; g) = +1$ は区間 $]a, +\infty]$ であり、$x \leq a$ には $g(x) = x$ があります。これを行うには、e) と f)、および b) と c) の構成を使用します。 $F$ では正常である $H$ と $\{e\}$ 以外に、$N$ 含むが部分群ではないことを示すために、元 $f \in H$ が $e$ と区別されることを考慮します。 $a$ と $b$ を最大の下界とし、$x \in \mathbf{R}$ の集合の最小値上界 (どちらも仮定で有限) とし、$\sigma(x; f) \neq 0$ とします。次に、$F([a, b])$ が $F$ と同型であることに注目し、前の結果を使用します。

h) 群 $H$ が単純であることを示します。 ($H$ 含む $F$ に自明でない部分群正常がない証明と同じ方法)。
