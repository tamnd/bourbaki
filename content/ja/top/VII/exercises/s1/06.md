$H$ と $K$ を、$\mathbf{R}^n$ の 2 つの閉じた部分群とし、$H + K$ を閉じた部分群とします。

a) $V$ (それぞれ $W$) が $H$ (それぞれ $K$) に含まれる最大のベクトル部分空間である場合、$V + W$ には最大のベクトル部分空間が含まれることを示してください。 $G$、従って $d(H) + d(K) = d(H \cap K) + d(H + K)$ [$G/(V + W)$ の有理数階数は有限であり、その結果、$G$ できない含むは $V + W$ に含まれない行であることに注意してください]。

b) $U$ を $V + W$ の相補的な部分空間とし、$G$ が $V + W$ と $M = G \cap U$ の直和となり、$H \cap K$ が $(V + W) \cap (H \cap K)$ と $L = H \cap K \cap U$ の直和となるようにします。 (練習問題5)。 $H'$ (それぞれ $K'$) を、$G$ を $V + W$ と $M$ の直接和に分解する際の $H$ (それぞれ $K$) の点の成分からなる $M$ の部分群とします。 $M = H' + K'$ と $H' \cap K' = L$ を表示します。

c) $H'' = H \cap (V + W)$ と $K'' = K \cap (V + W)$ を置くと、$V \cap W = \{ o \}$ の場合に $r(H'') + r(K'') = r(H'' \cap K'') + r(H'' + K'')$ (簡約する) となり、そのとき $H'' \cap K''$ は $V \cap K''$ と $W \cap H''$ の直和であることを示します。

d) それを示す
$$
r(H) + r(K) = r(H \cap K) + r(H + K)
$$
[c) と練習問題 4 を使用します。$r(H) = r(H') + r(H'')$ と $r(K) = r(K') + r(K'')$ に注意してください]。
