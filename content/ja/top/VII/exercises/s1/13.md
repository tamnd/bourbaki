位数 $n$ ($n$ 整数 > o) の *Farey 系列* は、有理数数 $p/q$ の集合 $F_n$ で、$0 \leq p \leq q \leq n$ となるような最低の項です。 増加する位数 (つまり、Farey 系列は *数列*)。

a) 2 つの有理数数 $r = p/q, r' = p'/q'$ が $p'q - pq' = \pm 1$ である場合、整数 $(p'', q'')$ のすべての対は形 $p'' = px + p'y, q'' = qx + q'y$ で表現できることを示します。ここで、$x$ と $y$ は整数です。 $x$ と $y$ が同じ符号を持つ場合に限り、終点 $r$ と $r'$ をもつ閉じた区間に対する分数 $p''/q''$ 属する 。

b) a) から、$r = p/q$ と $r' = p'/q'$ が $[0, 1]$ で 2 有理数数で、$q > 0$ と $q' > 0$ および $qp' - pq' = \pm 1$ である場合、$r$ と $r'$ は数列で連続する元であると推定します。 $F_n$、どこで$n = \max(q, q')$。さらに、最小の整数 $m$ では、$F_m$ のエンドポイント $r$ と $r'$ 含む点を持つ開いた区間は $m = q + q'$ となり、この区間の$F_{q+q'}$の点、つまり端数の$(p + p')/(q + q')$です。

c) 逆に、$r$ と $r'$ が $F_n$ の 2 つ連続する元である場合、$p'q - pq' = \pm 1$ ($n$ に帰納法を用いる) があることを示してください。

d) c) から、各実数 $\theta \in [0, 1]$ と各整数 $n \geq 1$ について、$1 \leq q \leq n$ と $|\theta - p/q| \leq 1/(n + 1)q$ (cf. 練習問題 10) のように、最下位項に少なくとも 1 つの分数 $p/q$ が存在することを推定します。

e) $p/q$ が $|\theta - p/q| < 1/q^2$ のような最下位項の分数である場合、$\theta$ 属するから開いた区間まで、その端点は $p/q$ に連続する Faley 系列 $F_q$ の 2 つの項です。
