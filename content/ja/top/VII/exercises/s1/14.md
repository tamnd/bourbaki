$\varphi : \mathbf{R} \to \mathbf{T}$ を標準準同型とします。 $\theta$ を $\mathbf{T}$ における無限大位数の元とし、$\theta_0$ を $\varphi(\theta_0) = \theta$ となるような (無理数) 実数とします。それぞれの整数 $n > 0$ について、$S_n$ を元の集合 $\mathbf{T}$ の $k\theta$ と$1 \leq k \leq n$ とし、$\mathbf{R}$ の区間 $I$ をそれぞれとします$N(I, n)$ は集合の $I \cap \overline{\varphi^{-1}(S_n)}$ の元の数になります。

a) $I = [0, \theta_0[$ を取る場合、$N(I, n) = [n\theta_0]$ であることを示します [$N(I, n)$ は、$1 \leq y \leq n$ と $x \leq y\theta_0 < x + \theta_0$ のように、整数 $(x, y)$ の対の数であることに注意してください]。

b) より一般的には、$I = [0, m\theta_0[, m$ が整数であるとすると、$m.[(n - m)\theta_0] \leq N(I, n) \leq m.[n\theta_0]$ (同じ方法) になります。

c) $I$ がいずれかの区間である場合、数 $N(I, n)/n$ は $n \to + \infty$ として、$I$ の長さに等しい極限になる傾向があると推測します。 (b を使用して、$I$ が形 $[m\theta_0 + a, m'\theta_0 + a']$ で、$m, m', a$ と $a'$ が整数であるときの結果を最初に証明します)。次に、形 $m\theta_0 + a$ の数によって $I$ の端点に近似することにより、一般ケースに移ります。) [「数列 $(k\theta) \mod 1$ の等分化」]。
