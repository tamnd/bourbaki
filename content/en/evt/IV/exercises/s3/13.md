a) Let E, F be two Fréchet spaces, G a locally convex Hausdorff space and E', F', G' the duals of E, F, G respectively. Let $u$ be a bilinear mapping from $E' \times F'$ into $G'$, which is separately continuous (III, p. 28) when E', F', G' are assigned the weak topologies $\sigma(E', E)$, $\sigma(F', F)$ and $\sigma(G', G)$. Show that under these conditions, $u$ is a continuous mapping from $E' \times F'$ into $G'$ when E', F' and G' are assigned the strong topologies. (For $z \in G$, put \langle z, u(x', y') \rangle = \langle v_z(x'), y' \rangle \text{ where } v_z(x') \in F. \text{ First show that if } E' \text{ is assigned the strong topology and } F \text{ the initial topology, then the set of all } v_z, \text{ as } z \text{ ranges over a bounded set } C \text{ in } G, \text{ is equicontinuous; for this use IV, p. 51, exerc. 19, } d). \text{ Next show that there exists a neighbourhood } V' \text{ of } 0 \text{ for the strong topology of } E' \text{ such that the union of the sets } v_z(V') \text{ as } z \text{ ranges over } C \text{ is bounded in } F; \text{ for this use III, p. 47, exerc. 5.)}
b) Give an example to show that the conclusion of a) does not hold if we assume that $E$ is a Fréchet space and $F$ a strict inductive limit of Fréchet spaces (III, p. 47, exerc. 3).
