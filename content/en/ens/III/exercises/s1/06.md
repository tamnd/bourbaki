Let E and F be two ordered sets, and let $\mathcal{A}(\mathrm{E}, \mathrm{F})$ be the subset of the product ordered set $\mathrm{F}^{\mathrm{E}}$ consisting of the *increasing* mappings of E into F.

(a) Show that if E, F, G are there ordered sets, then the ordered set $\mathcal{A}(\mathrm{E}, \mathrm{F} \times \mathrm{G})$ is isomorphic to the product ordered set $\mathcal{A}(\mathrm{E}, \mathrm{F}) \times \mathcal{A}(\mathrm{E}, \mathrm{G})$.

(b) Show that if E, F, G are three ordered sets, then the ordered set $\mathcal{A}(\mathrm{E} \times \mathrm{F}, \mathrm{G})$ is isomorphic to the ordered set $\mathcal{A}(\mathrm{E}, \mathcal{A}(\mathrm{F}, \mathrm{G}))$.

(c) If $\mathrm{E} \neq \emptyset$, then $\mathcal{A}(\mathrm{E}, \mathrm{F})$ is a lattice if and only if F is a lattice.

(d) Suppose that E and F are both non-empty. Then $\mathcal{A}(\mathrm{E}, \mathrm{F})$ is totally ordered if and only if one of the following conditions is satisfied :

($\alpha$) F consists of a single element;

($\beta$) E consists of a single element and F is totally ordered;

($\gamma$) E and F are both totally ordered and F has two elements.
