A subset $ A $ of a topological space $ X $ is said to be a *thin* set if, for each perfect set $ P \subset X, P \cap A $ is nowhere dense in $ P $.

$ a $ Every finite union of thin sets is thin.

$ b $ The frontier of a thin set is nowhere dense.

$ c $ There is a largest perfect set in $ X $ whose complement is thin.
