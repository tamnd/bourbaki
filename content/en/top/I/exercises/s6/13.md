Let $ f $ be a mapping of a set $ X $ into a set $ X' $. Then $ f $ is injective if and only if, for every filter base $ \mathcal{B} $ on $ X $, $ (f^{-1}(\mathcal{B})) $ is a filter base equivalent to $ \mathcal{B} $.
